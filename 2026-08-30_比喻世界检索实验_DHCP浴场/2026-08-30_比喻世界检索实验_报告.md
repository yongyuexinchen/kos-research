# 比喻世界检索实验：DHCP 浴场模型（2026-08-30）

> **性质**：端到端最小演示（M 手工冻结、投影手工标注模拟 27B、fit 机器算）——**验证"比喻=查询 schema"反转的第一步，方向性结论**
> **触发**：用户提出反转——不是"卡片→抽特征→找相似卡→生成比喻"，而是"问题→建立比喻世界 M→全库卡片尝试落入 M→fit(card,M) 最大者=最佳同构"
> **上游**：《知识故事_比喻引擎原理_v2》《v0.2/v0.3 实验报告》、GPT 外脑对齐（fidelity 字段、机器算结构/模型解释语义/人裁决）

## 一、M = DHCP 浴场模型（冻结版 v1）

**world_element schema**（比喻世界的正式字段）：

```
world_element
├── role          角色名
├── relation      关系
├── source_ref    对应的现实元素
├── fidelity      faithful | emergent
└── inference_permission  primary | auxiliary | forbidden
```

**Faithful core（9 角色槽，primary）**：顾客(Client) / 正规师傅(合法Server) / 冒牌师傅(恶意Server) / 喊声(Discover) / 多方应声(Offer) / 挑选(Request) / 接受服务(ACK) / 错误服务(恶意配置) / 事后发现(暴露)

**Emergent layer（auxiliary，禁止参与主判）**：前台（emergent，function=post-hoc validation/权威否认，DHCP 无对应实体）、沐浴露（错误服务具象化）、浴场（faithful 环境对应）

**M 的忠实关系骨架（7 条，检索主判）**：

```
R1 need(需求方广播请求) → R2 claim(服务方响应) → R3 compete(多方竞争)
→ R4 choose(需求方选择) → R5 serve(服务提供) → R6 fake(服务含假/冒充)[核心]
→ R7 detect(事后发现)[核心]
```

## 二、实验设计

- 12 张候选卡：语音克隆/OOC/AI味/信用评分（AI 域+算法域，表面含"服务/骗/识别"词）+ Ahrens 3 张 + Aristotle 3 张 + 李善友/佩蕾丝/波兰尼（跨域无关卡）
- 标注：每张卡对 7 条关系覆盖（2=强 1=部分 0=无），只按卡内实际结构标，不看表面词
- fit 评分（机器算）：总覆盖 + 核心关系×1.5 − 结构惩罚（有选择无竞争 / 有服务无假服务）

|---|---|---|---|---|
| **Voice_Cloning 语音克隆** | **9.5** | 5 | 3 | 0 |
| **OOC 角色崩塌** | **9.5** | 5 | 3 | 0 |

**结构相关卡（语音克隆/OOC/AI味）稳定排前，结构无关卡（四因/形质）干净归零。**

## 四、发现

1. **反转初步成立**：fit(card, M) 排序能把"落入浴场世界"的卡排在前面——验证的不是"AI 能讲好比喻"，而是"**比喻世界能否形式化为查询 schema 并反向检索结构远亲**"。
2. **核心关系决定排序**：R6(假服务)+R7(事后检测) 命中 → 排前；外围关系（R2/R3/R4）在 12 张卡里几乎零覆盖——**M 骨架应分级：核心关系主判、外围关系作细分维度**。
3. **真空区**：R2(响应声明)/R3(多方竞争)/R4(选择) 库内无卡覆盖——DHCP 世界的"市场选择"环节在库里没有对应知识。含义：**fit 是相对最优检索，不是绝对同构判定**；比喻世界的骨架如果太"专"，检索结果会稀疏。
4. **评分粒度不足**：语音克隆（恶意冒充成功）与 OOC（扮演失败被识破）并列 9.5——结构上"假服务+事后检测"都命中，但**冒充意图/方向相反**。需要加"意图方向"维度（成功冒充 vs 失败暴露）。

## 五、局限（诚实声明）

- 投影为**手工标注**（模拟 27B 角色）——投影自动化是 S0 的活
- fit 分数为演示性数字（无校准、无显著性）
- 样本缺"表面相似但结构不同"的对照卡（如"提供良好服务但无冒充"的卡）——"不靠表面词"尚未直接验证

## 六、下一步

1. 补对照卡（良好服务无冒充 / 冒充无服务），验证 fit 不靠表面词
2. 加"意图方向"维度区分成功冒充 vs 失败暴露
3. M 骨架分级定稿（核心 R6/R7 主判 → 外围 R1-R5 细分）
4. 27B 投影自动化（S0 后）：卡 → 关系覆盖标注
5. 与签名实验的关系：**结构签名=候选粗筛，fit(card,M)=精排**——全库扫描时先用签名召回 30-50 张，再对候选做 fit
