## 一、新方法学分类：三维度三档（pilot1+2 的元结论）

Step 2 两批六个国家暴露：**route 维度的时间行为分三种类型**，编码规则因型而异：

| 型 | 定义 | 编码处理 | 例子 |
|---|---|---|---|
| **E 型（事件型）** | 有明确立法事件 → 年度可精确分段 | 用事件年填跳变 | SE L1 2003 / FR PACS 1999-2007 / NL RP 1998 / SI L1-L3 1976 / DE C_child 1998 |
| **S 型（结构性恒定）** | 立法从未提供/宪法否定 → 恒值 | 恒值可全程填（"从未"≠"未知"）| DE L1-L4 恒 0 / NL ordinary L1-L3 恒 0 / DK L2 恒 0 |
| **G 型（渐进无事件）** | 部门法渐进、无单一事件年可查 | **时间变异标 NA + uncertain_flag**（不做平滑/不做粗锚/不前推）；仅保留已知现代状态备注 | SE L4 / DK L3/L4 / NL ordinary L4 / SI L4 |

**G 型的存在是 pilot 最重要的方法学发现**：它不是编码失败，而是证据限制——渐进福利型制度（DK）与部门法等同型制度（SI/SE 的税社保维）在缺乏立法史源时**时间维不可重建到年度**。v0.3.1 protocol 增量：G 型维度降级为横截面编码（只能用于 2021 窗口比较，不进入时间识别）。

### 2.2 T4 验证结论

**DK 的渐进时间线在现有证据下不可重建到年度**——L3/L4 两个"多法条拼出"的维度全部落入 G 型（NA）。这不是 pilot 缺陷，而是对用户问题（"DK 大量 NA 说明 protocol 对渐进制度不够"）的实证回答：
- **protocol 确实不够**——"多法条 → 年度 L_k(t)"需要丹麦语立法史源（各法条首次引入年）才能运行，英文权威源（CEFL/INED）只给文本不给年份
- **修复路径**：①丹麦语立法史检索（§87/§111a/继承税档引入年）；②或接受 DK 作横截面国家（2021 值 + S 型恒 0 维），放弃其时间识别
- **战略含义（对 P0 重要）**：route 接口的时间识别将主要依赖 **E 型国家**（SI 1976/NL 1998/SE 2003/FR PACS 1999-2007），DK 的时间变异贡献低——立法事件 DID 设计天然聚焦 E 型

### 3.2 T5 验证结论——"route 不存在"语义正式规则化

**NL 是"route 不存在 ≠ route 存在但接口为 0"的完美案例**：

```
w_RP(NL, registered, 1997) = NA   ← route 在制度上不存在（编码 NA）
w_RP(NL, registered, 1999) = (2,2,2)  ← 1998-01-01 后凭空创建
w_R(NL, ordinary, 1997)    = (0,0,0)  ← route 存在但接口为 0（结构性零）
```

**正式规则（v0.3.1 建议，NL 提供决定性案例）**：
> **w_R(country, route, t) 在 route 的制度创建年之前一律编码 NA**（不是 0）——0 表示"route 存在但主系统不给接口"，NA 表示"该 route 尚不存在于制度空间"。二者对 A_j×w_j 的含义完全不同：A 数据若覆盖 route 创建前的行为（如 FR PACS 前的不存在），该段 w 无意义、观察值应从分析中剔除或 A 同步 NA。

此规则直接影响 P0 回归样本：FR-PACS 行 1975-1998 段剔除（或 A_PACS=NA），NL-RP 行同理——**只有 route 存在且 A>0 的 (country, route, year) 才能进入 A×w**。

### 4.2 T6 验证结论——political event ≠ institutional event 正式规则化

**SI 决定性确认**：1976-06-04 是唯一真实接口事件（ZZZDR + ZD 同日，同居身份/财产/继承三项一次到位）；**1991 独立（政治事件）对 w_R 零影响**（宪法 53(2) 是加固非重置——同居从部门法待遇升宪法认可，但 w_R 值不变）；2017 FC（整合）值不变；2013 宪法法院（同性继承扩展）不涉异性 ordinary。

**正式规则（v0.3.1，SI 提供决定性案例）**：
> **政治事件（独立/革命/政权更替）不自动产生 w_R 跃迁**；仅当 L_k(t⁻) ≠ L_k(t⁺) **且**有真实法律事件（立法/宪法条款/宪法法院裁决直接改变 route 接口）时才编码跃迁。制度连续性（继承法、过渡法、宪法）是默认假设——**"断裂"必须被证明，不是被默认**。SI 的历史面板证明：46 年窗口只有 1976 一个接口事件年（+宪法加固记录）。

## 六、Pilot 1+2 总结论（temporal reconstructability 首轮完整读数）

1. **事件型（E）国家时间上可干净重建**：SI 1976（三项同日）/ NL RP 1998 / SE L1 2003——立法时刻是时间识别的核心资产
2. **结构型（S）维度可全程填**：恒 0 的"从未提供"（DE/NL ordinary/DK L2）与恒高（SI 1976+）——时间上稳定本身就是信息
3. **渐进型（G）维度时间不可重建**（SE-L4/DK-L3·L4/NL ordinary-L4/SI-L4）→ NA + uncertain，不作时间识别——**这是证据限制不是编码缺陷**
4. **两个新规则确立**：route 不存在=NA≠0（NL 案例）；政治事件≠制度事件（SI 案例）——reconstruction protocol 从"经验观察"升级为"方法学规则"
5. **对 P0 的识别含义**：A×w(t) 的时间变异识别将依赖 E 型立法事件（DID 式），G 型 NA 段与 S 型恒值段不贡献时间识别——回归样本 = 事件窗口附近 + 横截面全样本
