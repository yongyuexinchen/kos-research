# w 量表认知访谈提纲（草案 v0.1）

> 日期：2026-09-02
> 前置：w 量表 P0 设计 v2-final-FROZEN（纸面冻结，本提纲是下一锹）
> 目的：回答 P0 冻结声明中的核心问题——**现实中的人会不会把"承认、供给、整合"理解成三个可以彼此脱钩的制度维度？**
> 若三维独立组合（R↑P↓、P↑I↓、R↑P↑I↓）大量出现 → 三维纯化是现实制度结构发现；若三维永不独立 → 回构念层合并。
> 本提纲同时核查条目语言（被试对"制度承认/公共支持/制度整合"的理解是否与设计一致）——为预测试条目修订提供依据。

---

## 一、访谈基本信息

- 形式：半结构化一对一访谈（60-75 分钟）
- 对象：每社会 **8-12 人**，覆盖：①该替代路线的使用/接近人群 3-4 人 ②一般人群 3-4 人 ③政策/从业相关 2-3 人（如有）
- 路线选择：每场访谈聚焦 **1-2 条替代路线**。中国语境首推组合：
  - **自由职业/数字游民**（provision 预期低、recognition 中等——制度接口主要缺失在供给层）
  - **不婚不育/非婚生育**（recognition 与 provision 都有张力——适合看 R/P 解耦）
  - **AI 伴侣**（三者都可能极低——适合看低-低-低是否整体出现，还是存在细分）
- 记录：全程录音（征得同意）+ 结构化笔记（三维编码表见第六节）

## 二、访谈目标清单（每场要带回什么）

1. 被试对"这条路"的 R/P/I 三维分别怎么描述——**是否会自然分成三层，还是搅在一起**
2. 三维是否独立变化（找 R↑P↓、P↑I↓、R↑P↑I↓ 的具体实例）
3. 条目语言核查：R3/P2/I1/D1 等条目被试理解为什么——与设计意图是否一致（paraphrase 法）
4. A 与 C_A 被试能否区分（"路上多不多" vs "走起来贵不贵"）
5. w_obj/w_perc 落差的主观证据（"制度上其实有/没有 X" vs "大家觉得有/没有 X"）
6. dynamic 预期（"更多人走会怎样"——开放回答看制度响应预期方向）

## 三、半结构化提纲

### 阶段 0：开场与路线锚定（5'）

- 自我介绍、目的说明（"我们在做关于人们如何选择人生路径的研究"）、匿名承诺
- 引出路线："我听说现在不少人在考虑 [自由职业/不婚/AI 伴侣这类选择]，你身边有这样的人吗？你自己想过吗？"
- **锚定确认**：让被试具体描述这条路是什么样（防止各人脑中的"自由职业"不是一回事）

### 阶段 A：可得性 vs 成本辨析（10'）

目的：验证 A（供给量）与 C_A（进入成本）在被试认知中可分。

- A 探测："在你看来，[这条路]现在是不是越来越多人可以走了？方便/容易获得吗？（谁都能选吗）"
- C_A 探测："如果要走这条路，代价大不大？难在哪？（钱？时间？家里人阻力？退路？）"
- **观察点**：被试是否把"很多人走"和"走起来难"当成两件事；若总是混在一起说，记录（提示 A/C_A 量表措辞需拆分）

### 阶段 B：三维解耦探测（25'，核心）

每维用 2-3 个开放问，**刻意制造"这一维变了另一维没变"的场景**来探测独立性：

**B1. Recognition（承认）**
- "走这条路的人，在大家眼里是正常的吗？还是会被说'没走正路'？"
- "如果一个人大大方方跟亲戚朋友说自己选了这条路，大家会怎么反应？"
- 追问（解耦试探）："如果大家其实都挺接受（R↑），但政府/制度完全不管它、不给任何东西——你觉得可能吗？你身边是这样吗？"

**B2. Provision（供给）**
- "走这条路的人，能享受到和上班/结婚的人差不多的保障吗？（社保？权益？出事了有人管吗？）"
- "如果这条路出了问题（比如被坑、权益受损），有正规的地方能解决吗？"
- 追问（解耦试探）："如果制度上其实给了不少支持（P↑），但大多数人根本不知道、也不信（R/I 或 perc 低）——可能吗？"

**B3. Integration（整合）**
- "走这条路的人，是被当成一种正式的、能长期稳定的安排，还是永远是'特殊情况'？"
- "走这条路攒下来的东西（经验？资格？钱？关系？），以后想回主流（上班/结婚）时还用得上吗？"
- 追问（解耦试探）："如果这条路很被大家接受（R↑）、也有保障（P↑），但它永远进不了正式体系、只能算'个人选择'（I↓）——你觉得现实里有这种吗？"

**B 阶段观察核心**：被试是否自然区分三层；在解耦试探下是否点头（说明现实中该解耦真实存在）还是困惑（说明三层可能搅在一起）。

### 阶段 C：条目语言核查——paraphrase 法（15'）

把预测试条目口头念给被试，让其用自己的话复述 + 举一个生活例子：

| 条目 | 问被试 | 核查点 |
|---|---|---|
| R1"正当选择而非没办法才走" | "这句话是什么意思？什么情况算'没办法才走'？" | 是否理解成自主性 vs 被迫（而非合法性）|
| P2"纠纷有正规机构受理" | "你会想到什么机构？真的会去吗？" | "正规机构"在脑中是否具象（法院/劳动仲裁/消协）|
| I1"进入正式结构而非例外" | "'例外'是什么感觉？举例？" | 是否理解成结构性嵌入（而非仅"合法"）|
| I3"资格随进入主流被承认" | "攒下的什么能带走？" | 可迁移性是否被理解为制度承认（而非个人技能）|
| D1"更多人走→制度会正式接纳" | "你觉得真会吗？多久？靠什么推动？" | dynamic 预期是否有内容（谁是推动者）|

**观察点**：逐条记录理解偏差——条目要改还是被试的理解其实反映真实结构。

### 阶段 D：Δw 制度-感知落差（10'）

- "抛开你个人的看法——你觉得法律/政策**实际上**对这条路是什么态度？（客观）"
- "那普通人**普遍觉得**制度对它是什么态度？（感知）"
- "这两个一样吗？如果有差，差在哪？"（追问落差来源：不知道？不信？觉得只是纸面？）

**观察点**：被试能否区分"制度事实上如何"与"人们感知上如何"；落差叙述的具体机制（信息差/不信任/象征性制度）

### 阶段 E：dynamic 预期（10'）

- "如果走这条路的人越来越多，你觉得制度会怎么反应？正式接纳？继续无视？还是管起来？"
- "谁最可能推动这个变化？（政府？市场？舆论？）"
- "你自己信不信它真会发生？"

**观察点**：预期方向（接纳/压制/无视）+ 预期强度（会不会真的制度化）——为 w_dynamic 题提供语料

### 阶段 F：收尾（5'）

- "关于这种人生选择和社会制度的关系，还有什么我刚才没问到、但你觉得重要的？"
- 致谢

## 四、访谈后立即编码（每场 10'）

对每场访谈填一张**三维编码表**：

| 维度 | 被试描述的制度状态（高/中/低/混合）| 证据引语 | 与另一维是否解耦（哪个组合）|
|---|---|---|---|
| Recognition | | | |
| Provision | | | |
| Integration | | | |

同时记：A/C_A 是否可分、paraphrase 偏差条目、Δw 落差证据、dynamic 预期方向。

## 五、跨场汇总：三维独立组合观察表（每社会汇总）

| 组合类型 | 出现频次 | 典型实例（社会+路线）| 含义 |
|---|---|---|---|
| R↑P↓ | | | 承认高但无供给 → 制度口头承认/无实支持 |
| P↑R↓ | | | 供给在但社会不认 → "制度给了但大家不认" |
| P↑I↓ | | | 有保障但进不了正式结构 → 永远的例外 |
| R↑P↑I↓ | | | 最反直觉：承认+供给都有但不整合 |
| R↓P↓I↓（全低）| | | AI 伴侣预期 |
| R↑P↑I↑（全高）| | | 理想制度化 |

**判定**：若"混合组合"（前三类为主）占比高 → 三维解耦在现实中成立，纯化是结构发现；若全是全高/全低 → 三维是同一构念表层，需回构念层。

## 六、退出判据与信号

| 信号 | 处理 |
|---|---|
| 多数被试对 P 维度提问答"不知道/没想过"（超过半数）| provision 可能超出普通人日常认知 → 需要加"信息暴露"环节或换对象（政策相关人群补充）|
| 条目反复被误解且修正后仍偏 | 该条目进预测试前必须改写 |
| 被试完全无法区分 A 与 C_A | A/C_A 量表措辞拆得更显式（加"很多人走 vs 门槛高"对比题）|
| 三维完全同高同低（无任何解耦实例）| 记录为"三维单构念"证据，准备构念层合并预案 |

## 七、与量表预测试的衔接

访谈产出直接喂预测试修订：
- 三维编码表 → 确认/推翻三维结构假设（若推翻，EFA 阶段预期会显示单因子或二维）
- paraphrase 偏差条目清单 → 改写后进预测试
- Δw 落差机制语料 → 丰富 w_perc 条目锚点（让 Likert 题贴近被试真实语言）
- dynamic 预期语料 → w_dynamic 题的选项设计（推动者：政府/市场/舆论）
