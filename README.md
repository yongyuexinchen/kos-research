# KOS 调研报告库（KOS Research Reports）

按 KOS 研究流水线（`system-card-research`：双 Agent 事实/结构调研 → 合成 → 独立审查 → 定稿）执行的多主题调研报告集合，时间跨度 2026-07 → 2026-09。

> **收录范围与性质声明**
> - 本仓库为**公开脱敏版**：按公开仓库伦理，作者身份、雇主、居住地、资产规模、私人通信等可识别细节已隐去或泛化；含个人决策复盘的报告已在文首标注匿名化说明。
> - 所有报告的结论性质多为**理论假设 / 方向判断（theory hypothesis）**，非实证结论，也非投资建议。证据等级（L1–L5）已在各报告内显式标注，引用规则随各报告声明。
> - 不含原始抓取素材（raw_data）、脚本、图片与内部运维记录；不含涉及国家安全与地缘冲突推演、个人隐私画像完整的内部文档。

## 目录结构

每个调研批次目录通常含：

```
01_AgentA_*   事实/数据向产出
02_AgentB_*   结构/历史向产出
03_合成_*     双线合成（共识/分歧/结论）
04_审查/审计   独立审查意见
05_完整报告   定稿
REPORT_*      批次索引/封面
```

命名前缀 `日期_主题`；顶层散落 `.md` 为早期批次单文件报告。

## 为什么公开

展示一套"把开放问题拆成可审计的调研流水线"的工作方式：每个结论都可溯源到产出过程（双 Agent → 合成 → 审查 → 定稿），每个断言都带证据等级，矛盾点显式呈现而非抹平。对方法论/思路的参考价值优先于结论本身。

相关仓库：`egs-theory`（EGS 理论体系与可检验命题集）、`apocalyptic-imagination-research`（末日题材主题调研）。
