**推荐路径 E（综合 7.0-7.5/10）**：培训班打底 + 作品集突围 + 非全在读并行。风险：摆烂（-1.5）+ 代码弱（-1）；优势：系统思维（+1）+ 数据交叉（+0.5）+ 存款缓冲（+1）。

### Q2: 中大非全值得考吗？

**Agent2 的答案很关键——分两种情况**（四象限决策）：

| | 408 能考过 | 408 考不过 |
|---|---|---|
| **有稳定工作** | ✅ 建议非全：边工作边读，学历补强 | ✅ 直接就业+自学 |
| **无稳定工作** | ⚠️ 先找工作！非全需定向就业 | ❌ 不建议考研，先就业 |

**🔴 致命矛盾点（你必须注意）**：中大非全 085411 大数据方向**仅接受"定向就业"（需有工作单位）**。你现在失业——**考上也可能因为"无工作单位"无法入学**。这是比 408 更前置的阻塞。

**修正后的决策逻辑**：
- 考研不是"退路"——它是"在职者的学历补丁"，不是"失业者的出路"
- 你的顺序应该是：**先就业 → 边工作边备考/就读**，而不是"先考研→再就业"
- 408 是决定性门槛：建议先花 2 周做一套 408 真题摸底，<200/500 分就果断放弃考研幻想

## 三、核心研判：你的最优策略（Hermes 定稿）

```
┌─────────────────────────────────────────────┐
│  先就业，考研降级为"在职补丁"，永月升级为武器    │
└─────────────────────────────────────────────┘

第一步（2026.08-12，备考期并行）：
  ├─ 408 真题摸底（2周内）→ <200分果断降级考研
  ├─ 备考继续（你有 9/15 进度闸门机制，保持）
  ├─ 每天 1-2h Python 工程化（不依赖 AI 写代码）
  └─ 永月记忆系统 POC → GitHub 开源（求职武器）

第二步（2027.01-04，等成绩窗口）：
  ├─ 考研上了 → 边等边准备复试 + 找工作
  ├─ 考研没上 → 全力培训班（AI 开发培训/同等）+ 作品集
  └─ 无论上没上：开始投递深圳 AI 应用开发（目标 15-22K 起步，非全在读薪资惩罚仅 2-3K）

第三步（2027.05-12）：
  ├─ 入职 AI 应用公司（Agent/RAG 方向）
  ├─ 若考研上了 → 边工作边读非全（学历补丁兑现）
  └─ 业余打磨永月（记忆系统 = 简历稀缺技能）

第四步（2028+）：
  ├─ 目标：向"给 Agent 加记忆的公司"跃迁（25-50K）
  └─ 终极目标公司：MiniMax（星野）/ 月之暗面 / 智谱
```

**为什么是这个顺序**（理论解释）：
- 你的时间窗是**存款倒计时**（[金额]撑 1-2 年），不是学历倒计时——现金流优先于学历
- 你的**市场担保人**（技能）兑现率高于**体制担保人**（学历）——先兑现高的
- 考研不是被取消，是**降级为在职补丁**——它解决"不被卡"，不解决"被录用"
- 永月是唯一同时覆盖三层的：存在逃逸（换船）× 技能套利（简历）× 理论实验（EGS 验证）
