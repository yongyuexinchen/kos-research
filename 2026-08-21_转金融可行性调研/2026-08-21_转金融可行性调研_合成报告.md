## 三、Hermes 独立裁决（三线没说透的三点）

### 1. "量化缺口"的真面目：回测工程 ≠ 量化研究（重要认知修正）

B线说145/159的"量化"二字是简历关生死线——对。但必须精确：JD原文是"**量化策略回测与数据管道**"，这是**回测工程**（用Qlib/backtrader跑通"策略→回测→指标"闭环），**不是量化研究**（因子挖掘/数学建模）。区别巨大：

| | 回测工程（要补的） | 量化研究（不要碰的） |
|---|---|---|
| 内容 | 数据管道+回测框架+夏普/回撤计算 | 因子模型/统计套利/高频 |
| 难度 | 4个月可补（AI 开发培训期第7-8周） | 无底洞（数学功底+硕士学历） |
| 面试作用 | 证明"我理解策略工作流" | 试图冒充研究员=自曝短板 |

**行动**：demo第7-8周加一个最小回测模块（均线策略+夏普比率，用AKShare/Qlib）——这是"量化"标签的过关答案，**不是**去学量化研究。

### 2. 投资经验的真正价值：不只是"懂业务"，是"懂用户"

B线说投资经验=业务理解维度加分——我升级这个判断：**你的投资经验=金融数据产品的用户体验设计师视角**。你作为散户用数据的方式（查口径/看指标/翻研报/对比同行）恰好就是金融数据产品要服务的场景；你知道"用户会问什么问题"=评测集设计能力+产品sense。这比"懂ROE"更强——它证明你能**设计**金融数据Agent，不只是**理解**金融数据。

**行动**：面试叙事里把"我的评测集来自我投资时真实问过的问题"讲成产品能力，不是个人爱好。

### 3. 记忆=83%高薪筛选器的战略含义：一鱼两吃

289条统计：记忆技能可投池12岗中10个（83%）落在25K+，竞争者没人做——B线说这是最便宜的差异化杠杆。补充战略含义：**金融demo的记忆层=永月（北极星）的最小切片**——求职用（差异化）+ 长线用（永月雏形）一个模块两笔账。这不是额外工作，是把已有的北极星折叠进demo。

## 四、最终决策建议

### 2027年投递策略（泛AI主 + 金融交叉辅，并行不悖）

```
主投（泛AI池，100份）：Agent应用/数据开发岗——岗位池最大，成功率最高
兼投（金融交叉池，50份）：145/159类（投研平台）、上海钢联/同花顺/东财深圳分部、
    招银网络科技/平安科技、券商IT——用金融demo差异化敲门
规则：金融岗offer < 泛AI岗offer×80% → 不接金融岗（F4硬规则，防参照点自我升满）
```

**注意**：145/159只是289条里唯一完全对口的岗——**不要把"金融交叉岗"想象成大片市场**。2027年的成功标准是"拿到泛AI offer"，金融是差异化标签不是主战场。

### 2028年Q2 转金融决策点（三条充要条件，全满足才转）

```
① 2027-2028金融demo保持更新（个人投研工具在跑）
② 金融岗offer薪资 ≥ 当前泛AI岗80%
③ 投递金融岗≥20份、面试≥3个（市场验证存在）
```

### 2031年 单干期权（验证后）

```
前提：12个月验证田通过（策略正期望+稳定）或金融数据服务积累出可产品化的资产
铁律：不代客理财/不收费荐股/不跟单（刑法225条红线）——单干只能走"工具/数据产品"变现
```
