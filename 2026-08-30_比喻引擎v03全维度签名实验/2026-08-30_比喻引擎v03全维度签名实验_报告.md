# 比喻引擎 v0.3 全维度签名实验报告（2026-08-30）

> **性质**：演示算例（人工签名抽取、7 张样本卡）。**本报告的价值不在"跑通"，而在实测发现"结构 vs 风格"的界限**——这是签名语言设计的第一个真实数据点。
> **上游**：v0.2 报告（变量骨架基线）、《比喻引擎设计_v0.3.md》、《学术边界与先例调研_合成报告》（"不变量不是被发现的，是被定义的"）
> **触发**：用户批评 v0.2"因果卡片可不只有变量这一个东西"——签名须覆盖七段式完整结构。

## 一、v0.3 六层签名设计（回应批评）

因果卡七段式结构 → 六层签名：

| 层     | 内容                                                | 对应卡段       |
| ----- | ------------------------------------------------- | ---------- |
| ① 断言层 | iv_count / dv_count / relationship_type           | 一、因果断言     |
| ② 前提层 | 支撑类型序列（D定义/E排除/P实证/M机制）                           | 二、前提链      |
| ③ 机制层 | shape（cascade/converge）/ steps / step_roles / 边类型 | 三、因果链详述    |
| ④ 证据层 | 证据类型集合（案例/原文/数据/历史/逻辑/跨域类比）                       | 四、证据       |
| ⑤ 边界层 | 反例类型 + 边界类型（可证伪结构）                                | 五、反例与边界    |
| ⑥ 连接层 | 理论网络位置（EGS/CET/锚点/死亡）                             | 六、与用户理论的连接 |

## 二、v0.3 结果（全维度加权，层权重：机制2.5/边界2.0/前提1.5/断言1.0/证据1.0/连接0.5）

**8 对判定 5/8 正确，出现两类故障：**

| 对 | 类型 | v0.2 | v0.3 | 变化 |
|---|---|---|---|---|
| G↔B（跨作者正例：推动者↔双向链接） | 正例 | 0.65 | **0.29** | 🔴 崩——风格差异压过真同构 |
| G↔D（同作者负例：推动者↔四因） | 负例 | 0.25 | **0.56** | 🔴 假相似——同作者风格拉高 |
| A↔E / C↔D / C↔F（同族正例） | 正例 | 1.00/0.80/0.65 | 0.75/0.53/0.42 | 🟡 全降——非机制层不匹配 |
| A↔C / B↔D / E↔F（负例） | 负例 | 0.20/0.30/0.25 | 0.28/0.06/0.18 | ✅ 保持 |

**诊断：加维度不提升区分度，反而引入"作者风格污染"。** 同作者卡共享：证据写作风格（Aristotle 堆原文+历史，Ahrens 堆案例+数据）、理论连接习惯（都连 EGS）、反例写法（Aristotle 全"框架内消化"）。这些风格让同作者卡"假相似"、跨作者卡"假疏远"。

## 三、v0.3b 修正：结构维/风格维分离

结构维（主判）= 断言 + 机制（权重3.5）+ 反例类型；风格维（降权）= 前提+证据+连接。

**结果：G↔D 仍 0.68 假相似——元凶定位到"反例类型"特征本身。**
- G 反例=[assimilated]、D 反例=[assimilated] → 反例类型 jac=1.0
- 反例类型是**带作者偏置的结构**：亚里士多德所有卡都"框架内消化"（理论强硬），Ahrens 卡都"缺条件/低质量"（理论谦虚）——它既反映可证伪结构，又强烈聚类作者。

## 四、核心发现（本实验的真正产出）

**1. 特征选择 = 定义同构。** 合成报告裁决"不变量不是被发现的，是被定义的"——本次实验实测了这句话：选机制层，同构=机制同构（跨作者有效，A↔E 稳定 1.00）；选反例类型，同构=作者辩论风格同构（G↔D 假阳性）。**签名语言的每个特征都在悄悄定义"什么算同构"。**

**2. 层间存在"结构→风格"光谱**（本次实测）：

| 特征 | 性质 | 跨作者稳定性 | 用途 |
|---|---|---|---|
| 机制层（shape/steps/roles/edge） | **纯结构** | 高（A↔E=1.00 三轮稳定） | 检索主判 |
| 断言层（iv/dv/rel） | 弱结构 | 中 | 辅助 |
| 反例类型 | **带作者偏置的结构** | 低（同作者聚类） | 需作者归一化后用 |
| 前提/证据/连接 | 风格噪音 | 低 | 剔除（仅做分歧检测） |

**3. 跨域同构检索的正确分层**：机制层主判（跨作者真同构）→ 反例层做作者归一化后的二次校验（可证伪结构一致性）→ 风格层不参与相似度。**"风格分歧"反而是跨域远亲信号**（结构像+风格不像 = 表面完全不同的真同构候选）。

**4. 对回测集设计的直接影响**：回测集真值对必须**跨作者埋**（否则作者偏置会污染校准）；反例类型特征需要作者归一化（同作者内反例差异才是信号）。

## 五、结论（方向性）

- 签名语言 v0.3 全维度方案**不可用**（作者污染），v0.3b 结构/风格分离**部分可用**，机制层主判方案（v0.3c）待回测集上验证。
- 本次实验的净产出：**实测出签名特征的结构-风格光谱 + 作者偏置问题**——这是回测集（S1）设计前必须知道的，否则回测集本身会被污染。
- 与 v0.2 一致：机制层（级联/汇聚/步骤）是跨作者最稳的结构特征，比喻引擎的"结构签名"以机制层为核心的方向不变。

## 六、护栏定义修正（GPT 外脑对齐，2026-08-30 晚）

原表述"差异护栏 = 投影丢失信息的逆运算"——**过度表述，撤回**。真正的逆运算不可能（无法从"堵塞→下游衰竭"唯一恢复政策机制/时间尺度/主体/反馈/可逆性/药理过程）。修正为：

> **差异护栏 = 对投影所丢失的、且可能导致误用的关键维度进行显式声明。**
> 映射表 = 保留下来的结构；护栏 = 主动声明最危险的丢失维度。
