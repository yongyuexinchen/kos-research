# 欲望机器的死亡约束：一个原创理论

> **死亡哲学系列（6 集）——EGS 理论宇宙的地基层**
>
> 本系列是作者原创理论"存在担保系统（EGS）"的地基层。EGS 系列讲"社会这台机器怎么坏"，本系列讲**"人这个物种为什么需要机器"**——死亡压力如何编码欲望、塑造制度、定义"正常"。
>
> 理论谱系：本系列不是弗洛伊德死亡驱力的翻版，而是**德勒兹-瓜塔里欲望生产理论的推进**——加了一个约束变量（死亡压力）。
>

## 理论主轴（每集都回到这里）

```
基本公理：
  欲望机器不断生产现实，但现实结构为了维持自身连续性，
  会在死亡压力下对欲望进行编码；
  当编码无法处理新的死亡压力时，逃逸线产生。

公式链：
  欲望生产 → 社会编码 → 正常行为 → 死亡压力增加
  → 编码失效 → 逃逸线出现 → 新结构形成

关键概念：死亡不是心理本能，是结构边界条件——
  "任何持续存在的系统，都必须生产出处理自身终结性的机制"
```
