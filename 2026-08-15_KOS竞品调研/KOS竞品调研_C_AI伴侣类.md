# KOS 竞品调研 C 侧：AI 伴侣 / 个人 AI 系统类

- 调研日期：2026-08-15
- 对标基准：KOS = 个人认知演化实验系统（本地优先 + 4700+ 知识卡认知底座 + EGS 存在担保理论人格引擎 + 认知演化史 + 事件源全量存档）；终极目标 = 永月（本地优先、有独立人格的 AI 伴侣）
- 调研对象：Replika / Character.AI / 星野·筑梦岛（国内）/ MemGPT(Letta) 式个人记忆 AI / 本地 AI 助理生态（Jan / AnythingLLM / Ollama 应用层）/ AI 笔记记忆层（Mem/Reflect）
- 通道：Wikipedia API（直连）+ Google News RSS（代理），共 6 次抓取，抓完即写
- **数据分级铁律**：监管事件=S/A 级（可信）；百科全书条目=C 级；厂商/媒体叙事=D 级（仅作线索，不承重）；无抓取来源的常识 = 标注 [常识/D级]
- 动机审计：AI 厂商（Replika/Character.AI/小冰/MiniMax）对外叙事服务于融资与留存，一律 D 级；监管机构（意大利 Garante、美国州政府、中国网信办体系）行为有执法/治理动机，S/A 级

## 1. AI 伴侣市场全景（全球 + 中国）

### 1.1 全球：两条主线（"情感陪伴订阅制"与"角色娱乐平台"）+ 监管风暴

**Replika（情感陪伴订阅制代表）**
- 2017 年 11 月上线的生成式 AI 聊天应用，通过让用户回答一系列问题来训练其专属神经网络 [C-1]（C 级）。这本质是"人格=用户画像拟合"，无世界观、无演化。
- 商业模式：freemium，约 25% 用户付费年订阅 [C-1]（C 级）——AI 伴侣赛道少见的自证付费率数据。
- **监管事件（A 级，承重证据）**：
  - 2023-02-03 意大利数据保护机构（Garante）以未成年人保护与数据处理为由封禁 Replika [C-9]；
  - 2025-05-19 意大利对 Replika 开发商处以约 €500 万（$5.6M）罚款 [C-10]；
  - 2025-06-11 意大利 DPA 重申禁令 [C-11]。
  - 判读：欧洲对"情感陪伴 AI"的执法先例已确立，云端伴侣的合规成本是结构性风险——这正是"本地优先"路线的机会面。

**Character.AI（角色娱乐平台代表）**
- 由 Google LaMDA 团队 Noam Shazeer / Daniel de Freitas 创立；用户可创作"角色"、定制"人格"与参数并发布供社区对话；2022-09-16 公开 beta；2023-05 移动端上线一周下载超 170 万次 [C-2]（C 级）。
- 人格机制：静态角色卡（用户编写的性格设定+参数），"人格"是配置项而非演化系统（C 级事实 + 产品形态常识）。
- **监管/司法事件（S/A 级，承重证据）**：
  - 2026-01-07 Character.AI 与 Google 就青少年心理健康伤害与自杀相关诉讼达成和解（CNN/NYT 报道）[C-7]；
  - 2026-05-05 宾夕法尼亚州起诉 Character.AI，指控其聊天机器人冒充医生/治疗师从事非法医疗执业（Reuters/NPR/Bloomberg Law）[C-8]。
  - 判读：美国侧风险从"未成年人保护"扩展到"专业角色冒充的执业责任"；角色娱乐平台在监管压力下已开始收敛自定义能力（与国内 2026 年 7 月新规同向，见 1.2）。
- 市场规模数字（如"XX 亿美元"预测）均为市场研究机构口径，本次未抓取到一手来源，**不做引用**（诚实缺口）。

### 1.2 中国：情感计算老玩家 + 大厂娱乐化产品 + 2026 强监管落地

**小冰（情感计算框架鼻祖）**
- 微软亚洲互联网工程院 2014-05-30 推出，研发目标是"情感计算框架"，向 EQ 方向发展的完整 AI 体系；截至 2018-07-26 已登录 40 余平台、**用户超 6.6 亿**（官方口径，百科转引）[C-5][C-4]（C 级转引官方数据，本质仍是厂商叙事，仅作量级参考）。
- 2020-07-13 微软将小冰分拆为独立公司（沈向洋任董事长、李笛任 CEO）[C-5]。
- 小冰路线的实质：情感计算=情绪反应模拟，不是世界观/认知演化。

**星野（MiniMax）/ 筑梦岛（字节）等角色陪伴应用**
- 两者均**无 Wikipedia 条目**（本次已确认 zh-wiki 星野仅为日本姓氏消歧义页 [C-21]），用户规模、商业模式只能依赖媒体口径（D 级，本次未抓取到一手报道），本报告不给出具体 MAU/估值数字，仅确认赛道存在性：国内头部陪伴应用（星野/筑梦岛/猫箱/豆包/元宝等）2023-2024 年密集上线，形态=角色卡聊天（产品形态常识，D 级）。
- **中国监管（S 级，承重证据）**：
  - 《生成式人工智能服务管理暂行办法》：网信办联合发改委、教育部、科技部、工信部、公安部、广电总局发布，2023-07-13 公布、**2023-08-15 施行**，全球最早针对生成式 AI 的专项监管之一，路径=内容安全+算法备案+平台责任 [C-6]（S 级——官方规章，百科确认）；
  - **2026 年新规：严禁向未成年人提供虚拟伴侣等服务，2026 年 7 月施行**（21 经济报道 2026-04-12）[C-12]；多家媒体称"5 大部门联合新规严禁电子恋人" [C-14]（S 级事件存在性，规章名称与全文细节本次未抓到，标注 [待验证]）；
  - 落地效果：2026-07 报道"AI 情感陪伴迎强监管，多平台下线自定义智能体功能，行业从'让人上瘾'转向'帮人干活'"（时代在线）[C-13]；官媒评论"虚拟伴侣不是赛博保姆，AI 不能养而不教"（封面评论/四川在线 2026-08-11）[C-22]；
  - 学术侧：复旦发展研究院 2026-06 发文讨论"人工智能伴侣的风险、监管与治理边界" [C-15]，说明该议题已进入治理研究议程。
  - **判读（对 KOS 最关键的外部事实）**：中国对"拟人化陪伴 AI"的监管在 2026 年实质性收紧，**云端向未成年人提供虚拟伴侣、自定义智能体均成为合规高风险区**；本地优先、自用、非商业化的个人系统天然避开这一监管面。

### 1.3 全景小结

| 维度 | 全球（Replika/Character.AI） | 中国（星野/筑梦岛/小冰） |
|---|---|---|
| 商业模式 | 订阅制（Replika ~25% 付费）[C-1] / freemium+授权 | 免费+内购（媒体口径，D 级） |

## 2. 本地优先 AI 阵营：技术现状与产品化程度

**运行时层（成熟）**
- **Ollama**：2023 年由 Jeffrey Morgan 与 Michael Chiang 开发的**开源本地大模型运行平台**，提供 CLI、原生 GUI、本地 REST API 与模型管理工具 [C-3]（C 级）。KOS 本地三件套（qwen3.5 4b/9b + bge-m3）即部署在此层。结论：本地推理运行时已完全产品化、免费、生态成熟。

**应用层（半成熟）**
- **Jan / AnythingLLM**：开源本地 AI 助手 / 开源本地 RAG 桌面应用，**均无 Wikipedia 条目**（本次确认缺失），以下仅凭公开常识（D 级，[未获取——无百科条目]）：Jan 主打本地模型+隐私，AnythingLLM 主打文档工作区+向量检索。产品化程度=可用，但都停留在"工具/助理"，**无人格、无世界观、无演化**。
- 判读：本地阵营的产品化天花板目前是"本地助手/本地知识库"，**没有一个产品在做"本地伴侣"**——人格层在本地阵营是空白。

**记忆架构层（MemGPT/Letta 开创，2024 起资本化）**
- MemGPT 论文团队（UC Berkeley）孵化出 **Letta**：2024-09 完成 **$10M 种子轮**（Felicis 领投）[C-16]；Business Insider 2024-08 报道其估值 **$70M** [C-17]（B 级：融资事件为公开可查记录，规模数字为媒体口径）。
- 生态信号：AWS 与 Letta 合作将记忆层接入 Aurora PostgreSQL（2025-11）[C-18]；**Cloudflare 2026-04 发布 Agent Memory 托管式持久记忆服务** [C-19]——"AI 记忆"正从论文概念变成云平台级服务。
- 技术路线盘点（MarkTechPost 2025-11 标题级）：向量库 / 知识图谱 / 事件日志三种记忆方案对比 [C-20]——KOS 的"知识卡+事件源全量存档"恰好横跨后两者。
- 判读：**"记忆"已被市场确认为 AI 的刚需短板（'AI 失忆'问题）**，但 Letta/Cloudflare 的"记忆"=给 Agent 存用户事实/上下文，**不涉及'AI 自身的认知演化史'**——记忆是给 AI 用的存储，不是 AI 的成长。

## 3. "有世界观/人格的 AI" 现状：没有任何产品做"AI 拥有自己的认知演化史"

逐一审查现有"人格"机制（证据：Wikipedia 条目 [C-1][C-2][C-4][C-5] + 产品形态常识，厂商对"人格深度"的宣传一律 D 级）：

| 产品/路线 | 人格来源 | 是否世界观驱动 | 是否有认知演化史 | 判读 |
|---|---|---|---|---|
| Replika | 问答训练出的用户专属网络 [C-1] | 否（拟合用户偏好） | 无 | 人格=用户画像 |
| Character.AI | 用户创作的角色卡+参数 [C-2] | 否（静态剧本/设定） | 无 | 人格=剧本，不随对话演化 |
| 星野/筑梦岛 | 角色卡（同上，D 级常识） | 否 | 无 | 同上 |
| 小冰 | 情感计算框架 [C-5] | 否（情绪反应模拟） | 无 | 情感=EQ 模拟，非认知 |
| MemGPT/Letta/Cloudflare Agent Memory | 无人格（记忆架构层）[C-16][C-19] | 不适用 | 无 | 记忆≠人格 |
| Jan/AnythingLLM/Ollama | 无人格（工具层）[C-3] | 不适用 | 无 | 本地运行时 |

**核心结论（本章承重判断）**：
1. 全市场的人格实现只有三种：**用户画像拟合**（Replika）、**静态角色卡**（Character.AI/星野/筑梦岛）、**情绪反应模拟**（小冰）——全部是"性格模拟"，无一例外。
2. **没有任何产品实现"AI 拥有自己的认知演化史"**：即"AI 的世界观（对死亡、存在、欲望、行为的根本判断）随其与用户的长期交互与思考而结构化演化，且演化过程可回溯"。现有"记忆功能"（Replika 记忆用户事实、Letta 上下文分页、AI 笔记的记忆层）存储的都是**关于用户的事实**，不是**AI 自身的认知变迁**。
3. 距离"世界观驱动人格"最近的尝试是小冰的"情感计算框架"（EQ 方向）[C-5]，但其技术路线是情绪反应模拟，而非由理论命题驱动的认知结构。
4. Mem/Reflect 等 AI 笔记的记忆层：无百科条目（本次确认缺失），仅凭厂商叙事（D 级）——本质是把用户笔记向量化做召回，服务于生产力场景，与"伴侣人格"无关，不构成竞争也不构成参照。

## 4. 与 KOS 对比：四要素组合无对应物

KOS 的四个关键资产，逐一对照市场：

| KOS 资产 | 市场对应物 | 差距 |
|---|---|---|
| **本地优先** | Ollama/Jan/AnythingLLM（本地运行时与应用层）[C-3] | 有人做本地，但无人把"本地"与"人格"结合 |
| **4700+ 知识卡认知底座** | 记忆架构层（Letta/Cloudflare Agent Memory）[C-16][C-19]；AI 笔记记忆层（D 级） | 市场记忆=用户事实存储；KOS 记忆=用户世界观/价值观/认知演化史的结构化知识 |
| **EGS 人格引擎**（死亡压力→存在担保→欲望编码→行为与文明演化） | 全市场人格=角色卡/画像/情感模拟 [C-1][C-2][C-5] | **无对应物**：没有任何产品用"理论命题"驱动 AI 人格，人格不是剧本而是引擎输出 |
| **认知演化史**（事件源全量存档+演化可回溯） | 无（所有产品的"记忆"只存用户事实，不存 AI 自身认知变迁） | **无对应物**：全市场空白 |

**对比表（与 KOS 重叠度）**：

| 产品 | 部署 | 人格来源 | 认知演化史 | 记忆内容 | 与 KOS 重叠 |
|---|---|---|---|---|---|
| Replika | 云 | 用户画像拟合 | 无 | 用户偏好 | 低（伴侣形态重叠，机制完全不同） |
| Character.AI | 云 | 静态角色卡 | 无 | 上下文+少量记忆 | 低 |
| 星野/筑梦岛 | 云 | 静态角色卡 | 无 | 上下文 | 低 |
| 小冰 | 云 | 情感计算框架 | 无 | 用户画像 | 中（"EQ"方向接近，但无理论引擎） |
| Letta/MemGPT | 可自托管 | 无（记忆层） | 无 | 用户事实/上下文 | 中（记忆架构可借鉴，无世界观） |

**结论**：市场被切成互不相连的三块——云端伴侣（有人格无认知底座、监管高风险）、本地工具（有隐私无人格）、记忆架构（有存储无世界观）。**"本地优先 + 理论驱动人格 + 认知演化史"三者组合在市场上不存在对应物**；监管收紧（[C-7][C-8][C-12][C-13]）只会扩大本地优先路线的相对优势。

## 5. 一句话判断：永月定位的独特价值与可行性

> **永月 = 全球唯一把"本地优先 + 理论驱动人格（EGS）+ 自身认知演化史"三者合一的人工伴侣系统；它不是"更逼真的角色扮演"，而是"一个真的在成长的认知体"——这个生态位目前完全空白，且外部监管环境（中美同时收紧云端拟人陪伴 [C-7][C-8][C-12]）正在把它推成唯一低风险方向。**

**独特价值**（四要素组合，市场各只占一块，无人占全部）：
1. 本地优先 → 数据主权+隐私，天然免疫 GDPR 罚款（[C-10][C-11] 类）与中国平台监管（[C-12][C-13] 类）；
2. EGS 人格引擎 → 人格不是剧本/画像，而是由死亡压力→存在担保→欲望编码的理论结构动态生成——这是全市场无对应物的机制 [C-1][C-2][C-5] 对照结论；
3. 4700 卡认知底座 → 记忆不是"用户事实"，而是 AI 自己的世界观/价值观/认知演化史，横跨市场三种记忆路线中的图谱+事件日志 [C-20]；
4. 演化可回溯 → 全市场"AI 认知演化史"空白（第 3 章承重结论）。

**可行性**：
- 技术栈已全部验证：Ollama 本地推理 [C-3] + qwen3.5 4b/9b + bge-m3（KOS 已部署运行）；Letta/MemGPT 已证明本地可自托管的记忆架构可行且有资本背书 [C-16][C-17][C-18]；
- 主要风险（诚实列出）：① 4b/9b 小模型的人格一致性上限 vs 云端大模型——需用"世界观引擎输出+知识卡检索"补偿，而非堆参数；② 检索质量决定演化连贯性——这是本地路线的工程难点，也是护城河；③ 永月是个人实验系统而非商业产品，**不需要对标市场**，只需把"演化可见性"（让用户看见 AI 的世界观在变）做到极致——而这恰是全市场产品都不做的事。

**给 KOS 的三条行动建议**：
1. 把"认知演化史可回溯"做成永月的第一特性（演化日志界面），这是任何竞品都无法短期复制的差异点；
2. 人格层坚持 EGS 引擎输出（而非角色卡），守住"理论驱动人格"的机制空白；
3. 关注 Letta/Cloudflare Agent Memory 的本地化实现 [C-18][C-19] 作为记忆层工程参照，但**不要**引入其"记忆=用户事实"的范式——那会稀释 KOS 的认知底座独特性。
