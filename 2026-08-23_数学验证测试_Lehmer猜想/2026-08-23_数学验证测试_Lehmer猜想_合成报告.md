## 一、命题与形式化

**Lehmer 猜想（1947）**：∀m ∈ ℕ⁺，Ramanujan τ 函数 τ(m) ≠ 0

```
τ 定义：Δ(q) = q·Π_{k≥1}(1−q^k)^24 = Σ_{n≥1} τ(n)·q^n
判定条件：对 m = 1..N 逐项计算 τ(m)，检查全部非零
```

**学术状态**：开放（未证明）。验证记录：Lehmer 1947 到 2.15×10¹¹ → Serre 1973 到 10¹⁵ → Jordan-Kelly 1999 到 2.27×10¹⁶。

## 二、验证方法

| 通道 | 方法 | 作用 |
|---|---|---|
| 主通道 | 生成函数法：稀疏因子卷积（每因子 (1−q^k)^24 展开 25 项，numpy int64 向量化），N=2000 | 计算 τ(1..2000) |
| 校验通道 1 | 与 OEIS A000594 已知 τ(1..20) 对比 | **代码正确性门禁**（α bug 纪律：校验不过=不产生结论） |
| 校验通道 2 | Ramanujan 递推交叉验证：互素乘性 τ(mn)=τ(m)τ(n) + 素数幂递推 τ(p^{r+1})=τ(p)τ(p^r)−p^11·τ(p^{r−1}) | 独立方法确认 |

int64 约束：|τ(n)| ≤ 2n^5.5（Deligne 界），N=2000 时最大 ~3×10¹⁸ < int64 上限 ✓（实测 max=2.4×10¹⁸）。

## 三、验证结果

```
✅ 已知值校验：τ(1..20) 全部匹配 OEIS A000594
✅ 交叉验证：互素乘性 + 素数幂递推全部一致
✅ τ(1..2000) 全部非零 —— 数值支持 Lehmer 猜想
   τ(10)  = -115920     τ(100)  = 37534859200
   τ(1000)= -30328412970240000    |τ|max = 2406870243670360160
```

## 四、诚实分级

**🟡 数值支持（未证明）**

- 数值验证 ≠ 证明：即使 τ(1..2000) 全非零，Lehmer 猜想仍是开放问题
