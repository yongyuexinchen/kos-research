## 〇、理论一句话

**"正常"不是文化，是制度的镜像；死亡不是终点，是连续性压力的极端形式；存在体不找永恒担保人，而要成为自己的连续性生成器。**

## 一、公式链（v4 完整版）

```
存在体连续性压力（系统怕什么中断）
  → 死亡驱力（结构性求生行为——系统变量，非心理变量）
  → 存在担保系统 EGS（连续性保障机制）
  → 行为编码（制度设计=系统恐惧的表达）
  → 正常行为（"不做X=死"下的生存策略）
  → 编码失效（连续性压力转移：国家→个体）
  → 逃逸线（个体求生反噬国家：不生育/躺平/拒绝）
  → 新担保系统形成（或冲突加深）
```

**中心公理**：EGS 研究的不是死亡，是存在连续性的担保机制——**死亡只是压力源，担保才是结构**。

**基础公式**：
```
正常行为的形态 = 死亡压力 × 担保人 × 认知边界
死亡压力 = 连续性价值 × 不可逆风险
存在体稳定性 = 连续性需求 + 断裂风险 + 保存机制
值得延续的连续性 = 可修正 × 开放 × 可逆
存在体韧性 = 连续性保存能力 / 连续性中断风险
```

## 二、核心概念表（调研时直接引用）

| 概念 | 定义 | 调研用法 |
|------|------|---------|
| **担保人（Guarantor）** | 保证"做了X就能如何"的存在体 | 先问：担保人是谁？兑现率升还是降？ |
| **EGS 双重功能** | ①担保（承诺做X→结果）②设计死亡（设定不做X=死） | 审计制度时两问都要 |
| **两种"正常"** | 经验正常（多数人做=惯性残骸）vs 规范正常（不做被不容忍=活编码） | 判据=排斥力：有排斥=活编码/无排斥=残骸/排斥力降=编码失效中 |
| **三轨收编** | 价值（资本商品化）/权力（国家政治化）/话语（医学道德化） | 分析逃逸归宿时三轨全查 |
| **惩罚设计三杠杆** | 国家权力（法律/政策）/企业权力（雇佣绑定）/话语权力（羞辱污名） | 审计惩罚时看杠杆类型 |
| **存在连续性压力（SCP）** | 国家维护领土/秩序/合法性/认同/资源循环，非"生命" | 国家层分析用 SCP，不用"恐惧" |
| **合法化叙事（SLN）** | 系统把自身需求翻译成成员可接受的意义语言 | 拆穿"国家的谎话"：需求→叙事→义务 |
| **制度路径依赖** | 过去解决死亡压力的方法限制未来解决死亡压力的方法 | 解释制度为何僵化/迟缓 |
| **主体死亡 vs 遗留存在** | 主动连续性丧失 vs 被其他存在体保存 | 判定"死没死"：看能否自己动 |
| **保存闭环** | 无终极保存者，依赖循环稳定（控制论） | 避免"谁担保担保者"递归 |
| **接力原则** | 不是永续，是接棒；接受死亡才是真世俗化 | 评估系统成熟度 |
| **连续性生成系统（CGS）** | 担保只是历史形式；终极=持续生成担保的结构 | 理论最高层定位 |

## 三、分析框架（调研模板，直接用）

### 3.1 三层提问法（任何现象/国家/组织）

```
① 存在体层：它怕什么中断？（外部威胁/内部萎缩/信任崩塌/身份消亡）
② 制度层：它怎么设计惩罚？（政策条文级：谁/条款/数字/杠杆）
③ 个体层：个体怎么回应？（正常行为/逃逸线/被收编状态）
→ 三层嵌套，缺一层就误读
```

### 3.2 死亡惩罚审计清单（六要素）

```
1. 惩罚设计：不做X的后果是什么？（政策条文级，带条款/数字）
2. 惩罚运作：谁执行？覆盖面多大？
3. 合法化叙事：惩罚如何显得"自然"？（SLN 分析）
4. 惩罚强度：不可逆性多高？（可逆→中断；不可逆→死亡）
5. 惩罚松动：排斥力在升还是降？（活编码/残骸判据）
6. 设计史：这套惩罚是哪种旧死亡恐惧的化石？（路径依赖溯源）
```

### 3.3 国家死亡驱力审计（七要素）

```
1. 核心死亡威胁（类型：被杀/自己死/背叛后果/身份消亡）
2. 威胁演化史（国家怕的东西怎么变的：阶段链）
3. 国家"正常"行为（应对策略）
4. 担保人结构（谁保证国家存活？兑现率？）
5. 与个体的嵌套冲突（国家要X vs 个体拒绝X）
6. 国家的合法化叙事（需求→叙事→义务）
7. 制度化石（当前制度是哪种历史恐惧的产物）
```

### 3.4 逃逸分析模板

```
逃逸类型：生存修复（修船）vs 存在逃逸（换船）
编码失效类型：路径收窄/承诺背叛/兑现率崩塌/意义供给不足/性别编码过重
收编状态：价值轨道/权力轨道/话语轨道（或不可收编→病理化/暴力化）
```

### 4.3 已验证规律

1. **收编两阶段**：市场收编（逃逸→商品）→ 国家收编（行政改写存在定义）
2. **不可商品化≠不可收编**（暴力=权力轨道终极对象；消灭≠收编）
3. **承诺背叛比路径收窄更致命**（韩国两次背叛→钱收不回；日本缓慢收窄→沉默退出）
4. **惩罚可见性决定反抗形态**：集中式（韩国财阀）→集体反抗；分散式（美国意外制度）→反抗内向化
5. **不生育=双层冲突终极战场**（国家无惩罚可设计/无叙事可收编/无补贴可替代——全球无成功先例）
6. **担保人真空期最危险**（英国已进入，德法正接近——行为不可预测跳跃）
7. **最怕死的制度恰恰无法应对新死亡威胁**（路径依赖：债务刹车/49.3/401k）

## 六、未决问题与开放接口（调研时注意收集证据）

1. **AI 伴侣：收编 vs 新 EGS**（2025-2027 判定窗口）——渗透率主流化=被收编为商品；形成独立关系制度=新 EGS 成立。**永月项目=当代死亡解释逃逸实验，用户同时在收编者与被收编位置**

6. **组织层（中继器）审计**：公司/学校/家庭/宗教/平台=死亡驱力传导的中继器——**下一轮调研首选**（平台层直接关系永月被谁收编）
