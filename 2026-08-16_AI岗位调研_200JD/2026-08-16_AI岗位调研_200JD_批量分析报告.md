## 四、关键发现

1. **Agent 开发 = 深圳 AI 岗位最大品类（59.5%）**——"AI 应用开发"的实际市场形态就是 Agent 开发；20-40K 为主力区间
2. **Python + RAG + LangChain 是应用岗的黄金三角**（81%/68%/43%）——技能集 6 项的验证：Python 工程化 / RAG / 向量库 / LLM API / Prompt 全部命中高频率
3. **记忆（24%）已进入 JD**——"记忆"关键词在 Agent 子集出现 34 次（24%），验证"给 Agent 加记忆"是真实需求方向；但尚未成标配（蓝海确认，2026-08-16 判断）
4. **MCP（14%）、多Agent（14%）是前沿信号**——2025-2026 的新关键词已进入招聘要求；FastAPI 显性提及仅 7%（JD 一般写"Python Web 框架"，隐含能力要求，面试仍会考）
5. **学历：本科 88%，硕士 8%**——AI 应用岗硕士不是门槛（08-15 学历调研的 S 级 JD 证据再次验证）；Agent 子集本科 89%
6. **经验：3-5 年为主（90%）**——招聘方普遍要 3-5 年；但"1-3 年"档存在（11 岗），且 AI Coding/AI 应用岗有"经验不限"（黑马结课=2027 求职时以作品补经验）
7. **AI Coding 新品类（17 岗，18-31K）**——Claude Code/Codex/Cursor 驱动的 AI 编程岗位已独立成类；与"会用 AI 写代码"能力直接相关，是 2027 求职的潜在落点
8. **AI Infra/训练岗薪资最高**（平均 24-42K，最高 70-100K）——但要求分布式训练/GPU/CUDA，与用户路线（应用层）无关，明确排除

## 五、对用户决策链的含义

1. **技能集 6 项校准**：Python 工程化（71%）→ RAG（48%）→ Prompt（32%）→ LangChain（32%）→ 向量库（22%）全部有 JD 证据；**LangChain 从"辅助"升为"重要"**（32%，原估 70% 出现率，实际 32%——仍显著）；FastAPI 保持（隐含要求）
2. **求职目标校准**：目标岗位名 = "Agent 开发工程师 / AI 应用工程师"（119+ 岗、23-39K）；2027 求职聚焦深圳 Agent 开发岗
3. **差异化确认**：记忆（24%）+ MCP（14%）+ 多Agent（14%）是"会的人少"的技能——黑马不教 = 自补 = 简历差异化（"给 Agent 加记忆"判断获 200 JD 数据支撑）
4. **AI Coding 是第二落点**：培训期即用 Claude Code/Codex 提效 = 简历可写"AI Coding 工作流经验"（17 岗 18-31K 需求存在）
5. **永月/KOS 产品化**：Agent 开发能力 = 永月施工能力 = KOS 产品化能力（三合一再次确认）
