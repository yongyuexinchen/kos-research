# 35岁后路线规划 · 杠铃结构（2026-08-15 定稿）

> 决策人：本人（[年龄]，2026-08-16 入AI 开发培训）｜ 落盘日期：2026-08-15
> 性质：职业下半场路线设计（非调研）——基于 08-15 学历调研 + 08-12 非全/AI岗位调研 + 考研去留决策 + Agent 赛道判断合成
> 一句话：**稳定为底（雇佣线），空间为顶（产品期权），35岁是决策点不是危机点**

---

## 一、结构定义（杠铃）

```
稳定端（主轴 90%）：雇佣线——小厂/中厂 → 资深技术专家/技术负责人（技术+业务纵深）
空间端（期权 10%）：永月 POC + 垂直Agent/KOS商业化（晚上+周末+小额资金，不辞职不烧存款）
```

- **稳定端** = 现金流 + 保底 + 35岁后依然被市场要（作品护城河）
- **空间端** = 北极星 + 超额收益（做成了平滑过渡独立，做不成=做出来就好的作品，损失可控）
- **两者关系**：空间端不能影响稳定端（时间盒、不烧钱、不辞职）——损失有下限，收益无上限

## 二、为什么是杠铃（资产结构依据）

1. **[金额]存款 ÷ 月支出1000 ≈ 20年生存缓冲**——安全感已由资产提供，不需要用创业"搏"安全感
2. 创业是缺安全感者使用的杠杆；我们的处境是"稳定地活着 + 有余地做自己的事"
3. 终极目标（永月）不必以"创业成功"为前提——它可以先是"作品"，商业价值是超额回报
4. 学历调研结论：学历不是年龄保险（清华硕士被裁）；35岁危机的正解=让"产出>成本"可证明（作品/专家/业务纵深）——这正是稳定端的设计目标

## 三、时间线（2026-2034+）

```
2026.08-12   AI 开发培训（Python/FastAPI/RAG/Agent）
2027.01-06   求职——"有空间的雇佣"标准（见四）
2027-2030    稳定端爬升：助理→中级→资深
             └ 每份工作留下完整可展示项目（作品护城河）
2029-2031    空间端：永月 POC → MVP（时间盒制）
2031-2033    空间端验证：最小验证田（有人付费？真实需求？）
             └ 有苗头→评估加大投入；没苗头→永月回归"作品"属性
2033-2034    决策点：空间端成了→平滑过渡独立；没成→稳定端深耕
2034+        下半场：资深专家/技术负责人（保底态）或产品所有者（理想态）
```

## 四、稳定端设计（"有空间的雇佣"标准——生命线）

选公司三标准（缺一不可）：
1. **业务近**：离业务/用户近，能接触完整系统（非外包纯执行）
2. **自主空间**：有技术决策权/学习纵深（非大厂螺丝钉）
3. **成长性**：能积累可迁移资产（作品、知识、方法论、行业声誉）

禁忌：耗尽型公司（长期加班吃光晚上时间=温水煮死空间端）。

## 五、空间端设计（防舒适区侵蚀——唯一敌人）

1. **时间盒**：每周固定小时数做永月（雷打不动，哪怕1小时）
2. **作品纪律**：每份工作留下完整可展示项目（稳定端护城河，非公司kpi）
3. **定期评估**：每半年问一次"空间端有没有推进"——没有就砍别的补上

## 六、风险与预案

| 风险 | 概率判断 | 预案 |
|------|---------|------|
| 空间端产品失败 | 高（90%应用层出清） | 损失可控（时间+小钱）；稳定端毫发无损；永月=作品不亏 |
| 舒适区侵蚀空间端 | 中高 | 时间盒+定期评估（防御机制见五） |
| 行业变化（Agent出清2027-2028） | 中 | 已押存活层（记忆/垂直/本地/可靠性），不押中间层/套壳 |
| 35岁仍被裁（保底态被击穿） | 低-中 | 作品护城河+资深定位+20年缓冲=有选择的切换 |
| 身体（久坐/肛周复查） | 持续 | 复查保留；产品线不依赖体力=35岁后天然优势 |

## 八、v1.1 修正（2026-08-15 认知层/演化层推演后）

> 来源：KOS 五层校准（认知层 4 张 critical 卡 + 演化层 S1-S5 信号基线 + 考研分流转换卡）推演产出
> 推演全文：本次会话（2026-08-15 推演七维度）；本节省略链：为什么没做出永月 → 欲望熄火 → 参照点 → 主权红线

### 修正1：永月 POC 提前——第一块多米诺 🔴 最重要

- 原设计：永月 POC 2029 启动
- 修正：**第一个完整项目出现在AI 开发培训期（2026.08-12），哪怕是小 demo**——它是打破"为什么没做出永月"零产出循环的第一块多米诺
- 依据：失败模式卡（critical）——被动等教→依赖工具→零产出（"没画过一幅画"铁证）；失效条件=关键模块手敲+第一个完整项目产出；AI 开发培训=新兵营模式（有截止日期有反馈=爆发环境）
- 2029 POC 是正式启动，不是首次启动；AI 开发培训期项目=循环破裂预演

### 修正2："有空间的雇佣"升级为红线（不是偏好）

- 原设计：选公司三标准（业务近/自主空间/成长性）为建议
- 修正：**任一标准不满足即不入职；在职期间自主权丧失信号出现（连续数周纯执行无学习）即启动跳槽；薪资可让，主权不能让**
- 依据：核心创伤=失去主权（Core）；部队实证——新兵营（自主+反馈）→爆发，下连队（被安排）→摆烂。耗尽型公司会触发摆烂→简历损伤→35岁前被提前淘汰

### 修正3：决策指标预写（仪表盘决策）

- 原设计：2033-2034 决策点"看情况"
- 修正：**空间端验证只看一个信号——有没有人付费**。有→评估加大投入；无→永月回归作品属性，稳定端深耕。指标现在写死（转换卡模式），届时查仪表盘不赌感觉
- 依据：参照点管理失败史（恋爱熄火：参照点满分→现实输给想象）——35岁凭感觉决策会两头踩雷（恐慌跳槽/自我否定）

### 认知层预警（三机制，执行期监控）

| 机制 | 触发信号 | 防御 |
|------|---------|------|
| 为什么没做出永月循环 | 2027-2029 空间端无产出（又回到"等AI喂"） | AI 开发培训期第一个项目=破裂点；关键模块手敲纪律 |
| 欲望熄火（实现即熄火） | 永月 POC 做出来"没感觉" | 过程化验收（能对话/有记忆/人格稳定）；作品无终点=跳舞无熄火点；她不是全部（永月的希望卡） |
| 参照点焦虑（看别人读研毕业） | 2027-2029 学历焦虑复发 | 考研逻辑链环10（2026≠2029，门没关）；35岁不是故事结束（建设者叙事） |

### 体系侧联动

- 考研分流转换卡 2026-08-15 换锚：trigger=第一个完整AI项目+2027入职成功；S1 首验点=2027 求职结果 vs 逻辑链预测（小厂优先/20-30K 区间）
- S3 行动转化率恢复点：2027.01 入职成功→KOS 恢复常规巡检（防"冲刺模式"无痛变"躺平模式"）
