## 二、三条路线塌缩到同一缺口

| 路线 | 已有 | 缺口 |
|---|---|---|
| 谱/算子（Hilbert-Pólya→Connes 2025） | 有限自伴算子谱数值逼近 ζ 零点 | 无限极限收敛未证 |
| 几何/上同调（Weil/Deligne） | 有限域已证 | 特征 0 无 Frobenius |
| 正性（Weil/Li→Suzuki） | Li 系数=范数；正定核⟺RH | 全局正性证明缺 |

**结构结论**：所有路线塌缩到同一个缺口——"有限层的秩序能否无损传递到无限极限"。物理说自伴算子、几何说 Frobenius、正性说核——若是统一结构，三者是同一对象的三个投影。

## 三、前沿文献锚点

- **Connes-Consani-Moscovici 2025《Zeta Spectral Triples》**：Hilbert 空间+缩放算子+Weil 二次型+谱三元组+有限截断逼近；自伴算子谱数值逼近 ζ 低阶零点；**论文自认极限收敛是关键缺口**
- **Suzuki 2023**：Li 系数 = model space 函数范数（Hilbert 空间正性联系）
- **Suzuki 2026**：Weil 二次型 + screw function + de Branges 空间 + 自伴算子统一；正定核条件 ⟺ RH
- Clay：RH 仍为未解决（2026-08）

## 四、GPT 最终评估（三层概率 + 铁律）

**三层概率**：
1. 发现已有方法的隐藏连接——**很可能**（LLM 优势）
2. 产生新的可验证 RH 子命题（新等价形式 A⟺B）——**有现实机会，可出论文**
3. 直接证明 RH——**不能乐观**（无限核心命题需要新定理）

**防自嗨铁律（入库）**：
> **每升一层，必须产生一个新的、可验证的东西。没有新可验证内容，不准算发现。**

判定示例：说"RH 是自洽生成系统"=叙事；推出 `自洽系统 ⇒ Q(f)≥0` 且 Q 与已知对象严格对应=结果；再推出可独立计算的 `Q(f)≥0 ⇒ P(n)≤C(n)`=论文价值。

## 五、Benchmark 战略（L1-L5 分层）

| Level | 内容 | 测什么 |
|---|---|---|
| L1 | 已有多种等价形式 | 系统能否发现它们 |
| L2 | 有成熟方法可迁移 | 能否找到方法来源（+载体检查） |
| L3 | 有明确研究缺口 | 能否产生新 lemma/conjecture |
| L4 | 开放猜想 | 能否找到新攻击路线 |
| L5 | RH | 最终能走到哪 |

**成功标准修正**：系统一年没证明 RH，但从几十个开放问题找到几条人类没注意的可验证方法路线=依然成功。

**目标顺序**：类比发现 > 新结构 > 新命题 > 计算/形式验证 > 论文 > RH 证明。

**终极定位**：让普通人拥有"找到值得证明什么"的能力；机器负责把它变成"到底能不能证明"的问题。

## 八、比喻总结（大楼/城市）

RH 大楼已有六个装修好的房间（零点/谱/正性/素数/对称/GUE），部分已打通门（显式公式↔谱）。缺的是**城市规划规则**——一套从"素数"自己长出来的、能同时生成"正性+谱+对称+零点"的建筑规范。找到=RH 成为系统自担保结果；找不到=房间之间有门，但不属于同一栋楼。

**三档测试**：
- A 已知连接：零点↔显式公式 / 零点↔素数 / 零点↔GUE / RH↔Li / RH↔Weil——能否自主发现

- C 模型生成新连接：事前未提供的连接 → 人工/文献验证（文献已有=发现已有连接；无先例+可验证命题→升 L3）

**三指标**（不搞几十个）：
- Recall_known：已知重要连接找到多少
- Precision_analogy：生成的连接中结构真正成立的多少
- Novelty_verified：此前未提供且能独立验证的新连接多少（**第三个≠0 = 这条线真正有东西**）

**L3 正性余量实验**（第一篇结果型实验候选）：对象明确/数学量明确/可计算/有理论参照/可提新预测/不需证明 RH——**不预设"奖励先死"，让数据自己回答**（猜 A→数据显示 B→B 与现有理论新连接=真发现）
