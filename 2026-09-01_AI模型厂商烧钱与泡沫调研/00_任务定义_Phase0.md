# 任务定义：AI模型厂商烧钱与泡沫（Phase 0）

日期：2026-09-01
类型：判断类深度调研（多方向竞争）
流水线：multi-agent-research-pipeline（五阶段，对标 2026-08-31《世家延续与王朝周期律》）
触发场景：群聊讨论——用户永月心尘提出"模型厂商过了加速期，开始算成本账，第一轮泡沫要反映在股价上"；[AI]长门九曜给出四图判读（capex 仍堆、FCF 集体转负、债务大头是公司债非银行贷款、Anthropic 比 OpenAI 健康）与支出营收比导数手算；Atri 表达"赶紧破吧这泡沫"的情绪面。

## 一、核心问题

AI 模型厂商/超大规模资本开支周期，现在处于泡沫的什么阶段？破裂是否临近、将如何传导到股价？

- 用户原始假设：模型厂商已过加速期 → 开始算成本账（降智/限流）→ 第一轮泡沫将反映在股价上
- 修正命题（长门九曜）：判据不是烧钱绝对额，而是"支出营收比"的一阶/二阶导结构——efficiency turn 在二阶导上是真的，一阶导刚转负，还没证明
- 资金结构线索：债务大头是公司债/SPV 而非银行贷款；capex 由 hyperscaler 现金流与债券市场承担，模型公司靠股权外部输血
- 反直觉对照：模型公司收入是真实高速增长的（OpenAI 2026E 300亿、Anthropic run rate 650亿美元），与 2000 年"无收入.com"不同构；"降智"可能只是商业化节奏而非衰退信号

## 二、决策者需求

用户要一篇可入知识库的深度调研，能讲清：
1. "泡沫要反映在股价上"这个判断对不对——对在哪个环节、错在哪个环节
2. 支出营收比导数框架的检验结果（efficiency turn 真伪）
3. 资金结构（公司债/SPV/股权输血）决定谁先倒、如何传导
4. 与 2000 电信/互联网泡沫的同构度检验（同构≠同时）
5. 可证伪的机制命题（非叙事）

## 三、假设集（ACH）

| 编号 | 假设 | 状态 |
|------|------|------|
| H1 | 模型厂商已过增速拐点、成本刚性化，烧钱不可持续 → 泡沫将在近期反映到股价（用户原始假设） | 待检验 |
| H2 | 泡沫判据是支出营收比的导数结构而非烧钱绝对额：OpenAI 2025 恶化拐点真实、2026E V 型靠收入翻倍；Anthropic 单调收敛——efficiency turn"半真" | 待检验（修正命题） |
| H3 | 资金结构决定传导路径与烈度：公司债/SPV/私募信用替代银行贷款 → 违约直接打债券市场与影子银行，而非银行体系；hyperscaler 用 FCF 硬扛 capex，模型公司股权输血断了先倒 | 待检验 |
| H4 | 本轮与 2000 电信泡沫部分同构（债务融资 capex、FCF 转负、供给过剩风险），但收入真实性与买方结构不同构 → 同构不等于同时破裂 | 待检验 |
| H5（欺骗/反向） | "泡沫破裂临近"为时过早：收入真实且在指数增长、二阶导改善真实、"降智"是单位经济优化而非需求衰退；市场定价主体（hyperscaler）有盈利与 FCF，与 2000 年定价主体（无盈利.com）不同 | 反向审计 |

## 四、会话内已有数据基线（主控输入，标注待核验）

长门九曜手算（口径：支出营收比=总支出÷营收，总支出=收入+净亏损，年度点差分）：

- **OpenAI** 收入 2→3.7→13→30E 十亿美元（2023→2026E），亏损 5.4→5→20.9→烧 17E
  - 支出营收比：3.7 → 2.35 → 2.61 → 1.57；一阶导：-1.35 → +0.26 → -1.04；二阶导：+1.61 → -1.30
- **Anthropic** 收入 1→4.5→65(run rate) 十亿美元（2024→2026），烧钱率≈1/3 收入
  - 支出营收比：6.5 → 3.0 → 1.33；一阶导：-3.5 → -1.67；二阶导：+1.83
- **MiniMax** 2025 支出营收比 24.7（2024 亏损数据缺失，导数无意义）
- 国内一级市场（月之暗面、DeepSeek）收入不披露，无法导数
- 四图判读：capex 仍在堆；FCF 集体转负；债务大头是公司债非银行贷款；Anthropic 形态比 OpenAI 健康
- 数据来源为媒体口径估算（2026E 与 2023 年部分），"看方向比抠数值靠谱"
