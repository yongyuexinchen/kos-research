## 二、核心架构差异化（五家专精记忆的）

### Mem0（63k，通用记忆层王者）
- 架构：**提取→存储→检索**三层流水线——对话/文本 → LLM 提取记忆 → 写入向量库/图库 → 检索注入上下文
- 特性：多后端（Qdrant/Chroma/pgvector/Milvus + 图数据库）、多 LLM、增量更新（只存变化）
- 商业模式：开源 SDK（Apache）+ Mem0 Cloud 托管 + 企业版
- 评价：生态最全、采用最广；但"通用记忆层"本身无垂直差异化

### Letta / MemGPT（24k，记忆分层先锋）
- 架构：**记忆分页 + 虚拟上下文管理**——把记忆当"操作系统内存"按需换页；核心记忆（系统提示）+ 记忆块（sleep-time 固化）
- 差异化：记忆按"重要度"自动换入换出，上下文窗口不膨胀
- 商业模式：开源平台 + 托管云
- 评价：架构最深（记忆分层哲学），KOS"懒加载知识卡"的灵感来源

### Graphiti + Zep（30k+4.8k，时序知识图谱）
- 架构：**时序知识图谱（Temporal KG）**——实体/关系带时间戳；双临时性边（episodic 事件记忆 + semantic 语义记忆）
- 差异化：**时间维度**是最大特色——"上周你说过 X，这周改口了"这类变化可追踪（≈ KOS 判断版本日志/苗床层的图谱化）
- 商业模式：Graphiti 开源（Apache）+ Zep Cloud 托管
- 评价：技术差异化最强，企业向；与 KOS 演化层语义最接近

### Cognee（30k，KG+RAG 平台）
- 架构：知识图谱 + RAG + 记忆一体化平台；数据管道（摄取→图谱→检索）
- 商业模式：开源 + 企业版
- 评价：平台化，功能全但重

### Basic Memory（3.7k，AGPL ⚠️）
- 架构：Obsidian 插件 + 本地 Markdown 记忆——对话记忆存本地文件，AI 可检索
- 评价：**与 KOS 场景最像**（个人知识库+AI 记忆，本地优先）；但 **AGPL 许可=不可闭源商业化**（教训：选底座看许可）
- 验证价值：证明"本地优先个人记忆"有真实需求（Obsidian 生态验证）

### 框架内嵌（LangGraph checkpoint / LlamaIndex memory）
- 定位：框架的持久化模块，非独立记忆产品；MIT 许可
- 评价：做底座可，但无独立商业化空间（依附框架生态）

## 四、结论：哪个值得商业化

### 判断 1：记忆框架本身 = 红海中间层，不值得押（符合"勿押中间层/套壳"）

- Mem0/Letta/Graphiti/Cognee 四家已全部完成"开源 + 托管云"商业模式闭环——**记忆框架本身是 2025-2026 的红海**，大厂（阿里 AgentScope）与创业公司（Mem0/Letta/Zep）在打
- 你 200 JD 调研的"记忆 24%"是需求信号，但供给侧的通用层已经饱和——**做通用记忆框架 = 第三梯队进红海**

### 判断 2：值得商业化的是"垂直记忆"——带认知逻辑的记忆（你的差异化）

- **通用记忆层（Mem0 们）记的是"事实"**（对话内容/偏好）
- **垂直记忆记的是"认知演化"**（判断为什么变/苗头/版本日志）——这正是 KOS 的演化状态机 + 苗床层 + confidence_history，**框架给不了**
- 商业化形态：不是"又一个记忆框架"，而是"**带人格与认知演化的记忆系统**"（永月/AI 伴侣/个人认知助手）——垂直场景（伴侣/交易者/研究者）里的记忆，蓝海且需求侧已验证（验证田=交易者决策日志）

### 判断 3：选型建议（做底座）

| 场景 | 选型 | 理由 |
|------|------|------|
| 通用底座（快速起步） | **Mem0** | 63k 生态最全、Apache、本地可部署（永月本地优先铁律满足） |
| 要时间维度（记忆演化） | **Graphiti** | 时序知识图谱 = KOS 判断版本日志的图谱化对应 |
| 最省事 | **改造 Hermes 记忆系统** | 本机已有（memory/session_search/skills=长期/情景/程序三层），零成本 |
| 参考学习 | Letta | 记忆分层/虚拟上下文 = KOS 知识卡懒加载的架构蓝本 |
| ❌ 排除 | Basic Memory | AGPL 许可锁死商业化（教训存档） |

### 判断 4：许可纪律（本次调研的硬教训）

- 商业化底座只选 **Apache-2.0 / MIT**；AGPL（Basic Memory）不可闭源商用
- 选型时第一步查 license，再谈架构

## 五、对永月/KOS 的含义

1. **永月记忆层底座 = Mem0（或改造 Hermes）+ Graphiti 时序思路**——不重复造轮子，差异化全押在 KOS 认知逻辑
2. **"记忆框架"是中间层，不押；"垂直记忆"是存活层，押**——200 JD（需求 24%）+ 本报告（供给红海）双确认
3. **拆框架清单更新**：Hermes（本机）→ Mem0（提取-存储-检索三层）→ Letta（记忆分层）→ Graphiti（时序图谱）——拆完吸收，进 KOS 产品化设计思考.md
4. 商业化时间线不变：培训期技能集（底座能力）→ 2027 入职后验证田 → 垂直记忆产品化（2031-2033 决策点）
