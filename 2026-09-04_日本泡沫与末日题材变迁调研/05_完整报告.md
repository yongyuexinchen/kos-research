## 1. 执行摘要

**核心问题**：日本泡沫经济期（1985—1991）与破灭后（1992—2010年代），末日/灾难题材影视文娱作品的数量与题材如何变化？

**定稿结论**：

```
┌────────────────────────────────────────────────────────────────┐
│ 题材（稳健结论，置信度：中）                                     │
│   末日"威胁来源"发生趋势性内化迁移：                              │
│   外部实体（核战/怪兽/天灾）→ 都市社会内部崩溃+赛博朋克（泡沫期）  │
│   → 精神末世/内心崩溃（1990s 破灭后）                            │
│   → 封闭社会的生存压迫/种族冲突末世（2000s—2010s）               │
│                                                                │
│ 数量（结论被审查修正，置信度：低）                                │
│   代表作密度在泡沫期与 1990s 无显著上升证据（抽样 4 部 vs 3 部）；  │
│   真正上升的是 2000s 后单体 IP 的商业体量与跨代持久度，            │
│   而非"作品数量爆发"。精确计数须依赖系统数据库，本轮缺失。          │
│                                                                │
│ 结构解释（理论假设，L3/L4，非事实）                              │
│   末题创作 = 死亡焦虑的文化处理机制；                             │
│   "经济永续增长"意义神话失效 ⇒ 死亡焦虑溢出 ⇒                     │
│   末日题材从"击退外部敌人"转为"在崩溃中重寻个体意义"。             │
└────────────────────────────────────────────────────────────────┘
```

**一句话**：泡沫破灭最显著的文化后果不是末日作品"变多"，而是末日想象"由外转内"——威胁从哥斯拉式的可命名外部敌人，内化为 EVA 式的精神/制度性崩溃。

## 2. 调研结论（A/B 观点并列，注明来源）

### 2.1 数量变化（本轮最弱结论，已被审查降级）

| 来源 | 观点 |
|------|------|
| Agent A | 泡沫期核验代表作 4 部（1984 哥斯拉重启 / 1982-90 AKIRA 漫画 / 1988 AKIRA 剧场版 / 1989 攻壳漫画）[A1][A5][A6][A7]；1990s 核验 3 部（1995 攻壳剧场版 / 1995 EVA / 1997 EVA 剧场版）[A3][A7]。**如实声明无精确计数** |
| Agent B | 未独立统计数量，以相变点框架间接支撑 1995 为拐点 [B5] |
| 审查修正（P0-2） | A 原始"泡沫期 ≲ 1990s"的上升公式与自身清单矛盾（4 ≥ 3），已删除。**代表作密度在两期相当，无"数量爆发"证据** |

**定稿数量判断**：

```
D(泡沫期: 核验4部) ≈ D(1990s: 核验3部)  —— 代表作密度相当，无显著数量上升
真正上升的是 IP 持久度与商业体量：
  · 哥斯拉系列 38 部，跨 60 余年反复再生产 [A5]
  · 《进击的巨人》世界累计发行破亿册（2009 起连载）[A4]
  · EVA 衍生品截至 2007 超 1500 亿日元 [A3]
```

> 方法论声明（不可省略）：本结论基于**代表作抽样密度**，非官方精确统计。维基词条未提供逐年/逐年代统计。精确的"作品数量变化"需依赖电影数据库（映画.com / IMDb / 日本动画数据库）系统抓取，属遗留项。

### 2.2 题材变化（本轮最稳健结论）

| 阶段 | 威胁来源 | 代表 | 来源 |
|------|---------|------|------|
| 1950s—1970s（前史） | 外部客观灾难：核/怪兽/天灾 | 哥斯拉 1954、日本沉没 1973 | [A2][A5] |
| 1980s（泡沫期） | 都市社会内部崩溃 + 超能力失控 + 赛博朋克 | AKIRA 1988、攻壳 1989 | [A6][A7] |
| 1990s（破灭后） | 精神末世 / 内心崩溃 / 制度性缺失 | EVA 1995、攻壳剧场版 1995 | [A3][A7] |
| 2000s—2010s | 封闭社会生存压迫 / 种族冲突长期末世 | 日本沉没重拍 2006、进击 2009/2013 | [A2][A4] |

**学术线索**（L4，非铁律）：Susan J. Napier 将 AKIRA 反复的大爆炸意象与广岛/长崎原爆记忆、冷战焦虑联系，主张影片把灾害处理为"可复发的事物、而非单一历史事件" [A6]；Thomas Lamarre（破坏是循环性的）、Le Blanc & Odell（政府权力破碎被动）[A6]。

**定稿题材判断**：

```
威胁来源轴（趋势性迁移，非系统性绝对化）：
外部核战/怪兽/天灾 → 都市社会内部+赛博朋克 → 精神末世/内心崩溃
→ 封闭社会生存末世。存在持续反向母题（进击的巨人外部巨人、
哥斯拉系列延续），故表述为"趋势"而非"系统/绝对"转移。
```

### 2.3 成因机制（A/B 互补）

- A 侧重"原爆记忆的延续性"（Napier 论 AKIRA 与广岛长崎）[A6]
- B 侧重"意义神话失效后焦虑溢出"（Becker 不朽工程机制）[B1]
- **合并定稿**：原爆核创伤为底层素材 → 泡沫破灭+1995+2011 事件链为触发 → Becker"文化世界观失效"为机制。此为**理论解释假设（L3/L4）**，非已证实事实。

## 4. death_drive 维度（人文体系必带）

| 三问 | 定稿 |
|------|------|
| ①生存主体 | 意义层（"经济永续增长"的世界观神话）为主，文明层（列岛存续）为辅；非个体/家族/组织层 |
| ②死亡信号 | 三种安全神话依次死亡：1991 泡沫破灭（经济增长）→ 1995 阪神+奥姆（日常安全）→ 2011 震灾+福岛（科技安全）。注：阪神/2011 精确日期本轮未核验，标 [TV] |
| ③核心问题 | **日本社会害怕"意义死亡+秩序死亡+文明连续性死亡"，因此反复生产末日叙事**——在作品中预演死亡、重获控制感，是文化世界观（不朽工程）失效后的自救机制，非病态 |

理论锚点：Ernest Becker《The Denial of Death》(1973)——文化+自尊=人类否认死亡的核心机制。**来源为维基二手转述，正文按 L3/L4 理论假设使用，非铁律。**

## 5. 相变点结论

```
1995（阪神大地震 + 奥姆真理教地铁沙林事件）= 题材"临界区间"代表性起点，非精确时点。
  阪神 = 工程/自然防线可崩 → 科技安全神话前兆性死亡 [TV]
  奥姆 = 社会内部可自生末日型暴力 → 日常安全神话死亡 [B5]
  末日威胁从此不再来自外部，而来自系统/关系/心理内部。
常态区间（渐变）：1991—1994；临界区间（断裂）：1995—1997（EVA→新范式确立）。
```

**可观测信号（待采集·预注册，非已有证据）**：①非正规雇佣率（终身雇佣瓦解速度）②媒体"安全神话"修辞出现/破灭频次 ③ACGN 末世作品占比 + "有外部敌人 vs 无外部敌人"设定比（需先定义"末世作品"分母的操作性界定）。
