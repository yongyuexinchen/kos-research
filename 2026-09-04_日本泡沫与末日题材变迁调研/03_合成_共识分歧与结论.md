## 1. 执行摘要

**核心问题**：日本泡沫经济期（1985—1991）与破灭后（1992—2010年代），末日/灾难题材影视文娱作品的数量与题材如何变化？

**一句话结论**：

```
数量：泡沫期代表作密度 ≲ 破灭后 1990s < 2000s—2010s，且单体 IP 持久度与商业体量
      持续上升（无精确官方计数，趋势基于代表作密度，见方法声明）。
题材：末日"威胁来源"发生系统性内化迁移——
      外部核战/怪兽/天灾 → 都市社会内部+超能力失控+赛博朋克（泡沫期）
      → 精神末世/内心崩溃/制度性缺失（1990s 破灭后）
      → 封闭社会的生存压迫/种族冲突的长期末世（2000s—2010s）。
结构解释：末题创作 = 死亡焦虑的文化处理机制；"经济永续增长"的意义神话失效
       ⇒ 死亡焦虑溢出 ⇒ 末日题材从"击退外部敌人"转为"在崩溃中重寻个体意义"。
```

## 2. A/B 观点并列

### 2.1 数量变化

- **A（数据向）**：泡沫期（1985—1991及紧邻期）代表作约 4—5 部（1984 哥斯拉重启、1984 风之谷、1988 AKIRA、1989 攻壳漫画）；1990s 起出现高 IP 维度作品（EVA、攻壳剧场版）；2000s—2010s 扩张至《进击的巨人》世界累计破亿册 [A4]、哥斯拉 38 部系列 [A5]、EVA 衍生超 1500 亿日元（截至2007）[A3]。**明确声明无精确计数，趋势基于代表作密度**，趋势公式：`D(泡沫期) ≲ D(1990s) < D(2000s—2010s)`。
- **B（结构向）**：未做独立数量统计；以"相变点"框架间接支撑——1995 前为常态区间（末日仍以外部敌人惯性呈现），1995—1997 为临界区间（内化题材范式确立、密度抬升）。
- **共识**：数量呈"上升"趋势、且 1995 是密度/题材双重拐点。
- **分歧/风险**：A 强调"无官方精确计数"这一根本局限；B 用"ACGN 末题占比 + 敌人设定类型比"作为可观测信号（本身为待采集指标，非已有数据）。二者的"数量上升"目前同属**代表作密度层面的定性判断**，精确量化仍缺。

### 2.2 题材变化

- **A**：归纳四阶段——①外部客观灾难（1954哥斯拉/1973日本沉没）→②泡沫期的都市崩溃+超能力失控+赛博朋克（1988 AKIRA、1989 攻壳）→③破灭后精神末世/内心崩溃（1995 EVA、1995 攻壳剧场版）→④封闭社会生存/种族冲突长期末世（2006 日本沉没重拍、2009/2013 进击的巨人）。核心判断：**灾难从"外部实体"持续内化为"社会内部/精神"**。
- **B**：以"核末世 → 世界系"命名同一迁移，强调这是**传承中的断裂**（同构机制、异质变量）——同构的只有"末题=死亡焦虑的文化处理机制"，而"威胁从外部实体→内部系统"是质变。补充关键特征：**世界系"消除社会层"**（无中间社会/国家/军队，只有"我与你"的关系直接对世界危机短路）[B3]。
- **共识**：题材内化迁移是 A/B 独立得出一致结论，可信度最高。
- **分歧**：A 把它描述为连续的"四阶段迁移谱系"；B 把它描述为"传承中的断裂（相变）"。二者不矛盾，是"渐变 vs 相变"两种取景——正式结论应采用 B 的"常态区间 + 临界区间"双层框架，A 的谱系并入区间内部。

### 2.3 成因机制

- **A**：仅提供学术线索——Susan J. Napier 将 AKIRA 反复的大爆炸意象与广岛/长崎原爆记忆、冷战焦虑联系，主张影片把灾害处理为"可复发的事物而非单一历史事件" [A6]；Thomas Lamarre（破坏是循环性的）、Le Blanc & Odell（政府权力破碎被动）[A6]。
- **B**：给出完整 death_drive 框架（见下），锚定 Becker《The Denial of Death》"文化世界观+自尊=不朽工程"机制 [B1]。
- **共识**：末日题材是"创伤记忆/死亡焦虑的文化处理"，随社会创伤反复再生产。
- **分歧**：A 侧重"原爆记忆的延续性"；B 侧重"意义神话失效后焦虑溢出"。二者互补而非冲突，正式结论合并为：**原爆核创伤为底层素材，泡沫破灭+1995+2011 的事件链为触发，Becker 意义神话失效为机制**。

## 5. 相变点结论

```
1995（阪神大地震 + 奥姆真理教地铁沙林事件）= 题材"临界区间"的代表性起点，非精确时点。
  阪神 = 工程/自然防线可崩 → 科技安全神话前兆性死亡
  奥姆 = 社会内部可自生末日型暴力 → 日常安全神话死亡
  末日威胁从此不再来自外部，而来自系统/关系/心理内部。
常态区间（渐变）：1991—1994；临界区间（断裂）：1995—1997（EVA→新范式确立）。
```
