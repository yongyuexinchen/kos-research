## 一、Q9｜Capital Conversion Matrix（资本转换矩阵）

研究对象九类资本为 **Human（技能/健康/时间）、Financial（现金/证券）、Business（生意/P&L）、IP（可商业化知识产权）、Network（关系/客户）、Reputation（声誉/信任）、Physical（房产/设备/实物对冲）、Safety（保险/安全垫）、Option（未来选择权）**。转换 ≠ 无成本兑换：每次转换消耗"转换成本 + 时间 + 损耗"，并可能不可逆。

### 9.1 六维转换属性定义

| 属性 | 含义 | 量化方式 |
|---|---|---|
| 转换成本 | 货币+精力沉没 | 高/中/低 + 需记账数据 |
| 转换时间 | 从投入→可再生出资本 | 高(≥3年)/中(6–36月)/低(≤6月) |
| 成功率 | 转换达到目标的概率 | 高/中/低（L3 估计） |
| 损耗 | 转换中被磨掉的量 | 无/低/中/高（如技能折旧、关系疏离） |
| 窗口 | 是否存在时间窗 | 有(指明窗口)/无 |
| 是否不可逆 | 能否转回原资本 | 可逆/部分可逆/不可逆 |

### 9.2 Matrix 4：转换通道表（示例链，取值=L3）

| 转换链 | 成本 | 时间 | 成功率 | 损耗 | 窗口 | 可逆性 |
|---|---|---|---|---|---|---|
| 现金→教育→Human Capital(M→H) | 中(学费) | 高(1.5–3y) | 高(毕业)但变现不定 | 低 | 无 | **部分可逆**(技能不可退回现金) |
| Human→工资→Financial(M→F) | 低 | 低 | 高(J1) | 低 | 无业→有 | 可逆 |
| Financial→创业→Business(F→B) | 高 | 高 | **低**(创业失败率) | 高(资本消耗) | **有**(融资/红利窗口) | **不可逆**(失败点耗) |
| Knowledge→IP→Business | 中 | 中 | 低–中(内容冷启动) | 低 | 有(平台/版权窗口) | 不可逆(IP一旦公开) |
| Reputation→Customers→Business | 低 | 中 | 中 | 低 | 有(注意力窗口) | 部分可逆(声誉易损) |
| Physical→Financial(P→F) | **高**(房产8–12%往返, 30–90d; 金饰35–50%) | 中–高 | 高 | 高 | 无 | 一般可逆(慢) |
| Safety→Option(S→O) | 无(持有) | 无 | — | 无 | 无 | 可逆 |

### 9.3 Capital Convertibility（可转换性）指标——定义

对单条转换 `C_i: A→B`，定义 `Conv_i = (1−损耗)·(1−成本)·成功率·(时间衰减因子)`，其中时间越长系数越低的衰减统一到 0–1。某类资本的整体 `Convertibility(A)= Σ_j w_j · Conv_j`（w_j 为该转换对当前决策的重要性权重，L3）。**结论（L3 推导）**：Convertibility 排序大致为 **Safety ≈ Financial > Human > Network ≈ Reputation > IP ≈ Business > Physical**。物理资本可转换性最低、窗口最受环境(区位/行情)牵扯，与 D2 物理资产结论一致(L3(D2))。**需真实数据**：逐笔"转换耗时/损耗"时间序列（学习曲线、成交成本），方可将各 Conv 从 L3 校准为 Empirical。

## 二、Q10｜Future Effective Path Space（ΔPathSpace）

定义：**增加 1 单位某种资本，在未来新增的"可执行有效路径"的数量与去相关度**。不是收益率，而是"打开多少扇门、每扇门是否通往正交因子"。半结构化量化=高/中/低 + 方向 + 约束。

| +1 单位资本 | 新增路径数的方向 | ΔPathSpace | 约束/前提 |
|---|---|---|---|
| 现金 +10万 | 正交、约无方向性（任意迁移/缓冲/等待） | **高**（最广） | 单一限制=量级；流动性=路径期权(D2: R5 正交) |
| 新技能(AI 应用) | 单一方向、单因子内 | **中**但**伪分散**（仍在 AI 因子）| 前提是该技能与现有技能**不同因子**才增空间，否则仅横向多一水龙头(D2 |"1因子4皮肤") |
| 新客户网络 | 方向性、跨行业 | 中–高（若跨 R6 泛行业则真增） | 前提=客户池不与 AI 周期同源(D2 D3/D4) |
| 可商业化 IP | 一条放大杠杆 | 中（回报协同、不增分散） | Constraints=发行/版权窗口；下行同源(D2 Q19 Common-Shock) |
| 全球金融资产(海外非科技指数) | 正交、多因子 | **高**（若低相关于 AI）| 须低相关；高相关(如 AI 股)是双暴露非增空间 |

**机制**：ΔPathSpace 近似"实物期权"的增长期权——凡增一行驶权（expand/switch/delay）即增价值，且**价值随不确定性上升**（Damodaran；Myers 1977 实物期权，L1/L2）。故"现金与海外正交指数"是低相关、高不确定性情境下**路径期权价值最高**的一单位；而"AI 因子内加路径"虽 V 增加，但**同因子路径期权相互挤出**(下行同theater)，净增空间≈0(D2 P2)。**需数据**：候选新增路径的历史"落地成功率 + 与本职相关 ρ"，量化后 ΔPathSpace → Empirical。

## 三、Q11｜Reward Source Concentration Index（RSCI）

本研究的聚集度指标区间：**HHI(Σsᵢ²) / Shannon Entropy / Effective Number of Reward Sources / Factor concentration / Network concentration**。逐一评估其在 Personal EGS 语境的适用性后给出推荐。

### 11.1 候选指标评估（不直接接受 HHI）

| 指标 | 公式(示意) | Personal EGS 适用性 | 关键缺陷 |
|---|---|---|---|
| **HHI** | Σsᵢ² | 直觉但**局限大** | ①对少量路径畸高：n=4 等权 HHI=0.25 就"高集中"，但对正交因子未必危险；**直接把"路径少"与"因子集中"混为一谈**②权重 sᵢ 取"现值占比"在**非交易资产(人力/IP)无法标价**时不成立③sᵢ 取"当前现金流入占比"会漏掉**现值为 0 的人力将来流** |
| **Shannon Entropy** | −Σsᵢ·ln sᵢ | 更好：关注"分布在多源上的均匀度" | 对 0 暴露源(现值忽略)会有边界效应；熵本身无量纲、不好读 |
| **Effective # of Sources** | exp(H) 或 1/HHI | **最贴近直觉**：代表"等效独立源数" | 仍是被动描述，不含"源是否同因子"信息 |
| **Factor Concentration** | 对主因子集聚的暴露加总 | **弥补上者**：同因子多源只算 1 个因子(呼应 D2 伪分散) | 依赖"因子分解"的质量，现行仅 L3 |
| **Network Concentration** | 客户/节点 HHI 或图熵 | 针对 Network 资本单独适用 | 需关系图数据，本轮无 |

### 11.2 RSCI 推荐（改良版，L3 我方构造）

**单靠 HHI 会误判 Personal EGS**，因为这里"零暴露源"和"非交易资产"是常态、且聚合介质是**因子而非流量**。推荐**两层改良**：

```
RSCI_f = 1 − [Σ_F (Σ_{i∈F} w_i)²]      # 按"因子簇"加总权重后取 HHI 的互补
NSRC   = exp(H_f)                       # 等效独立因子数（H_f=因子层熵）
RSCI   = (RSCI_f, NSRC, 标注0暴露源数/非交易资产权重依据)
```

即**先在因子层聚合成权重，再算聚集度**，而非直接对"奖励流"算 HHI。理由(D2 支撑, L3(D2))：对象的 4 条 AI 流在因子层面是 1 个因子，直接对"4 条流"算 HHI 会显示"0.25 不算太集中"，**严重低估真实集中度**；因子上加总后才暴露出 RSCI_f≈0（几乎 100% 聚于单一 AI 因子）。

### 11.3 局限

①因子分解(六因子映射)是 L3 构造，需真实协方差数据校准；②0 暴露源(现值为 0 的人力)的权重分配无唯一标准；③补贴/政策/地域等难数值化因子仍停留定性；④指标是"状态的快照"，不含可转换性/可迁移性的动态(需 Q12 的 Switchability 补足)。

## 四、Q12｜三维度健康（面而非点）

建立三维：(1) **Wealth** 当前财富规模；(2) **Reward Sources** 依赖的独立奖励机制数量；(3) **Switchability** 某奖励源失效时能否快速转移。

**结论性讨论（公平呈现，无明显最优）**：

- **"财富高但奖励源集中"**：短期现金流厚、容错高，但**Common-Shock 暴露集中在单因子**——若因子塌(如 AI 融资崩+裁员+内容自动化+广告收缩同发,D2)，高财富只是"同因子上更厚"，**下行相关性不减**。这类人常高估计安全感。
- **"财富低但分散且可迁移"**：对下行韧性高、Switchability 强，但**低财富意味着无缓冲**——一次转换失败可能清零。分散带来的韧性若没有现金/安全垫兜底，仍是裸奔。
- **判定（L3，非唯一答案、须公平）**：**不存在纯财富维度上的唯一"更健康"**。健康 = Wealth 够支付"转换窗口"的现金流(≥12–24 月, D2 L3) **且** Reward Sources 跨因子 **且** Switchability 高。若必须排序：**"分散+可迁移+有缓冲" > "集中+高财富" > "分散+无缓冲"** ，理由在于下行场景下因子相关不可分散，而财富若同因子就失效(D2 Q4)；但该排序对"财富极高到可自筑多个正交子组合"的上限情形可能反转——届时集中也近乎无风险。**依赖 Switchability 的真实测度数据（失业→回岗/跨行/变现时长）方转为 Empirical。**

## 五、Q13｜生命周期（年龄阶段）

生命周期金融核心：人力资本现值 = 未来劳动收入的折现(L1：CGM 2005；Benzoni-Chyruk 2015)。人力资本随年龄单调下降(剩余工龄渐少)，是**不可交易的支配性资产**；其"股票化/债券化"取决于**与权益的长期相关**。

### 5.1 人力资本性质随年龄（L1）

- **年轻时**：剩余工龄长，若劳动收入与股息协整则人力资本**股票化**（Benzoni-Collin-Dufresne-Goldstein 2007：年轻应**短/低配**股票而非加——协整使现值 stock-like）。
- **年长时**：离退休近、协整来不及作用，人力资本转**债券化**，此时金融组合才需补权益。
- **对照**：CGM(2005)在"低相关"假设下得"年轻高权益"（劳动收入替无风险资产）；Benzoni(2007)在"高相关"假设下得"年轻低权益"。**同一命题两套结论，取决于相关系数——这正是本研究对象的人力资本风险关键（R1×R2=0.75,L3(D2)）。**
- Choi-Liu-Liu(2025, L1)**挑战年龄法则**：近似解福利损失仅 0.06%，而"100−年龄"损失 2.00%、恒定 60% 权益损失 3.75%；最优权益份额 ∝(1 + H/W)——**年轻的本质是 H/W 大，才推高权益**，且须权益**低相关**于其人力资本。Anarkulova-Cederburg-O'Doherty(2024, L1)更极端：全权益组合胜过年龄法，主张"降低权益随年龄"并非铁律。

### 5.2 分阶段资本结构（L2/L3 结合，对照=30 出头转型期）

| 阶段/年龄 | 人力资本 | 金融资本 | Safety/保险 | 关键动作 | 权益可承受度 |
|---|---|---|---|---|---|
| 20s 学习期 | 极高、最股票化 | 低 | 需 term 寿险(青年 HLV 最大) | 重人力投资、勿锁物理资产 | **仅当人力低相关**；高相关则克制(Benzoni) |
| 30s 转型期(对象) | 高、但其 AI 人力高相关=伪股票 | 10–30万=L3 | **现金缓冲优先** | 现金>学费>正交指数；检疫"AI+AI股"双暴露 | 进取只投低相关侧 |
| 40s 高收入/创业期 | 中、开始债券化 | 上升、H/W 降 | term 转降、增储蓄 | 现金流转资产、跨因子副业 | 权益占比可按 H/W 上升(Choi-Liu-Liu) |
| 50s–60s 积累→退休 | 低、债券化；协整失效 | 主导 | 缺口转 annuities/医疗 | 序列风险控、laddered bonds(D2/CFA L2) | 降权益(D2 L3)，低相关缓冲保 Switchability |

**主动找反例**："年轻时该高权益"的天花板式前提是**人力资本低相关**。本对象反例成立：其人力资本恰高相关于 AI 权益(R1×R2=0.75,L3(D2))，因此"进取"必须放在**低相关/现金/海外非科技侧**，而非叠加 AI 股——否则是 Common-Shock 双暴露(D2 Q19)。另见 Betermier-Jansson-Parlour-Walden(瑞典面板,L1)：从低波动行业转高波动行业者**降低金融风险的权益占比高达 35%**——实证支持"人力资本越股票化、权益配置越应当下降"。**需数据**：对象真实储蓄率、H/W、AI 人力与权益协整系数，方可 L3→Empirical 落地。

## 六、Q15｜Personal EGS Exposure Model v1.0（最终组装）

输入九类资本，输出暴露/集中/冲击/相关/转换/可迁移/路径空间的多维键值。**半结构化接口示意**（模型壳，非可交易参数）。

```
INPUT (L3/S，标 * 者以 S 级兜底)
  Human{S}  Financial{L3}  Business{L3}  IP{L3}  Network{S}
  Reputation{S}  Physical{L3}  Safety{L3}  Option{L3}
  + 年龄、现金缓冲月数、H/W、风险容量(非偏好)

OUTPUT
  reward_source_exposure:  {R1..R7: 现值/因子暴露权重, 附0暴露源清单}
     Factor_map: {AI工资,AI股,AI创业,AI内容 → 因子F_AI; R5->F_cash; R6->F_generic; R7->F_gold}
  concentration: RSCI_f(因子层HHI互补), NSRC(等效独立因子数)  # Q11改良
  common_shock:  各源与主导因子共享面的 Common-Shock 暴露(D2 Q19)
  correlation:  九类资本成对 ρ 矩阵(D2 L3，可替换为实测)
  convertibility: {C_i: (成本,时间,成功率,损耗,窗口,可逆,Conv)}  # Q9
  switchability: {失效场景→(转移成本, 到达新源的时间)}          # Q12
  path_space:    ΔPathSpace 高/中/低 + 方向 + 约束               # Q10
  lifecycle_tag: {阶段, H-characteristic(股票/债券), 权益可承受度} # Q13
```

### 6.1 输入成熟度分级（诚实标注）

| 输入 | 当前 | 转 Empirical 所需真实数据 |
|---|---|---|
| Financial / Physical / Safety | L3 | 资产清单+成本/变现数据(已有部分 L2 变现表) |
| Human(技能现值/未来现金流) | **L3/S** | 就业率、薪资本位随机行走、AI 人力与市场协整系数(CGM/Benzoni 需) |
| Business / IP / Network / Reputation | **S** | 现金流入历史、客户/关系图、IP 授权收入、声誉事件序列 |
| 相关性 ρ | **L3** | 中国本土 AI 就业/薪资/融资/广告预算跨周期协方差 |
| RSCI / ΔPathSpace / Switchability | **L3/S** | 转换耗时/损耗时间序列、新路径落地成功率 |

> **一句话（模型状态）**：v1.0 是**可复现的推理骨架**，可在环境数据喂入后逐格把 L3/S 升级为 Empirical；当前未给精确数的地方一律以高/中/低 + "需何种数据"收口，**不虚构精度**。
