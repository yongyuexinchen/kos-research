# 01 · 板块池A · 现金流/红利类 EGS 扫描

> 日期：2026-09-07 ｜ 组别：A（现金流/红利类）
> 环境约束：10Y TIPS **+2.42%**（高位）、FOMC 加息概率~60%、美债温水煮青蛙、风险偏好低、高利率压制长久期与高估值。
> 已持仓：黄金(定投)、创新药(定投)、三一(分批)、牧原(挂单)、**水电**（本组最重要的同源红线）。
> 方法：真实数据 WebSearch（券商研报/公司中报，截至 2026-09-07），主动找反例，不预设"红利就好"。
> 打分仅用**高/中/低**，不造假数字化分。

---

## 〇、核心矛盾的拆解

**高实际利率对红利股到底是"利好还是利空"？—— 答案是"中性偏利多，但需分层"。**

把问题拆成两根链条，结论不矛盾：

**① 相对吸引力（股息率 vs 国债收益率）—— 对 A 股红利是"利空但不致命"，方向被国内债扭曲。**
教科书逻辑（美债收益率上行 → 股息率相对吸引力下降 → 红利估值承压）在 **A 股并不被吃掉**：中国 10Y 国债仍在 ~1.7% 的低位，A 股红利股息率普遍 4-6%，**利差依然很厚**。因此"央行降息 → 保险/存款成本下降 → 红利资产相对更香"是国内主线；反而是**美股/全球**部分，高名义利率直接压制高估值成长（属 B/C 组任务）。所以高利率对本组红利**不是主要自变量**，国内利率才是。

**② 高利率通过"风险偏好/资金成本"传导 —— 对本组是"弱利多"。**
全球风险偏好低 → 避险资金流向现金流确定资产（红利占优）；高利率压制长久期高估值 → 本组低估值、短久期现金流被动受益。**风险在高杠杆板块的融资成本**上（银行、公用事业重资产扩张），但这部分被国内宽货币对冲。

**结论（先放这里）：本组六个板块在"高利率"环境的相对胜负，更多取决于各自"盈利 reward 源是兑现还是压制"，而不是"红利 vs 债券"这一个变量。** 下方逐个板块拆。

## 一、煤炭 —— 已验证红利 + 周期弹性，但已大涨、股息率被压缩，KOS"兑现强、位置透支"

| 维度 | 判断 |
|---|---|
| 1. Reward Source | = 产量 × 煤价 × 红利。**兑现**。秦皇岛港5500大卡2026H1均价772元/t(+12.7%)、6月末842元/t；安监"84号文"+《十五五规划》收紧国企供给，产量6-7月同比-9.7%/-10.1%（山西-31%/-36%）。23家上市公司H1归母净利748亿(+34.3%)，Q2环比+41.2%。神华中报净利287亿(+4.1%)、分红率74%；中证煤炭股息率年初5.82%。 |
| 2. 担保人 | 政策（安监/反内卷控产能）、长协定价锁定盈利可见性、火电发电需求(+2.9%)。可靠。 |
| 3. 怕什么死 | ①煤价大跌（若国内电力需求大幅下滑）；②新能源长期挤占火电需求；③疆煤外运扩产压制沿海价格；④板块已涨，股价回调反而来自"涨太多"而非盈利。 |
| 4. 位置/估值 | **中—偏高，股息率已透支压缩**。年初至今板块一度+24.68%领涨、中国神华市值曾跌破万亿；券商测算龙头股息率将从上市前4.5%压回2026年中**3.5%**左右——相对吸引力明显收窄。 |
| 5. 与已持仓相关度 | **中**。与水电同属"股息/公用"防御底色（部分同源）；但煤炭盈利源是**煤价周期**而非稳定现金流，是用更高波动换更高股息，且是火电上游（买煤炭≈间接押火电成本端）。 |
| 6. 适配按钮 | 当下不追。当煤价回调、板块回调使龙头**预期股息率重新回到5%+**（或 P/E 回落）时再介入；"煤价回调 + 股价补跌"双向验证。 |

**反例/裁决**：煤炭是**"已验证红利"而非"伪高股息"**——盈利真实兑现、分红率真实高。但问题在**位置**：已大涨透支，且它带周期弹性，"不像红利像通胀交易"。在高利率下它是**受益上游实物/抗通胀**的一类，性质接近耐通胀资产。低位时是好红利，现位不追；与水电部分同源需扣权重。

## 二、电力 —— 用户已持水电，重点看火/核（同源红线最锋利的一栏）

**先定同源基准**：水电=稳定票息式真红利（度电成本全电源最低、毛利稳、长时间免维护）。核电与水电**最同源**（同为"稳定票息式"基荷电源）；火电含煤价成本周期（类债但含周期），与水电**互补性相对更好、重叠度略低**，但仍是同一张"发电资产"牌。

| 维度 | 火电 | 核电 |
|---|---|---|
| 1. Reward Source | = 电价×利用小时×**容量电价**+长协煤价。**兑现弱/压制中**。H1火电归母净利476亿(-18.1%)受"煤价涨+电价跌"挤压，但容量电价 2026 年回收固定成本比例升至≥50% 托底，度电利润仍2-4分，好于预期，正在"公用事业化"（板块股息率已从2021年1.8%升至**4.4%**，多家锁分红承诺≥60-70%）。 | = 电价×利用小时×**装机成长**。**兑现弱/萌芽**。广东核电电价止跌、机制电价锁70%电量收益"安全垫"，装机成长确定性强；但H1净利-15.3%（机组检修+江苏市场化电价下跌）、ROE 4.0%。铀价上行影响可控。 |
| 2. 担保人 | 容量电价政策、煤电调节性电源价值、电价市场化改革。 | 机制电价政策（辽宁/广西）、核准成长。 |
| 3. 怕什么死 | 电价市场化继续下行、利用小时被新能源挤占、煤价大涨。 | 电价市场化下探、利用小时降、铀价大涨、项目投产不及预期。 |
| 4. 位置/估值 | **低**。基金配置 2021 年以来最低、全行业低配。 | **低**。基金配置低，市场化电价利空已price-in。 |
| 5. 与已持仓相关度 | 水电：**中—高（同电力公用，但商业模式互补）**。 | 水电：**高（最同源，最需规避重复）**。 |
| 6. 适配按钮 | 煤价企稳/长协电价回升或回调至更高股息率时；容量电价提升落地时介入。 | 机制电价落地 + 装机投产节奏明确 + 估值仍在低配区间时。 |

**反例/裁决**：电力板块整体与已持水电**显著同源**，本档真正的增量价值小于表面。若要在这张牌上加仓，**火电 > 核电**：火电"煤价差+容量电价"的周期-红利结构与水电互补，核电则与水电几乎同构（重复最重）。且电力板块 2026 年红利/公用风格本身跑输（水电-11.3%、核电-8.3%，2025至2026-02），说明"红利"并非此地自动成立，需扣掉已持水电的暴露再决定。

## 三、电信运营商 —— 最强的"伪高股息陷阱"候选

| 维度 | 判断 |
|---|---|
| 1. Reward Source | = ARPU×用户数 × 云/算力业务。**传统业务压制、算力萌芽**。移动 ARPU 从45.6→45.1元（连续第四年降），增值业务增值税率6%→9%直接压缩利润；中国电信 H1 归母净利-14.9%、移动-6.3%（同口径平）。亮点在算力：中国移动算力服务+14%、智算+130%，电信天翼云618亿(+7.8%)。 |
| 2. 担保人 | 牌照垄断 + 央企背景 + 现金流充沛（移动经营现金流+37%、自由现金流+111.6%）。担保人可靠。 |
| 3. 怕什么死 | ①ARPU 持续下滑 + 价格战重燃；②增值税上调；③算力巨额资本开支（电信255亿/占35%、移动算力网+71%）**侵蚀 ROE、折旧快、回报周期长**；④云/智算处于竞争红海、毛利率低。 |
| 4. 位置/估值 | **中低**。电信 PB 1.05 倍、PE ~14.5 倍；移动 PE ~14 倍。 |
| 5. 与已持仓相关度 | **低**。与水电/黄金/创新药/周期均低相关，分散价值真实。 |
| 6. 适配按钮 | 本档不视为"红利防御"标的。仅当①利润下滑斜率止住、②算力开始贡献真实利润、③股息率仍靠真利润而非靠提派息率硬撑时，才考虑。中国移动（同口径盈利稳、现金流最厚）> 中国电信 > 中国联通。 |

**反例/裁决**：这是本组最典型的**"伪高股息陷阱"**——**股息率5%+是靠派息率60%→75%硬抬出来的，而分母（利润）在下滑（电信利润-17%/-14.9%）**。商业模式是"现金流好、利润停滞、增长靠烧算力"。在"红利防御"逻辑下它最脆弱，因为**高股息不可持续的数字基础不稳**；它更像"等待算力转型兑现的期权"，不是当前环境的现金流防御资产。

## 四、石化 —— 周期红利，靠油价/地缘，稳定性最弱的一档

| 维度 | 判断 |
|---|---|
| 1. Reward Source | = 油价差(炼油毛利) × 上游油气 × 化工减亏。**兑现，但依赖油价中枢**。中国石化 H1 净利256亿(+19.3%)，炼油毛利453元/t(+44.1%)、上游营业利润+21.5%；但**炼油加工量-5.6%、成品油消费-8.6%**（高油价已抑制需求），Q2 环比-49%。 |
| 2. 担保人 | 一体化央企、国内炼能严控（反内卷）、中东断供暴露全球供应链短板→国产替代叙事。 |
| 3. 怕什么死 | ①油价**双刃剑**：大涨抑需求（炼量负增长）、大跌缩上游（库存收益消失）；②国内成品油/化工需求疲软；③化工过剩。 |
| 4. 位置/估值 | **中低**。石化 PE ~15.7倍、PB ~0.76。 |
| 5. 与已持仓相关度 | **低**。 |
| 6. 适配按钮 | 不作为当前红利标的。仅当油价企稳+炼化景气拐点确认+估值回落时考虑；它是"周期修复"而非"稳定现金流"。 |

**反例/裁决**：石化的"高股息"**依赖油价上行+分红政策**，盈利源波动大、2026H1高增主要是地缘油价红利的库存收益，**不可持续性强**。在高利率、需求疲软环境下，它的 KOS 成立度弱于煤炭/银行/高速——**当归入"周期反转"而非"现金流红利"**，本组内优先排除或降权。

## 五、高速公路 —— 最纯粹的稳定红利，弹性小但 KOS 真实

| 维度 | 判断 |
|---|---|
| 1. Reward Source | = 车流量 × 费率（特许收费权）。**兑现（稳健）**。宁沪高速 H1 通行费收入+5.76%、净利+3.28%、车流量微降但**货车流量+5.83%**（旅货结构优化、高费率），经营性现金流常年高于净利（折旧大）。 |
| 2. 担保人 | **路产特许收费权垄断** + 货车/产业带需求刚性（长三角制造业）+ 收费按期/扩建重算续期。 |
| 3. 怕什么死 | ①收费期满收入归零（需持续续期/购新路，宁沪73亿收购苏锡常南部高速）；②高铁分流客车；③自身改扩建分流；④政策降费率（低概率）。 |
| 4. 位置/估值 | **中低**。宁沪 PE ~13倍；华创按26年维持0.49元派息测息率3.2%、但滚动口径(加0.25中期)达~5.98%；ROIC 5.63%。 |
| 5. 与已持仓相关度 | **中低**。与水电同为"类债票息"防御底色（资金属性同源），但资产不同（收费公路 vs 发电）。 |
| 6. 适配按钮 | 增速低、弹性小，适合作为组合"纯收息压舱石"。当股息率回到5%+估值中性、且路产扩建/并购确定性落地时，小额配置。 |

**反例/裁决**：高速是本组**无争议的"已验证红利"**——盈利真实、分红稳健（宁沪20多年从未降每股派息、2026首次中期分红）、无原材料/库存/客户流失风险。但**弹性几乎为零、增长被收费期限与扩建开支约束**，属"配置价值>alpha"。位置不贵，作为防御底仓成立，需接受低弹性。

## 六、银行高股息 —— 净息差触底+"高息存款到期重定价"是真实顺风，但依赖拨备缓冲

| 维度 | 判断 |
|---|---|
| 1. Reward Source | = 净息差 × 信贷规模。**兑现（由"压制"转向"企稳"）**。2Q26商业银行净息差1.41%(环比+1bp)，上市行H1净息差1.38-1.49%、**净利息收入+8.4%**；核心驱动是**2026年约50万亿高息定期存款集中到期重定价**（个人定存付息率降30-60bp，兴业/农行测算存量3年息存款成本降135-140bp）。注意：利润增速仅3.0%，**多提拨备吃掉了约6成增量营收**（信用成本0.64%→0.84%），属"蓄力式"企稳而非真提速。 |
| 2. 担保人 | 政策（存款利率下调托底息差、信贷投放窗口）、大行存款续存率90%+、国有大行分红率统一+1pct。偏可靠，但真实盈利靠拨备缓冲。 |
| 3. 怕什么死 | ①净息差若再走低（LPR若压、资产端降价）；②零售不良上行（按揭0.94%、信用卡2.82%、消费贷1.80%、经营贷1.89%全升）；③信贷需求不足（新增贷款92.5%对公、零售-1.8%）；④地产尾部风险。 |
| 4. 位置/估值 | **低**。银行估值极低（PB<1），股息率5-6%，大行分红率提升。 |
| 5. 与已持仓相关度 | **低**。与水电/周期/科技均低相关，分散价值真实。 |
| 6. 适配按钮 | **本组内较适配**。买入逻辑="高息存款到期重定价(2026-27) + 净息差触底 + 政策托底 + 极低估值"。介入信号：①净息差连续季企稳/回升、②零售不良拐头、③放量信贷转向零售。**品种分层**：国有大行（风险最低的稳红利）在最优先；优质区域行（江浙/成渝对公强+成长）次之；股份行（零售/地产敞口）需等不良回落。 |

**反例/裁决**：银行是本组**"真正通过验证的高股息"候选**——它面对"高利率→坏账/成本"的反例，答案恰好相反：**国内存款利率下行+存款到期重定价让负债成本大降，反而托底了息差**；叠加国有大行分红率抬升、估值极低。但必须诚实标注**反例**：①盈利是"熬出来的企稳"（多提拨备），坏账/零售不良仍在上探，不能当成长看；②若未来政策降息压低资产端，或零售风险放大，红利稳定性打折。属于"低估值+稳分红+催化真实"的可配置红利，**分散价值（与所有存量持仓低相关）是本组内独特优势**。

## 七、组内排序与红旗汇总

**KOS 成立度排序（主观，非精确分数）**：
低位可配：**银行大行 > 高速公路**
兑现强但透支：**煤炭**（等回调）
同源红线：**电力(火>核，且均要扣水电已暴露)**
伪高股息陷阱／KOS 弱：**电信（最危险）、石化（归入周期而非红利）**

**红旗（主动找的反例）**：
1. **电信 = 伪高股息**：5%股息靠派息率硬抬、分母利润在跌，最不符合"红利防御"。
2. **石化 = 周期伪装红利**：盈利靠地缘油价+库存收益，Q2 已-49%，不稳定。
3. **煤炭 = 真实红利但位置透支**：不是伪，但已领涨、龙头预期股息率压回3.5%，现价 KOS 不成立。
4. **电力 = 同源最锋利**：火/核与已持水电同属发电资产，尤其核电与水电同构，加仓需先减去水电暴露，防空转。
5. **银行 = 需拆银**：息差企稳真，但靠拨备缓冲+存款到期重定价一次性顺风，且零售不良在升；要区分大行/区域行/股份行。

## 八、对"煤炭 KOS 在高利率环境是否成立""是否与水电同源"的直接回答

- **高利率环境里煤炭到底行不行？** 煤价中枢上移+供给收缩是**国内政策驱动的真实利好**，与"10Y TIPS +2.42%"的外生高利率几乎无关——它受益的是**抗通胀/上游实物**逻辑（和高利率的"温水偏避险"共振），而非"红利vs债券"利差。**KOS 成立，但体现在"现价已透支"层面不成立**：盈利真、分红真，价格早已反映，追高=输给自己的纪律。
- **煤炭与水电是否同源？** **部分同源、部分互补**。资金属性上都属"高股息防御"，红利风格下会同涨同跌（相关度中）；但盈利源本质不同——水电=稳定票息，煤炭=煤价周期弹性。买煤炭换的是"更高股息但更高波动"，且它是火电上游，等于把一部分赌注押在火电成本端。**结论：煤炭可在回调后作为"类通胀/周期红利"的小额补充，但不能当成水电的替代/加仓，两者是两套逻辑。**
- **银行 KOS 是否成立？** 成立度高但路径是"企稳红利"而非"高成长"。真实拐点是**高息存款到期重定价（2026-27）+息差触底+政策托底+估值极低+分红率抬升**，四条都落在 2026 年，不是"伪高股息"；最强反例是"利润靠拨备缓冲+零售不良在升"，因此它适配"防御+收息"而非"进攻"，且应只配于国有大行/优质区域行层面。
