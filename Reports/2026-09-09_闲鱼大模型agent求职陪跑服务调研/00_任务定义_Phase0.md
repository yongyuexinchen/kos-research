# 闲鱼大模型Agent求职陪跑服务调研 · 任务定义 Phase0

## 零、承接框架与背景

- 调研对象画像：正在学尚硅谷大模型/智能体课程，计划包装"项目、公司、背调、社保、银行流水"以求职 LLM Agent 应用开发岗。
- 触发点：闲鱼大量"大模型 Agent 求职陪跑"卖家；用户要求调研"靠不靠谱、怎么分辨"。
- 已有本地基线（KOS reference）：
  - `china-job-market-research` skill：L1-L5 分层法 + 平台可达性速查 + 报告模板
  - `job-market-ai-skills-2026.md`（2026-07 猎聘 JD 快照）：AI 应用开发岗技能集（RAG/Agent/Docker/FastAPI/向量库），两条路线分化
  - `shenzhen-ai-job-market-2026.md`（2026-08 快照）：深圳岗位趋势、学历/年龄惩罚、推荐路径=培训班打底+作品集突围
- 政策背景：人社部+网信办+教育部+公安部+金融监管总局 2026-05 五部门联合发布"招转培/培训贷"求职骗局风险提示；人民日报 2026-07 报道"付费远程实习"诈骗团伙被判刑。

## 一、研究问题（并行）

1. **Agent1·服务供给与价格结构**：闲鱼/短视频/机构三类"求职陪跑"卖家的服务模式、定价档位、师资真实度、典型话术
2. **Agent2·分辨方法**：红旗/绿旗清单、可落地的验证手段（身份验证/合同/付费方式/退款）
3. **Agent3·造假法律风险与背调机制**：2026 年背调到底查什么（社保/个税/学信网/前司访谈/第三方机构）、公司包装/背调包装/社保流水造假的民事与刑事后果、真实判例
4. **Agent4·进入路径**：针对尚硅谷 LLM Agent 学习者的真实求职路径（可验证作品集/开源/课程项目如实标注 vs 履历造假），对比评估

## 二、边界

- **绝对边界**：本调研不输出任何"如何伪造履历/社保/流水/背调"的方法论，只做风险识别与合法路径；涉及造假的描述仅限"结果与后果"层面。
- 实时闲鱼商品价格/成交量：网络受限，标 `[待验证]`，给出人工复核方法（浏览器搜索关键词清单）。
- 尚硅谷官方宣传（17k/82.8万/479%岗位增长等）属机构营销素材（L4 利益相关方），需独立交叉验证，不得单独支撑结论。
- 背调内部细节属公司保密信息，仅能以 HR 社区/律师公开表述推断（L4/L3）。

## 四、验收

1. 闲鱼求职陪跑服务整体靠不靠谱？给出**明确裁决**（可用/谨慎/不可用，分档）
2. 给出**红旗/绿旗清单**，可当购物前检查表直接用
3. 说清"公司包装/背调包装/社保流水"环节的**真实后果**（判例+法条），不空谈道德
4. 给出尚硅谷学员的**合法替代路径**，含可执行的简历写法与作品集方案
