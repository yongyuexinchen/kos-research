## 0. 母问题

在"中国创新药从国内医保/仿制替代 → License-out/海外商业化/全球价值捕获迁移"的假设下，回答：

> **这个新 Reward Function 究竟由谁获得、通过什么机制、价值经过哪些环节泄漏、最终有多少传导到个人投资者持有的股票/指数/ETF？**

特别区分：**Industry Reward ≠ Company Reward ≠ Index Reward ≠ Investor Reward**。必须走完链条：

```
Reward Source → Reward Capture → Reward Transmission → Investor Return
```

## 2. 硬性证据纪律（沿用，Q3/D 强化）

验证前置理 户要求：主动找 交易取消/里程碑失败/海外销售不及预期/政策限制/利润不增/股东不捕获/指数不捕获/头部垄断/中小掉队/泄漏。特别警惕"产业数据好看股东收益差"。

- 每断言标 **L1**（财报/监管/公告一手）/ **L2**（多源独立）/ **L3**（结构判断，禁止冒充捕获数据）。
- Deal Value ≠ Upfront ≠ Milestone ≠ Royalty ≠ Revenue ≠ Profit ≠ EPS ≠ Shareholder Return——逐层兑现率，无法验证**不造数**，用 高/中/低 + 需何数据。
- 本轮**不立刻决定仓位**；只给出"进入配置层需哪些变量"。
