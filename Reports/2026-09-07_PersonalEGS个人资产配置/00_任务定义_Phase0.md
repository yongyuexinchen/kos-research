## 一、本轮专问（纠正"过度聚焦 AI/技术职业"的结构偏差）

$$
\boxed{
\text{一个 30 岁左右的人，如何在未来 10–20 年不断积累可以产生奖励的个人资产，}
}
$$
$$
\boxed{
\text{使自己逐渐降低对单一工资、单一行业、单一雇主、单一政策环境的依赖？}
}
$$

不再是"2035 年哪个职业最有前景"，而是：**把所有收入来源视为『资产形成路径』，研究如何把劳动收入逐渐转换为能力、资本、网络、企业、IP 等长期资产**。

## 二、禁止/允许边界

### 2.1 禁止
- **禁止把 AI 作为默认答案**——AI 只是 Human Capital Path 之一
- **禁止把 AI/股票/房地产/创业/公务员分别当"职业答案"**——它们都是资产形成路径
- **禁止预测具体资产价格/工资**——只研究长期现金流、风险、流动性、资产形成能力

### 2.2 允许
- 开放研究：职业/技术/金融投资/股权/创业/副业/实体经营/不动产/IP/内容/个人品牌/社会网络/学历/地域迁移/现金储备
- 研究资产之间如何组合
- 建立组合 Portfolio，而非单一最优职业

## 四、KOS 调研规范（强制，承 v1-v5）

1. **证据分层**：A（官方/法规/正式文件）｜B（高质量学术论文）｜C（可靠媒体/行业研究）｜D（二手评论）｜E（推论/理论假设）。EGS-B 三轮已声明：逐年宏观数据当前无 A 级渠道可核；个人层数据多为 C-D 级；金融/创业/实体数据多为 C 级。
2. **不预测具体资产价格/工资**——只研究长期现金流、风险、流动性、资产形成能力。
3. **不默认技术岗位最高**——必须研究真实数据，允许得出"技术岗位资产形成能力低"的结论。
4. **不浪漫化资产收入**——必须研究投资失败/创业失败/实体失败/流动性风险/小企业生存率/"被动收入"神话。
5. **不允许把"AI 应该做"当默认答案**——AI 只是 Human Capital Path 之一。
6. **核心结论用盒式公式标注**。
7. **数量/统计断言必须带来源编号**，无来源的推断标 `[INF]`。
8. **双导出铁律**：本轮只产报告于 `Research/Reports/2026-09-07_PersonalEGS个人资产配置/`；不直接动知识层/认知层/演化层/行动层。

## 六、统一符号（沿用 v1-v5 + 本轮新增）

| 符号 | 定义 |
|---|---|
| $S(t)$ / $C(t)$ / $\text{Resp}(t)$ / $B(t)$ | 第五轮四层（技能/能力/责任/议价权） |
| $\text{PersonalAssets}$ | 个人资产组合 = {HumanCapital, FinancialCapital, BusinessCapital, PhysicalAssets, IP, Reputation, Network, OptionValue} |
| $\text{AssetStock}(t)$ | 资产存量 |
| $\text{ConversionRate}$ | 劳动→资产转换率 = 新增可产生未来现金流的资产 / 当前劳动收入 |
| $\text{AssetYield}$ | 实体资产 = CashFlow / Capital |
| $\text{Independence}(A)$ | 资产 A 产生收入对个人持续劳动的依赖程度 |
| $\text{CorrelationRisk}$ | 各资产之间的相关性风险（是否都押注同一周期） |
| $\text{RiskBudget}$ | 风险预算（什么年龄承担什么类型风险） |
| $\text{PaybackPeriod}$ | 资产形成的时间尺度 |
| $\text{Guarantee}_{\text{personal}}$ | 个人担保函数 = f(HumanCapital, Cash, FinancialAssets, Business, Network, SocialSecurity) |
| $\text{PersonalEGSScore}$ | Income + AssetAccumulation + SkillCompounding + OptionValue + Independence − Risk − Lockin − CorrelationRisk |
| $\text{Resilience}$ | CashBuffer + IncomeDiversification + AssetDiversification + SkillTransferability |

| A6 | Reputation | 行业声誉/个人品牌/可信度 | 复利 |

## 八、五种赚钱方式

| # | 类型 | 特点 | 独立性 | 资产形成能力 |
|---|---|---|---|---|
| W1 | Wage Income | 出售时间劳动，现金流强但与劳动绑定 | 低 | 低 |
| W2 | Skill Income | 高技能工资/项目，人力资本溢价 | 中 | 中 |
| W3 | Business Income | 企业/经营实体，非线性收益但失败风险高 | 中 | 高 |
| W4 | Capital Income | 股息/利息/上涨/房租，与劳动弱绑定 | 高 | 高 |
| W5 | IP/Network Income | 内容/软件/IP/品牌/许可，边际成本低 | 高（维护依赖） | 高 |

## 九、核心命题（本轮要验证）

$$
\boxed{
\text{个人真正的"逃逸能力"来自资产积累——当个人资产规模增加后，对单一工资的依赖降低。}
}
$$

$$
\boxed{
\text{国家担保 → 市场担保 → 雇主担保 → 个人资产担保——个人资产可以自建担保函数。}
}
$$
