# 研究包1：优化目标函数 + 个人资产负债表

> 对象画像：约31岁（30–33）· 无业转型期（学习大模型应用/部署、求职中）· 可投资流动资产 10–30 万人民币 · 现无工资收入 · 3年大数据经验（Python/SQL，非计算机本科）· 拟读非全日制大数据研究生 · 主观风险承受「进取」（股权侧重）。
>
> 关键约束：**无业转型期 = 存活/保本优先度被外力强制上调**，即使自评进取，在收入恢复前不得按无约束股权策略配置。
>
> 方法学立场：本报告只做"哪些可算、怎么算、算出来的量级"，全部量化项标注证据等级 L1/L2/L3（L1=用户给定事实；L2=有模型支撑的估算，条件依赖输入；L3=当前无法可靠计量，仅概念/代理）。**不编造输入数字；任何未经验证的输入均标注 L3「待核实」。**

## 二、Q1 目标函数：目标向量（3 轴）+ 阶段权重表

### 2.1 九个候选目标的重叠/冲突判定

| 候选目标 | 归并到哪条轴 | 是否独立 |
|---|---|---|
| 当前现金流最大化 | 轴A（生存/跑道） | 并入 A |
| 极端生存概率最大化 | 轴A（Runway≥0） | 并入 A，且为**硬约束**而非目标 |
| 长期财富最大化 | 轴C | 与 R 合并（解决双目标冲突用AV） |
| 风险调整后财富最大化 | 轴C（=AV/CE 等价） | 并入 C |
| 创业期权价值 | 轴C 内部（真实期权项） | 非独立资产，见 Q3 |
| 生涯稳定性 | 轴B 内（=人力资本持续性×低σ） | 并入 B |
| 未来迁移/路径空间最大化 | 轴B 内（=可迁移性维） | 并入 B |
| 被迫接受低质工作概率最小化 | 轴B（=再就业质量底线约束） | 作为**约束**不入目标 |
| 未来有效路径空间最大化 | 轴B内（=期权/可迁移） | 并入 B |

**结论**：9 个目标不是 9 个独立维度。真正线性无关的只有 **3 条轴**；其中若干"目标"（生存、低质工作）在当前阶段应当**从目标降级为硬约束**。因此：

> **Personal EGS 采用「目标向量」，不是一个加权标量**——但该向量在主目标轴上仍收敛为一个经济学的经典标量：**生命周期效用** `E[Σ βᵗ u(Cₜ)]`（Modigliani–Friedman–Merton-Samuelson 体系）。目标向量是对这个单一效用目标在"转型-稳定-积累"三个阶段做**约束门控与权重门控**后的实现形式。理由：加权和目标里的高风险-高回报替代无业空窗期不安全；只有把"生存"做成乘积型门控（0-1），才能让主观进取不违背当前存活优先。

### 2.2 三轴定义（可计算形式）

令决策集 `x ∈ X`（现金/股权/教育/求职等支出的组合），对各阶段阶段权重 `wᵢ(Stage)`：

```
maximize_x  V(x) = w_A·U_A[runway(x)]  +  w_B·U_B[ΔPV_HC(x), reentry(x)]  +  w_C·U_C[E[W], σ(W)]
s.t.        runway(x) ≥ R_min           （生存/跑道：硬约束，每期强制）
            burn_flag: C2 未解除前，可投资资产转股权的比例有上界
```

- **轴A（生存/跑道）**：`runway = Financial_Capital / 月burn(×h(到再就业的期望月数))`；`U_A` 用生存概率 = `Φ`(跑道超期次数)。**乘积门控**：`I[runway≥R_min]`，缺口→整项归零。
- **轴B（人力资本/再就业）**：`ΔPV_HC = PV_HC(投资后) − PV_HC(现) − 直接成本`，叠加 `reentry`（再就业概率与速度、质量底线）。Becker 投资逻辑：教育/转码投入若内部回报率 IRR＞机会成本才做。
- **轴C（长期风险调整财富，含创业期权）**：用**均值-方差/Merton**形式 `U_C = E[W] − (γ/2)·Var(W)`（等价于 CARA 对数贴现），且股权暴露上限由人力资本-债券化逻辑决定（Choi-Liu-Liu `/∝ Merton share`）。创业期权为 C 内部的可扩张/等待期权项。

### 2.3 阶段权重表（权重=该轴对总V的边际贡献权重）

| 阶段（Stage） | 判定条件 | w_A 生存/跑道 | w_B 人力资本/再就业 | w_C 长期风险调整财富（含期权） |
|---|---|---|---|---|
| **转型期**（当前） | 无工资、求职中 | **0.55（+硬约束门控）** | 0.35 | 0.10 |
| **稳定期** | 已再就业或研究生在读、收入恢复 | 0.30 | 0.40 | 0.30 |
| **高收入积累期** | 收入稳定×成长进入积累 | 0.15 | 0.25 | 0.60 |

> 权重含义：转型期"活着+保住人力资本可迁移性"占 ~9 成支配地位；长期财富被刻意压到 0.10，是为了**不鼓励在无收入期冒险加杠杆博收益**。稳定期再就业确定性上升后，股权暴露才按 Merton 公式放开。

**可操作分配器（转型期的"钱怎么摆"）**：
1. 先提 **Safety Capital**：`6–12 个月burn`（无业期取上限，8–15 万量级）——满足 R_min 硬约束。
2. 扣除研究生学费承诺与求职现金需求。
3. **仅剩的余量**才进入股权（指数/宽基 + 少量自选），且此余量设定"进取"上限（如 ≤ 剩余可投资部分的一定比例），回到稳定期前不追加。

## 三、Q2 资产类别判定表（10 类：可计量/半计量/纯概念/重叠）

结论先行：**多数条目不是独立资产，而是某一主体资本的重叠表达或估值视角。**

| 类别 | 判定 | 重叠关系 | 当前可计量等级 |
|---|---|---|---|
| **Financial Capital** | ✅ 可独立计量 | 无（基准资产） | L1（用户给定 10–30 万） |
| **Human Capital** | ✅ 可独立计量 | 是最大资本，承载 B 轴全部 | L2（模型）/L3（输入需核实） |
| **Safety Capital** | ⚠️ 半独立 | **只是 FC 的一项"指定用途劈分"**，非独立资产 | L1 劈分（target 6–12月 burn） |
| **Re-entry Capacity** | ⚠️ 半独立 | **=人力资本的"可转换性×再就业渠道"维度**，非独立资产；内含/出口于 HC | L2/L3 |
| **Option Value** | ❌ 纯概念 | **不是资产，是所有"未来选择"的估值方法**（真实期权视角），跨 B/C | —（用途=Q3 定价法，非科目） |
| **Business Capital** | ❌ 现阶段≈0 | 与 IP/期权重叠；对象目前无企业/创业现金流 | L3（量级≈0） |
| **IP** | ⚠️ 半计量 | 与 Business/Reputation/Network 高度重叠 | L3（代理：可见技术产出） |
| **Reputation** | ❌ 潜在、难独立计量 | 与 Network/IP 重叠 | L3（疫情代理） |
| **Network** | ⚠️ 半计量 | 与 Reputation 重叠；对再就业有可计量代理 | L2/L3（引用/内推概率代理） |
| **Physical Assets** | ✅ 可独立计量（但小） | 无 | L2（设备、1–5 万） |

**重叠合并后的"真正独立科目"只有 4 条**：
- **Financial Capital**（含 Safety Capital 劈分）
- **Human Capital**（含 Re-entry Capacity）
- **Physical Capital**
- **Social/Credential Capital**（Network×Reputation×IP 输出，作再就业乘数代理，非现金科目）

**Option Value/Capital** 不入资产负债表资产栏——它是给"未来路径"定价的方法学透镜，落在 Q3。

## 四、Q3 估值公式（对象实例化，货币单位=人民币万元）

### 4.1 人力资本 PV（Becker/Mincer + 生命周期贴现）

> 依据：Becker 1964（NBER）人力资本=未来收入现值；Mincer 学历回报 ~7–10%/年；Ibbotson–Milevsky–Chen–Zhu（CFA 2007）：<50 岁人力资本主导。失业期用"再就业概率加权"的两态凸组合。

```
PV_HC = P_re · Σ [E[Y_{AI,t}]·(m_sustain·m_transfer)]/(1+r)^t  +  (1−P_re)·PV_fallback
```

- **P_re**：12 个月内再就业概率（AIOps/大模型应用需求高 + 3年数据经验）≈ **0.6–0.8**（L3 待核实）
- **E[Y_AI]**：再就业年收入（AI/大模型应用=Deployment 工程，经验3–5年）**20–35 万**区间（L3 待核实）；折现起点取对象进入稳态期（如半年后入职）
- **g**=4–8%（成长）；**r**=8–12%（技术岗位不确定性高，取中高）
- **m_sustain**=0.7–0.85（非 CS 本科+LLM 迭代快 = 持续性风险溢价）；**m_transfer**=0.8–0.9（Python/SQL 可迁移，且正式切入 AI 上扬赛道）
- **T**≈28–32 年（31→~63）

**对象实例化（中情景：Y0=25 万、g=6%、r=10%、m=0.8、P_re=0.7、T=32）**
```
PV_full = 250000·0.8 /(0.10−0.06) × {1 − [(1.06)/(1.10)]^32}
        = 200000 × 25 × 0.695 ≈ 347 万（满就业确定性口径）
PV_HC ≈ P_re × 347万 ≈ 240 万；计入 fallback 尾部 ≈ **200–300 万**
```
> **量级结论**：人力资本现值约 200–300 万，是金融资本的 >10 倍——与文献"30 多岁人力资本主导资产负债表"一致。这是生命周期配置理应"高股权"的底层原因，**但被转型期生存约束临时压制**（见 Q1 门控）。

### 4.2 金融资本（可市值）
```
FC = Σ 市值 − Σ 负债 = 现金+存款+基金+股票 − 任何贷款
```
当前 **10–30 万**（L1，用户给定）；负债假设≈0（L3 待核实）。

### 4.3 人力资本投资（非全研究生 + AI 转码）回报（Becker IRR）
```
NPV = −Cost + Σ_{t} ΔY_t/(1+IRR)^t ≥ 0  ⇔  IRR ≥ 机会成本(r≈8–12%)
```
- **Cost**：学费（非全日制总 **3–10 万**，L3 待核实）+ 打工/学习时间的机会成本（无业期=零工资，机会成本由求职推迟量衡量）。
- **ΔY**：学位与 AI 应用技能包带来的收入增量 **5–15 万/年**（L3，取决于能否落地项目/作品集）。
- **关键判别（可操作的投决）**：对无业对象，**推动 PV_HC 的主杠杆不是那张学位，而是"可上线的 LLM 应用作品 + 作品集证明力"**；学位提供资质背书与可迁移性，而非直接收入。故教育支出的审批权应连到"是否提升 P_re 与 m_transfer"这两个可观测输出，而非"学历本身值钱"。

### 4.4 期权价值（真实期权，Damodaran / marketopia 框架）
创业/副业期权不做"一次性投入"，而做"分阶段看涨"：
```
OV_option = P(success) · E[payoff|success] · (状态点—是否现期行权) − 转换成本
```
- 对象当前创业期权：**行使成本极高、确定性空窗期强**，应作为"等待/扩张 + 学习"期权（Damodaran 的 learning + adaptive + exclusivity）持保留。换算成策略：用**低成本探索**（开源 LLM 项目、接 AI 外包单、公开发布技术产出）以最小现金消耗**买下未来行权资格**，而非现在辞职创业。
- 量级：现阶段 ≈**0–20 万**（L3，纯期权意义），且不进入负债/资产主表。

### 4.5 再就业能力 & 网络/声誉
```
Re_entry ≈ P_re ≤τ · Σ 折现再就业收入 − (求职成本 + 储备消耗)     （内含于 PV_HC）
Reputation/Network 代理 = 再就业概率增量 × 折现收入增量            （L3，代理计量）
```

- 经济净值 ≈ **200–310 万**，其中人力资本占 **~85–92%**，金融资本占 ~8–10%——与该年龄生命周期理论的资产结构一致。

**B 级（机构方法论/实践综述，非独立学术文献）**
- TIAA–Nuveen Lifecycle Funds HC/FC 方法论 `tiaa.org/public/pdf/lifecycle_funds_methodology_and_design.pdf`
- CFA Institute Enterprising Investor（1 Jul 2026）— 人力资本贴现率解析
- Financial Planning Pyramid（financestrategists.com）— 应急基金→积累的阶段层级

## 七、可证伪命题 / 缺口

**可证伪命题（都可被观测数据推翻）**
1. **再就业速度+质量**：对象应在 ≤12 个月内再就业，且首份 offer ≥ 3 年数据经验的合理对标（约 ≥20–25 万/年），P≥0.6。→ 若 >12 个月或薪资显著低于该档，则 B 轴假设与 P_re 需下修。
2. **人力资本主导**：只要在就业，PV_HC ≫ FC（~10×）。→ 若转码后多年收入未涨，则 m_sustain/m_transfer 或 g 过高，模型需重估。
3. **生存门控可观测**：若 C2 未解除时，对象把金融资本的股权比例提到触发行权（如条件触发后仍重仓高波动），则该行为违反模型硬约束 → 行为-模型失配。
4. **稳定期 Merton 推论**：恢复收入后，股权比例应显著高于常青 60/40（年轻+人力资本=债，`) 应接近 80–100%`）。→ 若稳定期仍长期持有超高现金，说明模型的风险溢价或 γ 设定与真实偏好不符。

**缺口（L3 待核实，建议对象补数以封闭模型）**
- 真实月 burn 与剩余跑道精确值
- 有无存量负债（贷款/信用卡）
