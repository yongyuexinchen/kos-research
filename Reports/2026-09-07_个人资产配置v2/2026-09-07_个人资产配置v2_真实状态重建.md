## 三、v2 核心矛盾（必须先摆出来）

**两个对冲压力同时存在**：
1. **求职安全垫需求**（2027/01-06，无收入）→ 需要现金增厚
2. **抄底弹药需求**（2026Q4-2027Q2 AI 泡沫窗、猪价反转2027）→ 需要现金囤积

**当前 400/日 的定投流向两个口径重复的资产（创新药+黄金），恰与这两个现金需求冲突。** 这是 v2 要纠正的第一个失衡。

## 四、25 万存量配置（v2 定稿）

> 原则：**存量保流动性，流水建长期仓**。存量不参与日定投的赛道重叠。

```
┌─ 存量池（25万）─────────────────────────────┐
│ L0 活期/货基（安全垫）:   40-50%  = 10-12.5万 │
│     用途：2027 H1 求职+下行 18-24 个月生计       │
│     （月支1000计，实际只需1万/年，余上浮为心理垫）   │
│                                              │
│ L1 现金弹药（抄底池）:     25-35%  = 6-8.75万   │
│     用途：2026Q4-2027Q2 信用侧破裂信号出现后       │
│     分批进：①AI应用赢家(出清后) ②创新药大跌加仓 ③猪价确认后牧原/温氏 │
│                                              │
│ L2 黄金 底仓（对冲/尾部）:  8-12%  = 2-3万      │
│     存量一次性建底（不必都靠日定投）                │
│ L3 创新药 核心底仓:        8-12%  = 2-3万      │
│     存量一次性建底（减少对 300/日 的依赖）           │
│ L4 储备/未分配:            0-5%               │
└──────────────────────────────────────────────┘
```

**关键区别 vs 库内四层**：库存原有的"水电现金流层"因长电未持仓+股票清仓，在 v2 里降为**弹药候选**而非现持仓——先保现金，弹药里再考虑。

## 五、日定投流水重配（v2 定稿）

倒置视角：与其"每天机械打 400"，不如把日定投理解成**向弹药池输送的增量 + 底部区的左侧建仓**。但当前强度偏高，需压：

| 流水项 | v1 现状 | v2 建议 | 理由 |
|---|---|---|---|
| 创新药 300/日 | ~6.6k/月 | **→ 150-200/日**（~3-4.4k/月） | 存量已在 L3 建底，降流水强度；勿与 25 万存量赛重叠 |
| 黄金 100/日 | ~2.2k/月 | **→ 保持 100/日** 或拆为存量后降 50 | 黄金尾部对冲价值高，但存量建底后流水可降 |
| 合计 | 400/日 ≈42%/年 | **→ 200-250/日 ≈21-26%/年** | 释放 ~15 万/年 增量给现金弹药 |

> **为什么压**：当前求职在即、无收入、25 万是全部缓冲。42%/年的定投强度会同时掏空安全垫和弹药池。压到 ~22%/年，把省下的现金留给 2027 抄底窗和失业缓冲。**"日定投"应是长期仓的左侧建仓工具，不是唯一建仓方式——存量一次性建底更优。**

## 七、求职期的现金节流（v2 特别章）

当前 25 万、月支出 1000，理论缓冲 20 年——但若求职空窗 + 高位定投，缓冲会被流水掏空。v2 硬约束：

1. **求职期（2027 H1）现金覆盖率不得低于 15 万**（≈60% 存量）——安全垫优先
2. 日定投强度 **暂停或减半**（该 200-250/日）在求职空窗期，恢复收入后再回升
3. 任何抄底动用弹药前，先确认现金仍 ≥15 万
