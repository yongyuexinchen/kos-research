## 一、本轮专问（不再问"2035 年什么行业最火"）

$$
\boxed{
\text{一个人在 30 岁进入某条职业路径后，什么能力会随着时间增加而不是衰减？}
}
$$

$$
\boxed{
\text{当技术、产业、政策不断变化时，什么能力使一个人能够不断重新进入新的奖励函数？}
}
$$

最终目标：找到一个 30 岁左右、具有大数据背景的人，在未来 5–15 年可以持续升级、持续获得奖励、且在产业变化后仍然拥有选择权的能力结构。

## 三、KOS 调研规范（强制，承 v1-v4）

1. **证据分层**：A（官方原始/法规/正式文件）｜B（高质量学术论文）｜C（可靠媒体/行业研究）｜D（二手评论）｜E（推论/理论假设）。EGS-B 三轮已声明：**逐年宏观数据当前无 A 级渠道可核**；个人层 JD/薪资数据多为 C-D 级。
2. **不预测 2035 年具体职位名称**——只预测能力层级。
3. **不使用未经历史验证的阈值**——Radar v2 只保留领先指标方向，删除任意数值阈值。
4. **不允许把"架构能力不可替代"当断言**——必须找证据。
5. **必须区分 Skill/Capability/Responsibility/BargainingPower 四层**——不允许混用。
6. **核心结论用盒式公式标注**。
7. **数量/统计断言必须带来源编号**，无来源的推断标 `[INF]`。
8. **双导出铁律**：本轮只产报告于 `Research/Reports/2026-09-07_PersonalEGS能力复利/`；不直接动知识层/认知层/演化层/行动层。

## 五、统一符号（沿用 v1-v4 + 本轮新增）

| 符号 | 定义 |
|---|---|
| $S(t)$ | Skill 价值（具体技能资产，快速折旧） |
| $C(t)$ | Capability 价值（解决问题能力，慢折旧或复利） |
| $\text{Resp}(t)$ | Responsibility 价值（承担系统结果能力，复利） |
| $B(t)$ | BargainingPower（议价权，组织缺这个人的损失） |
| $S \to C \to \text{Resp} \to B$ | 长期复利链 |
| $\text{CapabilityDensity}$ | 跨系统可解决的问题数 / 核心技能数 |
| $\text{Capability}_{\text{portfolio}}$ | 组合能力（A+B > A+B） |
| $\text{MigrationValue}$ | 从旧技术切换到新技术的速度 |
| $\text{LEGS}$ | 长期 EGS 分数 = $R_{\text{current}} \times \text{Persistence} \times \text{Transferability} \times \text{OptionValue} \times \text{Reversibility}$ |
| $\text{Penalty}$ | $\text{AutomationRisk} + \text{AgeRisk} + \text{Lockin} + \text{IndustryRisk}$ |
| $\text{NetLEGS}$ | $\text{LEGS} - \text{Penalty}$ |
| $\text{Robust Capability}$ | 三情景（Bull/Base/Bear）下都成立的能力 |
| $\text{AgePremium}_{\text{execution}}$ | 执行型岗位年龄溢价/折价 |
| $\text{AgePremium}_{\text{decision}}$ | 决策型岗位年龄溢价/折价 |

## 六、Skill / Capability / Responsibility / BargainingPower 四层定义

| 层级 | 定义 | 示例 | 折旧速度 |
|---|---|---|---|
| Skill | 具体技能 | SQL/Python/RAG/LangChain/Docker/K8s | 快 |
| Capability | 解决问题能力 | 数据系统设计/分布式系统/AI 系统设计/性能优化/成本控制/可靠性设计 | 慢 |
| Responsibility | 承担系统结果能力 | 对系统稳定性负责/对成本负责/对业务指标负责/对安全负责/对技术路线负责 | 复利 |
| BargainingPower | 个人在组织中的议价权 | "如果没有这个人，会损失什么？" | 复利 |

## 八、最终评价指标（用户拍板）

$$
\boxed{
\text{NetLEGS} = \underbrace{R_{\text{current}} \times \text{Persistence} \times \text{Transferability} \times \text{OptionValue} \times \text{Reversibility}}_{\text{LEGS}} - \underbrace{(\text{AutomationRisk} + \text{AgeRisk} + \text{Lockin} + \text{IndustryRisk})}_{\text{Penalty}}
}
$$

不输出伪精确数字，使用：
- 高 / 中 / 低
- 或 0–5 级区间

## 九、三情景定义

| 情景 | 定义 | 关键变量 |
|---|---|---|
| Bull | AI 继续快速扩散，新应用持续涌现 | AI 渗透率 5 年内 > 60%，新岗位创造 > 消灭 |
| Base | AI 成为基础设施，技能逐渐普及 | AI 渗透率 5 年内 30-50%，岗位创造 ≈ 消灭 |
| Bear | AI 自动化速度远超岗位创造 | AI 渗透率 > 50% 但消灭 > 创造，初级/中级岗大幅减少 |

> Robust Capability = 三情景下都成立的能力。
