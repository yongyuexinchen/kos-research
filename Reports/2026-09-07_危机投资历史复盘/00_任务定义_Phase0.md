# 重大金融危机·投资历史复盘 · 任务定义 Phase0

> 日期：2026-09-07 ｜ 主题：各重大世界性金融危机期间/之后的"好投资项目"——不是罗列暴富故事，而是拆出**可迁移的机制规律 + 揭穿幸存者/回填偏差**。
> 前置基线：结合库内"配置全景认知图谱"（用户：现金弹药＋黄金腿＋创新药/A股，等2027-28 AI出清抄底）与"黄金EGS深度调研/美债温水煮青蛙"。
> 方法：KOS——不预设"危机期买某资产一定赚"，主动找反例；真实数据优先 L1/L2；相关性只给 高/中/低；不造伪精确；区分「危机中」vs「危机后」两个完全不同时点。

## 一、范围与边界

**只做一件事**：对几次代表性重大金融危机做**资产表现历史复盘**，回答：
1. 各危机场景（通缩/滞胀/金融秩序重构）中，哪些资产真抗跌、哪些真赚钱？
2. 危机**期间** vs **危机后**（宽松期）的盈利机会有何不同？（时点错配）
3. 有哪些"事后看起来涨"是靠幸存者/回填偏差制造的假象？
4. 沉淀出可迁移的**场景×时段×资产**规律，映射到用户当前组合。

**不做**：不给当下买卖仓位；不把历史线性外推为"本次也会如此"；不因"危机期黄金涨"就暗示"现在该买金"。

## 二、调研分路（三路并行 Agent）

| Agent | 覆盖 | 核心问题 |
|---|---|---|
| A | **1929大萧条 + 1930s**（典型通缩危机，含金本位/斯姆特霍利关税） | 通缩危机下黄金/现金/美债/房地产/大宗谁抗跌？金本位下"黄金保值"的真实含义？ |
| B | **2000互联网泡沫 + 2008次贷**（通缩+金融秩序冲击） | 危机分阶段(火花/火海/救火)各阶段资产表现？黄金为何在雷曼处暴跌又后大涨？债/REITs为何在两次危机表现相反？ |
| C | **避险场景规律归纳 + 时点错配 + 幸存者偏差** | 构建"通缩/滞胀/金融秩序重构×资产"排序框架；区分危机中/后机会；识别流程图伪收益 |

## 三、研究纪律（每个危机强制输出）

1. **量化资产表现**：黄金/现金/美债/股票/房地产/大宗 的累计涨跌（带数据来源 L1/L2）。
2. **分阶段**：危机起→爆发→救火→复苏 各阶段谁涨谁跌（尤其黄金在流动性脚踏期会跌）。
3. **反例/失效**：什么证据说明"某资产在某场景不灵"（如 REITs 两次相反）。
4. **幸存者偏差**：标记哪些"暴富故事"是回填/半成品（如 1929 黄金收益实际归财政部）。
5. **映射**：结论如何落到用户"现金+黄金+创新药/A股、等出清抄底"的处境。
