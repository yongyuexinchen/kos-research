> 日期：2026-09-08 ｜ 职责：将 KOS 组合纪律翻译为分解到金额/比例的仓位数学，输出同源上限、国别敞口总控、风险敞口表与最大理论回撤预案
> 口径：**目标比例法**——金额 = 比例 × 基准（全部资产 25 万）。所有金额为**参考金额**，需按实时行情与用户实际现值校准，**禁伪精确**。
> 输入：Phase0 任务定义 + 各 EGS 合成裁决（福耀/海尔/迈瑞/联影/华明/三花/TCL）+ 双系统整合。

## 一、口径声明（比例法 + 需校准点）

1. **基准与可用资金**：总资产 25 万 = 现金约 24.3 万可投入 + 已投定投约 7000（创新药 300/日 + 黄金 100/日）+ **已有三一 8000 股票头寸**（不在本轮新增腿内，但计入国别敞口）。三一 8000/25万 ≈ **3.2%**，按既有头寸处理。
2. **单位换算**：下文每腿给出 `目标比例 → 参考金额（=比例×25万）`。单票金额按**目标价建仓参考**，非一次性满仓；实际下单挂单价见 Agent3，比例上限以表格为准。
3. **禁伪精确声明**：① 三一/思源已成交价与现值为用户私有数据，未纳入计算，仅按名义 3.2%/既定条件单预留；② 各标的 β 为粗估区间，用于回撤量级判断，非精确实测；③ 相关性为**结构判读**（同 source/同行业/跨行业），无协方差数据支撑，属 L2/L3 估算。
4. **进攻腿当前 0 仓**：券商/恒科/创新药换质/面板，双开关（AI 出清 + 实际利率转负）未开时**只预埋预案、不落单**，其份额不占已配置空间，作为"弹药"计入现金。

## 四、国别敞口总控计算

出海多腿（福耀/海尔/迈瑞/联影/华明/思源/三花/三一）共享"**中国制造出海 / 赚美元人民币报表**"这一 source——**能分散行业周期、不能消除国别风险**（2026H1 海尔-7.0 亿 vs 福耀-8.03 亿汇兑同时受损即为实证）。

**合并国别(os)敞口（目标口径）**：
- 福耀10 + 海尔6 + 迈瑞6 + 联影2 + 华明4 + 思源4 + 三花3 + **三一(既有)3.2** ≈ **38.2%**

**建议国别敞口总控数字**：
> **出海合并敞口总上限 = 40%（含既有三一约3%权益）。双开关触发、创新药换质/恒科叠入激进仓后，仍严格压住"出海 source"≤40%，总高β加总不破该上限的激进预案另立账。**

理由：
1. 出海总体 = 本组合"压舱+进攻双主线的共同权重股"，是 D 级短板对冲的正向暴露，但**同 source 多腿相关性在系统性冲击（人民币急升/美欧准入收紧/关税再超预期）时趋同**，必须设总量级的"伪分散天花板"。
2. 40% 略高于当前 38.2%，为三花/思源右侧加仓留 2% 余量；若突破 40% 须以减其他低性价比出海腿（如海尔→福耀换仓）对冲，而非无上限加新。
3. 黄金 10%、现金 51% 为精确的**非出海反保险**，是对冲国别集中的第二层独立缓冲。

## 六、最大理论回撤推算与预案

**方法**：组合加权 β × 市场回撤 + 高β尾部（相关性趋同修正）。全资产口径投资占比 49%，权益（不含黄金）约 39%。

**抽样回撤推算（全资产口径）**：
- 权益加权 β ≈ (福耀10×0.7 + 海尔6×0.6 + 迈瑞6×0.9 + 联影2×1.4 + 华明4×1.1 + 思源4×1.3 + 三花3×1.5 + 创新药4×1.3) / 38 ≈ **0.99**
- 场景A·市场温和回调 -10%：组合 ≈ -0.39×10% ≈ **-4%**（≈ -1.0 万）
- 场景B·深度熊市 -30%（出海相关性趋同，高β衰减更深）：组合 ≈ **-11%~-14%**（≈ -2.8~-3.5 万）
- 场景C·极端（深度熊 + 高β期权归零：联影/三花/思源/创新药约11%仓位跌 45-50%）：
  - 基础股 -11%~-14% + 高β尾部贡献约 -4%~-5% ≈ **-15%~-18%**（≈ -3.8~-4.5 万）

**回撤预案（四级）**：
1. **现金 51% 是首要缓冲**：深度回撤时现金≈12.75 万即"越跌越买"弹药，天然空气袋。
2. **高β闸门自动降险**：联影（北美连续两半年负=撤）、迈瑞（毛利<57%/国际<10%）、华明（电力设备毛利破55%/海外无α）、三花（止损<21）、TCL（破 3.9-4.0 前低）独立证伪即减，不完全依赖大盘判断。
3. **防御承接**：黄金 10% 在股票系统性下行时提供低相关对冲，福耀/海尔类债高股息承接现金流。
4. **回撤硬约束**：单腿回撤超 -20% 即触发"再评估而非摊平"程序（证伪 vs 机会），**绝不单腿无上限加仓**（不押单一、分批不割一刀）。

## 七、需用户校准的输入清单

以下为数据缺口或私有数据，落地前必须由用户填现值校准（禁伪精确）：

1. **总资产现值**：是否仍为 25 万？三一 8000 是否已成交/现价多少？总资产= 现金 + 定投现值 + 股票现值，需重算比例基准。
2. **定投累计现值**：创新药 300/日、黄金 100/日已累计金额与当前占比（口径将"已投约7000"拆实）。
3. **思源 132 条件单**：是否已触发成交？成交价与仓位是否=4%（1 万）？
4. **权限**：是否已开通创业板（迈瑞）/科创板（联影）？未开通则医疗段按 ETF β 或让位（≥4% 需回填）。
5. **H股/港股通**：福耀 H（14.9x/4.4%）与海尔 H（9.56x/6.4%）性价比优于 A 股，是否具备港股通通道？偏好直接影响两腿成本与股息。
6. **单票风险偏好**：能否承受单腿回撤 -30%~-50%（联影/三花/思源/TCL）？决定高β合计是否压到 5% 以下。
7. **双开关实时指标**：10Y TIPS（现 2.4% 高位）与 AI 出清信号的最新读数，决定进攻腿（券商/恒科/创新药换质/面板≤3%）何时从 0 仓转正。
8. **面板周期触发器**：Q4 面板价企稳 / TCL光伏减亏转盈 / OLED进展，决定面板 0→3% 的右侧买点。
