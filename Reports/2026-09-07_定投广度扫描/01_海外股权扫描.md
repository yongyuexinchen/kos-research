# 01_海外股权扫描
**维度：海外股权（美股宽基/纳指/全球ACWI/新兴市场/日股）**
**立场：用户已持有 黄金(货币信用/实际利率源)、创新药(医药产业链/A股/人民币源)、水电(电价/A股/利率源)、大笔现金(等待2027-28 AI出清抄底)。**
**日期：2026-09-07**
**数据口径标注：[L1]官方/交易所一手；[L2]多个独立来源聚合；[L3]模型/专家判断。绝未用训练知识冒充2026实时数据。**

---

## 0. 执行摘要（核心裁决）

1. **海外权益"有资格"进下一轮，但"当前不是无脑定投窗口"**——因为它和用户正在"等"的那场坍缩是同一枚硬币的两面：用户要抄的"AI出清底"，主要就在纳指/美股科技/日股AI链上。现在的关键不是"要不要海外权益"，而是"**溢价税 + 高估值 + 出清未发生**"三者叠加不适合现在重仓。
2. **真正的价值不是"分散"，而是"换了一个 Reward Source"**：海外权益给用户引入用户目前最缺的**美元计价 + 全球企业盈利 + 全球科技资本开支**奖励源，同时给大量人民币现金提供**汇率/主权信用对冲**。回避"美股一定优于A股、全球一定分散"的预设。
3. **最大伪分散风险**：纳指/日股AI链/新兴市场(tech权重已40%)/标普里的AI权重/A股AI算力映射——这些**在"全球AI资本开支+全球流动性"上几乎同源共振**，相互之间不是分散，是换皮。而**纳指与用户的A股创新药不是伪分散**（AI资本开支 vs 医药BD/临床兑现，是两条不共振的链，且创新药在2026年AI崩盘时恰好是资金切换的方向，经验上近似负相关风格）。
4. **执行层硬约束在"溢价"，不在"观点"**：2026-09-07 纳指类场内QDII溢价11%-25%，标普500溢价8.9%；而日经225ETF、中概互联几乎无溢价。**溢价本身就是一个可交易的"情绪税"，高溢价进场等于未开战先缴税。**
5. **优先级建议**（见 §6）：日股(低溢价/费率低/独立增量)＞美宽基/标普500(场外联接，等溢价回落)＞中概H股/恒生(便宜但属"人民币/A股科技"源,非美元分散)＞纳指(11-25%溢价,暂缓,列入2027-28 AI出清右侧候选)＞纯ACWI/新兴(境内可得性差,且已科技化)。

**核心检测——纳指 vs A股创新药是否伪分散？**
- **结论：不是伪分散。** 纳指 reward源是"全球AI/半导体资本开支+流动性"；A股创新药 reward源是"全球药企License-out买方付费+新药临床兑现+国内医保/政策报销"。前者由云厂商/大模型 capex 驱动，后者由跨国制药 BD 预算和临床数据驱动，不是同一根导管。
- **经验佐证**：2026-06-23 全球AI硬件崩盘(韩股熔断、SpaceX跳水、英伟达租赁价回落)当天，A股创新药/CRO/化学制药逆势大涨，成为资金从AI高位撤出的"新进攻主线"（[L3]复盘剧评）。这说明两者的风格相关性甚至**接近负向换仓关系**——在AI崩盘时创新药反而是受益切换方向。
- **判定数据项**：要量化，应取近5年「A股创新药指数(如国证创新药/中证创新药产业)周度收益」对「纳指100周度收益」回归，观察 beta 与滚动相关；同时拆出"全球医药BD金额季度同比"作为创新药独立验证器。**本报告未做该回归，故只给"中-"级别判定。**

**伪分散的红线**：用户若标的是"海外科技"，则与其**尚未持有的A股AI算力板块**、以及**全球AI链条上的日股/新兴tech**高度同源。当用户在2027-28"AI出清"后抄底时，**纳指、日股AI链、新兴tech、美股AI权重是同一个底**，不能当成四个独立的分散点。

## 4. 反例 / 失效场景（Common Shock 与"证伪信号"）

**Common Shock（会让海外权益与用户组合一起坏的冲击）**

1. **全球AI泡沫同步破裂（最危险的Common Shock）**
   - 触发已现苗头：2026-06 博通下调AI指引→全球算力重估、韩股熔断、英伟达/内存股回落；2026-08 Anthropic年化收入预期增速落空→美债长端利率上行的同时，全球科技股齐杀（[L2]上海证券报/市场复盘）。
   - 传导：纳指、A股AI算力/光模块映射、日股半导体设备链、新兴tech(台积电/三星)、标普AI权重 **一起跌**。此时"海外权益"内部毫无分散可言，是同一个 Reward Source（AI capex）的换皮。
   - 与用户组合的关系：**创新药/水电相对独立**（药企BD与电价不依赖AI）；**黄金在流动性危机初期可能被抛售（现金为王的短暂阶段），随后避险回升**。这印证用户现有组合（金+创新药+水电）恰恰是"对冲AI单点"的布局，而**盲目加海外科技会把独立点重新合成一个AI点**。

2. **全球流动性收紧/加息（美元实际利率上行）**
   - 2026年内主线反复：沃什偏鹰+8月非农超预期→9月FOMC加息概率一度60%；30Y美债5.3%创新高时全球科技齐调（[L2]多家券商）。
   - 影响排序：纳指(最长久期)＞标普＞新兴/日股。**日股因金融业受益加息反而相对抗跌**——这是它区别于美股AI的新增正交属性。

3. **美元流动性危机 / 强美元+人民币贬值的"既要又要"**
   - QDII持有美元资产在"人民币升值+境外资产估值压缩"双向时受损；若人民币趋势性升值（中国AI出清后复苏），**高溢价买入场内QDII=溢价税+汇兑双重损耗**（[L2]北京商报列四重风险）。

**哪个新证据会推翻"值得定投"：**
- QDII场内溢价持续 > 10% 且无法回落（情绪税固化）；
- 美股 fwd P/E 重新上行破 22-23× 且盈利预期同步下修（估值与盈利负反馈，历史仅在2000/疫情后出现并随后熊市）；
- 云厂商 capex 与积压订单增速持续背离 / AI收入回款低于资本开支投入（已有从+150%订单回落到+80% capex的收敛迹象，需持续盯）；
- 美联储确认转向加息路径。

**哪个新证据会让"值得定投"成立（才适合恢复）**：见 §6 阈值。

## 6. 结论：资格 + 优先级 + 阈值信号

### 6.1 有没有资格进下一轮？
**有资格，但以"右侧/低溢价/小仓位"进场，而非当前无脑定投。** 对"满手人民币现金+等待AI出清"的用户，海外权益的真正补贴点是：给 ①美元计价 ②全球企业盈利 ③全球AI/科技资本开支 三个当前缺失的 Reward Source 开一个小口，并给人民币现金做汇率/主权对冲。**它不该被当作"多拿了几个A股板块"，而应被当作"买一张用户在2027-28想抄的那个底的期权"。**

### 6.2 优先级排序
1. **日股(日经225/TOPIX，513880等)**——工具损耗最小（低溢价+费率0.2-0.3%）、Reward有独立第二引擎(走出通缩+金融受益加息+设备链)、与美股AI低相关。**第一批小仓位(如3-5%卫星)可建，或作右侧观察锚。**
2. **美宽基/标普500**——估值处10年中位，Reward最综合。**用场外联接定投（≈0溢价），或等场内溢价回落<3%再说。**
3. **中概H股/恒生(513050等)**——便宜无溢价，但属**人民币/A股科技源**，补不了美元分散；若想给"A股"加敞口可买H股（AH溢价约119-122，H股更便宜），**但不列入"海外分散"栏**。
4. **纳指100**——Reward最纯粹但当前**溢价11-25%+PB 94分位+出清未发生**，三重损耗。**暂缓；直接列入 2027-28 AI出清右侧的抄底候选池。**
5. **纯ACWI/纯EM**——境内可得性差，且新兴已科技化(tech 40%)与纳指重合。**低优先。**

### 6.3 阈值信号（何时才恢复定投/加仓）
- **溢价gate（优先级最高）**：场内QDII溢价 **≤3-5%** 才进场；不满足则用场外联接或暂缓。（当前纳指+12~25%触发"暂缓"，标普+8.9%触"用场外"，日股可。）
- **估值gate**：标普500 转发fwd P/E **回落至 ≤18-19×(10年中位之下)**，或纳指 fwd **回落至≤20×** 再恢复；当前标普≈20、纳指≈22.8 属"偏贵但不极端"，宜候更便宜的2027-28。
- **出清gate**：当"云厂商capex/订单增速背离"或"AI收入回款跟不上capex"的证据转正、AI估值则随AI板块回撤后，进入右侧再开仓——这正是用户现金的用途，海外AI权益应与A股AI一起视为"同一个抄底机会"而非分散。
- **反向gate（出现即罢手/减仓）**：美联储确认加息、美股 fwd P/E 破23×、QDII溢价固化>10%。

### 6.4 一句收敛
把海外权益放进用户组合的正确姿势不是"加一个全球分散的指数"，而是"**用可控成本买一张全球AI第二腿（美元/全球盈利）的期权**"——当且仅当溢价税可控、估值回到中位以下、且不把创新药/水电的独立性因"全球科技"重新绑回同一个AI点时，才兑现其 Reward Source 价值。
