# 定投广度扫描 · 任务定义 Phase0

> 日期：2026-09-07 ｜ 主题：在既有组合（黄金/创新药/水电/现金弹药）之外广度扫描"可定投的新资产维度"
> 前置基线：阅读库内 [配置全景认知图谱](../2026-09-07_配置全景认知图谱/2026-09-07_配置全景认知图谱_基线.md)，不推翻既有四层框架，只在其上扩展候选集。
> 方法：KOS 规范——不预设优于、主动找反例、L1/L2/L3 分层、真实数据（WebSearch 优先 L1/L2），不用训练知识冒充实证、不造伪精确数（不用未实证的 0.75/0.80）。

## 一、范围与边界

**本任务只做一件事**：对"除黄金/创新药/水电/现金之外"的资产类别做**广度扫描 + Reward Capture 初筛**，回答两类问题：
1. **正交性**：该资产新增的独立 Reward Source 是否强于它对既有因子的双重暴露（Pseudo-Diversification 检测）？
2. **可定投性**：该资产的长期向上担保、跌后蓄势、定投友好度（波动/费率/标的可得性）是否成立？

**不做**：不给出最终仓位百分比（留给下一轮 Dynamic Allocation）；不推翻既有 F1-F6 与已排除行业表；不推荐个股（除非是当前可定投标的必需载体）。

## 二、扫描候选类（三个 Agent 并行）

| Agent | 类别 | 核心问题 |
|---|---|---|
| A | **海外股权**（美股宽基/纳指/全球ACWI/新兴市场） | 与 A股/人民币是否真正正交？追加美元+美股奖励源的成本？ |
| B | **固收与现金**（美债/中债/货币基金/同业存单） | 补足黄金之外的安全边？在美债温水煮青蛙下中债 vs 美债谁更符合"奖金兑现"？ |
| C | **实物与另类**（REITs/工业金属铜/红利股/公用事业/大宗） | 谁的 Reward Source 跟现有组合最正交？红利/公用是否已与水电重复？ |

## 三、研究方法（每个大类强制输出）

1. **Reward Source 拆解**：该资产真正依赖哪些外部奖励机制（不得"股票=股票奖励源"式浅层）。
2. **正交性检测**：对照卖家现有组合（黄金=货币信用/实际利率、创新药=医药产业链,A股,人民币、水电=电价/A股/利率、现金=购买力）——该资产是"新增独立源"还是"旧源换皮"？
3. **RC 初筛**：用 高/中/低 标 RC 能力；证据不够的标 L3 并说明要什么数据。
4. **反例/失效**：该资产在哪种场景下与你的组合一起坏（Common Shock）？哪种新证据会推翻"值得定投"判断？
5. **标的可得性**：对个人（QDII 限额/实盘平台）是否实际可买、费率如何、有无场内/场外 ETF。

## 五、验收标准

- 每个大类有独立 Reward Source 清单（≥3 源），且与既有组合逐项做过正交/伪分散对照。
- 明确标出"够资格进入下一轮配置"的候选（通常 ≤3 个），并给阈值信号。
- 全程无伪精确数；L3 处明示证据缺口。
