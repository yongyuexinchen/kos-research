# 金盘科技（688676）EGS 担保人/兑现/修复机制审计

**调研日期**：2026-09-07
**现价**：67.91 元 | **总市值**：312.24 亿 | **PE-TTM**：44.78 | **PB**：6.12 | **YTD**：-24.26%
**板块定位**：电网设备出海 T1 第三候选（对照：思源电气 PE 34.17 / 阳光电源 PE 13.67）
**数据口径**：2026 中报 + 公司投关记录 + 券商研报（国信/国海/中诚信等），全部为公开真实数字。

---

## 0. 一句话结论

金盘是高弹性、高纯度、但**当期盈利质量最弱**的"电网出海"标的：订单端确实疯了（海外 +271%、AIDC +336%），但利润端只 +14%，净利率仅 8.4%、半年 ROE 5.7%、经营现金流转负、储能板块毛利仅 5% 还在亏着卖。**EGS 档位：中（偏中高；奖励源真实但兑现质量存疑、地缘尾部风险卷土重来）**。PE 44.78 是三者最高，但它的护城河兑现节奏与盈利能力**配不上这个溢价，属于"情绪成长溢价偏过热"，从风险收益比看明显不如更便宜且盈利质量更高的思源。**

## 1. Reward Source——真正的奖励源是什么？量价齐升真实吗？

### 1.1 核心数据（2026 中报，均真实）
| 指标 | 2026H1 | 同比 |
|---|---|---|
| 营业收入 | 35.56 亿 | +12.73% |
| 归母净利润 | 3.03 亿 | +14.23% |
| 扣非净利 | 2.87 亿 | +16.42% |
| 毛利率 | 27.41% | +1.53pct |
| **净利率** | **8.43%** | +0.09pct |
| **经营现金流** | **-0.24 亿** | **+100%→负，上年同期 +2.35 亿** |
| 加权 ROE（半年） | 5.7% | -0.13pct |

**订单端（奖励源，强烈）：**
- 新签销售订单 **74.93 亿 (+69.31%)**
- 海外新签 **41.90 亿 (+270.69%)**，占总新签 **55.92%**
- 数据中心（AIDC）新签 **38.69 亿 (+336.25%)**
- 在手订单 **106.97 亿 (+41.87%)**；海外在手 **62.39 亿，占比 58.32%（首次破 50%）**；AIDC 在手 **50.92 亿，占比 47.6%**

### 1.2 奖励源拆解（分业务，刻意找反例）
- **① AIDC 数据中心干式变压功率器【真·主引擎】**：数据中心收入 12.65 亿 (+122.57%)，在手订单 50.92 亿 (+179%)。这是金盘最"纯"的亮点——客户是亚马逊/Meta/微软链路、弗吉尼亚本土产能直供。**量价齐升在数据中心侧成立。**
- **② 干式变压器出海（北美配电网配电侧）【真，但被标签化】**：早于 EO 自 1998 年即布局北美，伊利/弗罗里达/弗吉尼亚多地产能，345kV 液浸式已批量发货北美、6 月成功送电。**北美配电变压器缺口→电气设备出海逻辑真实**。
- **③ 储能 /【负贡献，反例实锤】**：储能收入 2.3 亿 **(-23.84%)**，**毛利率仅 5.21%（-4.6pct）**。中诚信/国海明确提示"储能系统毛利率已降至低位"。**金盘的储能不是奖励，是拖累。**
- **④ 数字化（原"数字化整体解决方案"）【萎缩】**：收入仅 0.04 亿 (-30.9%)，毛利 11%，几近消失。

### 1.3 本质差异（vs 思源 / 阳光）
- **金盘更偏"用户侧 / 配电侧 / AIDC 数据中心电源"这一端**——产品是干变（10-35kV，机器装进数据中心内部）、箱变、中低压开关柜、配电变。**恰好是 EO14420 豁免带。**
- **思源更偏"输电主网侧 /（高压 GIS、750/1000kV 主变）"这一端**——产品在禁令"禁区"内，且无美国本土产能（只有墨西哥+常州"外国制造"），EO 冲击是**真利空**。
- 阳光更偏"储能逆变器 + 光伏链"端，PE 最低（13.67）反映对其成长确定性的怀疑。

> **Reward Source 裁决**：奖励源真实且方向明确（AIDC + 北美配电出海量价齐升），但**纯度高而盈利质量低**——净利率 8.4% / 半年 ROE 5.7% 在仍是"增收不增利、订单疯长利润不动"的生态位，且储能是明确负项。奖励源的"价"靠 AIDC 高毛利撑，"量"靠订单撑，但**还没有传导为利润与现金流**。

## 2. 担保人——谁保证它赚钱？"本土产能自我豁免"有多可靠？

### 2.1 担保人清单
1. **订单骨架**：在手 107 亿（够 1 年多营收），海外 62 亿占 58%，客户为全球头部云厂商（AMZN/META/MSFT 链路）+ 新能源运维 + 电力系统集成商，部分为多年期框架协议（2-4 个月干变/开关、6-8 个月大油变、含运输约 12 个月周期）。**订单纪律强，是当前最强担保人。**
2. **美国本土产能（弗吉尼亚）**：2026H1 正式投产；子公司 JST USA 2026H1 收入 13.07 亿、**净利 1.01 亿（已盈利）**，叠加 CBP 关税退税冲减成本，**美国链路已经在赚钱**。分阶段目标：2026 美国厂产能利用率 40-50%，2027 满产；海外干变产能利用率 80-90%，仍有扩产计划，规划下半年启动欧洲基地。
3. **AIDC 北美配电缺口 + 固态变压器（SST）期权**：首台适配北美 13.8kV SST 样机已发海外测试，2027 年算力中心高压直流需求已与国内云厂商合作推进（"元神 ONE"系列 2026/1 发布）。SST 是给 2027-2028 买单的期权，**不是当期担保**。
4. **全球多基地**：墨西哥（Shelter，全链，约 10 亿/年基本满产）+ 美国双厂 + 波兰/马来西亚 + 待建的欧洲，构成"绕关税"网络。

### 2.2 "本土产能自我豁免"到底有多可靠？（刻意找弱骨论据）
- **可靠的部分**：EO14420 生效于 8/26，白宫文本明确豁免"地方配电设施/用户侧/数据中心自备"，公司证券部口径 + 多家独立核实："金盘产品（数据中心内干变、箱变、中低压开关柜）属用户侧，不在禁令范围；345kV 油变只要是数据中心自用而非接入公共输电主网，也在豁免带"；且行政令 120 天后才出细则、**无追溯效力、不影响已签约在途订单**。金盘主营收在豁免带 + 弗吉尼亚"美国制造"，**方向站得住**。
- **不可靠 / 尾部风险（卷土重来你怕它死的那部分）**：
  - **① 细则扩表情风险**：DOE 细则（约 12/25 前后）是否把"大型数据中心并网接口 / 大型自备电站"强行划入"主干电网设备、或认定中国出口的 69kV+ 连接件受限"，是**最大变量**。
  - **② "中资控股外国实体"认定风险**：行政令针对"受外国实体控制企业生产的设备"，**弗吉尼亚厂是否被认定中资控股受限实体尚无明确标准**——这是"本土产能自我豁免"最脆弱的一环，不是万无一失。
  - **③ 中国直供美国公共电网的高压主变**（345kV+）确有部分在管制范围，占北美收入比重不高但存在。
  - **④ 地缘反转**：2026 年政权更迭后贸易政策可逆，弗罗里达/弗吉尼亚产能一旦被定性，重资产爬坡直接变成沉没成本。

> **担保人裁决**：**订单纪律 + 本土产能 + 已盈利的美国子公司**是真担保，金盘对 EO 的"豁免"比思源可信得多（方向对、有真厂、已在赚钱）。**但"自我豁免"绝非铁律**，两大尾部——细则扩表、中资控股认定——足以在任何一份报表出来前让估值承压。担保强度 = **中到中强，非铁板一块。**

## 3. 怕什么死——风险清单（按杀伤力排序）

1. **【估值/兑现双击】** 体量小（312 亿），在手订单虽大但"订单→利润"传导不畅：现金流转负、ROE 低，一旦细则或地缘落地，高估值 + 低兑现会同时杀。
2. **【EO 细则扩表 + 中资厂认定】**：见 §2.2，最大不确定性，也是 8/27 单日 -7.71% 的根因。虽被多数人定性"情绪错杀"，但错杀不等于无风险。
3. **【汇率】**：海外收入占比 41.66%，人民币升值 5% 带来汇兑损失（2026H1 已亏 0.49 亿；伊戈尔对照 0.3 亿），且 2025Q4-2026Q1 人民币升值约 5% 是当期利润被吞噬的直接原因之一。
4. **【储能价格战】**：储能毛利 5.21%、收入 -23.84%，是明确出血点；铁锂/系统级价格战未见底，若继续放量会进一步稀释整体毛利。
5. **【光伏/新能源链拖累】**：传统新能源配套变压器低价中标订单集中交付、红海危机推高海运 30%、铜材涨价（H1 铜采购成本 +2.37 亿）——共同压毛利弹性。
6. **【AIDC capex 周期】**：AIDC 在手订单 51 亿占比近半，若北美云厂商资本开支在 2027 退坡（从高功率机柜 10kW→50kW 的供电升级节奏放缓），金盘这条最纯的 β 会最先受损。
7. **【现金流/存货/应收占用】**：经营现金流转负、存货应收高（在订单 +41.87% 需提前备货），中诚信评级点名的"流动资金占用大"并未转好。

> 风险裁决：**中高风险**。多数风险（汇兑、储能、铜价）是"利润受损"，可容忍；真正的"死"是 **EO 细则 + 中资厂定性 + AIDC 周期退坡**三件套——任何一件都能让 44 倍 PE 在无利润支撑下崩塌。

## 4. 修复机制——多少钱能把它救回来

| 机制 | 内容 | 强度 |
|---|---|---|
| **订单兑现** | 在手 107 亿 + 转化周期短（开关/干变 2-4 个月），海外数据中心无延期 | 强 |
| **本土产能** | 弗吉尼亚厂已投产且 JST USA 已盈利（净利 1.01 亿），2027 满产；欧洲基地下半年启动 | 强 |
| **高压/SST 升级** | 345kV 批量交付北美、500kV 电压等级、SST 发往海外测试 = 提高单机价值量、摆脱低价竞争 | 中强（当期兑现弱） |
| **多市场** | 美/墨/欧/东南亚多基地，"绕关税网络"+ 区域配送 | 中 |
| **降本** | 非晶材料自研、VPI 变压器数字化工厂、数字化降本，毛利结构优化 | 中 |

> 修复机制裁决：**强**。金盘真正强在"订单已在手 + 本土产能已盈利 + 多市场网格"，在 T1 三者中其**订单兑现确定性最高**，这是它敢坐拥高 PE 的底气。但每个修复机制的落地都绑定"贸易政策不变/细则不加码"这一前提——修复能力≠政策免疫。

## 5. 估值关键——PE 44.78 凭什么？是成长溢价还是过热？

### 5.1 三者横向硬对比（真实数字）
| 指标 | 金盘科技 | 思源电气 | 阳光电源 |
|---|---|---|---|
| PE-TTM | **44.78** | 34.17 | 13.67 |
| 市值 | 312 亿 | 1135 亿 | — |
| 2026H1 净利增速 | +14.23% | +13.23% | — |
| 2025A 净利率 | ~8.4% | **15.13%** | — |
| 2025A ROE | ~11%（全年估） | **22.63%** | — |
| 海外收入占比 | 41.66%（+68%） | 29.5%（+11%） | — |
| 在手/年度营收比 | ~3x（107/35.6） | ~1.3x（订单 289/215） | — |
| 订单弹性 | 海外+AIDC 爆发 | 开关/变压稳增+储能高增 | — |
| EO14420 敞口 | 豁免带+有美厂 | 在禁区+无美厂 | — |

**机构盈利预测（券商，非我方虚构）：**
- **国信证券**：金盘 2026/27/28 净利 **7.84 / 14.34 / 18.47 亿**（+19%/+83%/+29%），动态 PE **39.5 / 21.6 / 16.8**。
- **国海证券**：金盘 2026/27/28 净利 9.08 / 11.51 / 14.13 亿（+37.7%/+26.8%/+22.7%），动态 PE **34 / 26.9 / 21.9**。
- **思源**：21 家均值 2026 净利 **42.42 亿**（+34.65%），A股动态 PE ~27 / 20 / 15。
> 两券商对金盘 2026 盈利预测差 15%（7.84 vs 9.08 亿），PE 从 34→39.5，说明"订单转化率/毛利率假设"分歧巨大 = **盈利兑现的确定性并不像股价那么贵**。

### 5.2 裁决
**凭什么金盘最贵？** 靠的是：① AIDC 纯度（占比近半）——市场给它"算力电源"稀缺估值；② 海外占比最高 + 唯一美国本土产能——给它"关税豁免/出海最纯"溢价；③ 订单弹性最大（海外/数据中心同比三位数）。

**但它配不上这么贵，理由（反例）**：
1. **当期盈利质量三者最弱**：PE 最高的同时，净利率 8.4% vs 思源 15.1%、ROE 一半于思源、经营现金流转负、储能毛利 5%——**高 PE 建立在尚未兑现的高成长假设上**。
2. **成长确实快但基数小**：思源 2026 净利 42 亿是金盘（7.8-9 亿）的 ~5 倍，市值却只是思源 1/3，这反过来说明市场把"弹性"当"确定性"在定价。
3. **尾部风险未定价在折价里**：EO 细则 + 中资厂认定 + AIDC 周期，金盘的三条"死线"比思源/阳光更依赖政策与 capex 外生变量；44 倍 PE 里几乎没为这些留折扣。

**结论**：PE 44.78 = **成长溢价偏高、倾向过热，而非合理**。它不是"比思源/阳光更值"，而是"赛道更纯、故事更性感的贵"。以 2026 动态 34-39 倍、2027 还有 ~22-27 倍看，**只有 2027 年 +80%（国信）级别的利润兑现才能撑住当前价**，一旦兑现打折或细则加码，双杀空间比思源大。

## 6. EGS 总档位裁决

| 维度 | 评级 | 关键依据 |
|---|---|---|
| **Reward Source（奖励源）** | **高** | AIDC 干变 + 北美配电现货出海洋，量价齐升在数据中心侧为真；但储能是负项 |
| **担保人（是谁保证赚钱）** | **中~中强** | 107 亿在手 + 本土产能已盈利（JST USA 1.01 亿）+ 多基地；但"豁免"非铁律，细则与中资认定两尾部 |
| **怕什么死（风险）** | **中高** | EO 细则扩表 / 中资厂定性 / AIDC capex 周期 / 汇兑+储能价格战 / 现金流转负 |
| **修复机制（能否救回）** | **强** | 订单兑现 + 本土产能 + 高压/SST 升级 + 多市场网格，兑现确定性三才最高 |

> **EGS 总档位：中（偏中高，定义为"奖励源高、担保中、修复强、但当期盈利与估值不匹配"）**
>
> **对高估值的最终裁决：金盘 PE 44.78 是三者最高的"情绪成长溢价，偏向过热"**——它的奖励源、担保人、修复机制在三者里确实最"纯"（AIDC + 唯一美国厂 + 最激进订单），配得上一定溢价；但当期净利率 8.4%、ROE 半于思源、现金流由正转负、储能还在亏着卖，**44 倍 PE 打折的是 2027 年 +80% 的高难度兑现**。从风险收益比看：**思源（PE 34、净利率 15%、ROE 22.6%、EO 虽真利空但估值更便宜且盈利质量碾压）性价比明显优于金盘；阳光（PE 13.67，便宜但成长纠结）是另一个极端**。金盘居中也居中——贵在纯度，死在没有利润底的溢价上，属"T1 中高确定性、高估值、中风险"的第三候选，追高性价比不高，更适合回调后配置而非现价（YTD -24% 的"错杀"叙事需要兑现证明）。
