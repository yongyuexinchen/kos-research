## 一、核心问题与定义（形式化）

**Q2：中央和地方为什么激励不一致？**

统一的符号约定（沿用任务定义 Phase0）：$\tau_L$ 为地方考核/任期的有效时间尺度，$\tau_C$ 为中央视野时间尺度；$t$ 为时间。定义两类目标函数：

### 1.1 中央目标函数 $\text{Score}_{Central}(T)$

$$
\boxed{
S_C(T) \;=\; \int_{0}^{T} e^{-\rho t}\,
\Big[
a_1\,\text{TFP}_t
+ a_2\,\text{Cn}_t
+ a_3\,\text{Alloc}_t
+ a_4\,\text{FS}_t
+ a_5\,\text{SS}_t
+ a_6\,\text{Ext}_t
\Big] dt
}
$$

| 项 | 含义 | 时间属性 |
|---|---|---|
| $\text{TFP}_t$ | 长期生产率（技术+配置效率） | 慢变量，$t>5$ 才兑现 |
| $\text{Cn}_t$ | 居民消费 / 分配结构 | 中慢变量 |
| $\text{Alloc}_t$ | 全国资源配置效率（统一大市场、要素跨区流动） | 全国性公共品 |
| $\text{FS}_t$ | 金融稳定（系统性、宏观） | 关注**总量与传染** |
| $\text{SS}_t$ | 社会保障 / 就业结构质量 | 关注**人**而非**企业** |
| $\text{Ext}_t$ | 外部平衡（国际收支、外部竞争力） | 全局性 |

关键参数：$\rho$ 为社会折现率，$a_i$ 为当期的政策权重。**中央的时间尺度 $\tau_C\approx5$–15 年**（五年规划 + 2035 远景），且 $S_C$ 内含"出清收益在远期兑现"的结构：低效企业退出 → 资源释放 → $\text{TFP}$ 与 $\text{Alloc}$ 上升（线A §4.1 矩阵）[INF]。

### 1.2 地方目标函数 $\text{Utility}_{Local}(\tau_L)$

$$
\boxed{
U_L(\tau_L) \;=\; \sum_{t=1}^{\tau_L} \delta^{t}
\Big\{
\gamma_1\,\text{GDP}_t
+ \gamma_2\,\text{Fisc}_t
+ \gamma_3\,\text{Empl}_t
+ \gamma_4\,\text{KeyFirm}_t
+ \gamma_5\,\text{Project}_t
+ \gamma_6\,\text{Attr}_t
+ \gamma_7\,\text{Stab}_t
- \gamma_8\,\text{Debt}_t
- \gamma_9\,\text{LFR}_t
\Big\}
}
$$

| 项 | 含义 | 与出清的关系 |
|---|---|---|
| $\text{GDP}_t$ | 当期 GDP 增速与规模 | 企业退出 → 即期下降 |
| $\text{Fisc}_t$ | 财政收入（税收、土地出让） | 企业退出 → 税基缩水 |
| $\text{Empl}_t$ | 就业与工资 | 企业退出 → 失业 |
| $\text{KeyFirm}_t$ | 重点企业存续（"链主"、纳税大户） | 直接保护对象 |
| $\text{Project}_t$ | 重大项目落地 | 存量项目不能倒 |
| $\text{Attr}_t$ | 招商引资竞争力（对增量资本吸引力） | 退出 = 环境负面信号 |
| $\text{Stab}_t$ | 社会稳定（信访/群体事件，一票否决） | 裁员 → 稳定风险 |
| $-\text{Debt}_t$ | 债务与化债压力 | 续命推高隐性债务 |
| $-\text{LFR}_t$ | 地方金融风险（银行坏账、担保链） | 断贷 → 风险暴露 |

关键参数：$\delta$ 为地方折现因子，**考核窗 $\tau_L\approx1$–3 年**（年度考核 + 任期），$\gamma_7$（稳定）在体制约束下几乎为硬约束/一票否决项（线A §一）。

### 1.3 "结构性出清"与"企业续命"的操作性定义

$$
\text{结构性出清} := \text{资源从} \{ \text{长期负 TFP、资不抵债、产能过剩下限} \} \text{ 释放并再配置}
$$

$$
\text{企业续命} := \text{通过补贴/续贷/接盘/输血使} \ \mathbb{E}[\text{生存概率}] \ \text{在考核窗内维持} \geq \underline{P}
$$

**Q2 形式化**：在由 $(a_1,…,a_6)$ 与 $(\gamma_1,…,\gamma_9)$ 分别刻画的两个目标函数下，求解各自的占优策略 $\Pi_C,\Pi_L \in \{\text{structral-exit}, \text{lifeline-support}\}$，解释为何 $\Pi_C=\text{structural-exit}$ 而 $\Pi_L=\text{lifeline-support}$。

## 二、机制分析：为什么中央要出清、地方要续命

以下机制清单（$\text{M1}$–$\text{M10}$），每条 = 机制名 + 因果链 + 证据标签。证据强度由标签区分，机制层本身为 T1 结构假设，因果链为 T2 推演。

### M1 干部晋升锦标赛（GDP 锦标赛）——相对排名的考核刚性

- **因果链**：考核窗 $\tau_L$短 → 绩效按**相对排名**发放（Lazear & Rosen 锦标赛结构）→ 晋升概率 $\uparrow \text{GDP}_{t\in\tau_L}$ → 当期增长 = 存量企业+增量项目 → 企业退出当期即拉低排名 → $\Pi_L$
  = 保住存量企业以守住当期相对名次。
- **证据**：[R] Lazear & Rosen (1981) 锦标赛理论，回报按相对排名（知识库 Classic-Papers/01）；[R] 周黎安（2007）《中国地方官员的晋升锦标赛模式研究》：以相对经济绩效决定晋升概率的中国地方官员锦标赛；[KB: 聂辉华/02] 内外冲突双均衡框架中"分权→经济绩效晋升（GDP 锦标赛）"。
- **关键推论（T2）**：中央可以同时"口头否定 GDP 单一化"与"实际保留 GDP 权重"，因为锦标赛结构只需"相对排名仍有意义"，地方优化行为便不变（线A §一：2019 条例禁止"以 GDP 排名定结果"但未取消 GDP 权重，权重下放省级）[E][INF]。

### M2 财政分权与分税制：财权上收、事权下放的"税基饥渴"

- **因果链**：1994 分税制将增值税/企业所得税大头划归中央 → 地方失去稳定自有财源，事权不降反增 → 地方政府被迫依赖**地方税基 + 土地出让 + 转移支付** → 企业 = 稀缺税源 → 企业退出 = 直接削财政 → $\Pi_L$=保企业以保税基。
- **证据**：[KB: 聂辉华/09 土地财政] "分税制改革后地方政府在'财权上收、事权下放'压力下自发形成替代性财政收入机制……土地财政不是贪婪，而是制度约束下的理性自救行为"；[KB: 聂辉华/02] 分权→财政竞争格局。此为学术界共识级描述 [R]。
- **关键推论（T2）**：只要地方财政对"企业增量税收+土地相关的经营收入"依赖不变，中央任何"高质量发展"口号都不改变税基层面的保企业激励。

### M3 招商引资竞争：存量项目的"竞价锁定"

- **因果链**：晋升锦标赛 + 财政压力驱动地方间**为增长而竞争** → 以税收返还、电价地价优惠、补贴竞相招商 → 已落户企业 = 前期优惠的**沉淀成本** → 若其退出，等于宣告"这块地/这单优惠没有换来增长"，直接否定前任与现任政绩 → 保现有企业 = 为既往招商"止损"。
- **证据**：[R] 晋升竞争+财政竞争的经典组合（周黎安 2007；钱颖一 Weingast 分权激励论，通识）；[E] 2024 三中全会明确禁止"违规给予招商引资政策优惠"，反证该项扭曲的普遍性（任务定义/线A 证据卡）；[KB: 聂辉华/09] 地方以优惠条件吸引企业（"招商引资提供优惠条件"）。

### M4 属地责任 + 社会稳定一票否决：企业=就业=平安的等价物

- **因果链**：属地责任（KB: 聂辉华/05）使县级书记对辖区内一切事务兜底 → 县委书记"三座大山"中含社会稳定（信访一票否决）与招商引资（KB: 聂辉华/06）→ 企业裁员或破产 → 失业 → 欠薪/群体性事件 → 一票否决 → 书记前途清零 → $\Pi_L$=阻止企业倒下，即阻止就业风险显性化。
- **证据**：[KB: 聂辉华/06] 县委书记三座大山；[KB: 聂辉华/05] 属地责任 ="无限兜底义务+有限管理权限，责任边界≫权力边界"；[INF] 企业由此成为地方"隐性社保与稳定阀"。

### M5 财政补贴与税费优惠的"净财政收益"权衡

- **因果链**：地方对企业的续命补贴 $\text{s}_i$ ≤ 企业续存期的税+费+土地增值收益 $\text{f}_i$ → 只要 $\text{s}_i < \text{f}_i$，续命就是地方预算上的**正现值交易** → 尤其对垄断性/链主企业，$\text{f}_i$ 含全链条间接税收 → 更值得保。
- **证据**：[INF]（机制层）；[E-需核实] 中国地方政府对企业（尤其制造业、新能源）补贴的**县级分项规模**需以财政决算数据核实。
- **关键推论（T2）**：中央视角下这些补贴是**负和交易**（资源留在低效部门、阻碍 $\text{Alloc}$），地方视角下是**正和部门交易**——这不是"补贴对错"问题，而是**目标函数不同**导致对同一交易的估值相反。

### M6 银行续贷与地方金融风险的"协调止损"

- **因果链**：城商行/农商行/地方分行受地方政府协调力制约（书记可"沟通协调"银行）→ 断贷将引发连环违约与担保圈传染 → 坏账暴露计入地方金融风险 $\text{LFR}$ → 地方施加压力促续贷/续命（借新还旧、贷款展期、政府性担保）→ 企业"技术性不死"。
- **证据**：[KB: 聂辉华/06] 县委书记隐性权力之一即协调银行贷款（"条管单位强龙难压地头蛇"）；[KB: 翟东升/金融抑制] 中国存在信贷定向配置、低利率补贴优先部门的金融抑制机制（居民储蓄隐性补贴企业部门）；[R] 通识：中国"以贷养企/以贷续命"案例广泛（僵尸金融服务实体经济）。

### M7 国企接盘与城投续命：公有部门当"最后买家"

- **因果链**：民企濒危 → 地方国企/城投平台收购股权、代偿担保、接续项目、以"混改/纾困"名义输血 → 法人资格保留、员工不断缴、资产不出表 → 账面"企业仍在" → 出清被无限推迟。
- **证据**：[E] 2024 三中全会"融资平台转型""全口径地方债务监测"写入顶层文件，反证平台承担续命功能的普遍性（线A证据卡）；[R] 通识：国资纾困基金、地方国企并购民企案例广泛；[E-需核实]**县级城投接盘的具体规模与占比**需核实（城投年报与产权交易公告可查，本次未核实）。

### M8 时间尺度错配与"坏消息推迟"定理（继承线A §4.2）

- **因果链**：出清收益兑现期 $t^*$（3–7 年）> $\tau_L$（1–3 年）→ 出清的成本落在任内、收益落在继任 → $E[U_L]$ 最优解是推迟坏消息而非提前出清 → 任何干部都不接"别人不肯出清的成本"。
- **证据**：线A §4.2 时间尺度错配定理（T1 命题，已建立）；[R] 公务员/干部任期制通识（5 年一届、调动频繁）。
- **关键推论（T2）**：出清的宏观收益是**公共品**，地方无法独占；出清成本是**地方私品**，全由本地承担——这是激励错配的**核心不对称**。

### M9 内卷化式的"无法退出"：企业被嵌套为社保装置

- **因果链**：劳动力无法退出的结构性背景（土地社保功能、城乡二元、农民工"两头挂"）→ 失业者难以被社会安全网兜住 → 企业就近裁员=把他推出社保体系 → 地方用"保企业"替代"保人"（因为保人的制度能力弱）→ 企业的存亡被赋予超出生产效率的**社会稳定含义**。
- **证据**：[KB: 温铁军/内卷化] "无法退出"的结构约束、土地承担社会保障功能；[KB: 温铁军/成本转嫁] 城乡二元作为危机软着陆蓄水池；[INF] 县域尤甚（承接线B C 类）。
- **关键推论（T2）**：只要社会安全网（失业保险、常住地公共服务）不健全，"保企业即保稳定"就成立；中央若要"保人不保企"，必须配套把人的保障接到常住地（2024 三中全会"常住地公共服务"正是此方向 [E]）。

### M10 危机"向下转嫁"的温床：土地财政枯竭后的续命依赖加深

- **因果链**：土地收入锐减 → 地方更依赖企业税基与存量经营收益 → 越穷越不敢让企业出清 → 保企激励反而在经济下行期**增强**（反周期）→ 与中央"结构性出清"诉求在衰退期冲撞最烈。
- **证据**：[KB: 聂辉华/09] 土地财政三条红线下的崩塌 + 基层"生存压力压倒发展动力"；[KB: 明斯基/金融演化] 政策托底→僵尸企业存活→脆弱性累积；[KB: 辜朝明/财政政策必要性] 财政续命可能阻止"创造性毁灭"的争论在日欧同样存在（对照线）。
- **关键推论（T2）**：**下行期是激励错配最尖锐的时段**——恰好也是需求侧最需要出清的空间，构成 EGS 反馈链上的最难断点。

### 2.1 形式化对比表：$S_C$ 与 $U_L$

| 维度 | 中央 $\text{Score}_{Central}$ | 地方 $\text{Utility}_{Local}$ | 冲突性质 |
|---|---|---|---|
| 时间尺度 | $\tau_C \approx 5$–15 年 | $\tau_L \approx 1$–3 年 | **时间错配** |
| 折现 | $\rho$（社会折现率）小 | $\delta$（任期折现）大 | 远期收益被地方贴现掉 |
| 对企业的立场 | 看 $\text{TFP},\text{Alloc}$：低效企业=资源占用 | 看税基、就业、稳定：企业=资产 | **估值相反** |
| 对补贴态度 | 负和（扭曲配置） | 正和（净财政收益） | **同一交易估值相反** |
| 对债务态度 | 关注系统性/宏观杠杆 | 关注自身化解压力（$\text{Debt}_t$） | 局部理性 vs 全局理性 |
| 对金融风险 | 关注传染（系统性） | 关注本地坏账/担保链 | 尺度差 |
| 受益范围 | 出清收益=全国公共品 | 出清成本=本地私品 | **收益公共化、成本私有化** |
| 一票否决项 | 无（可容错） | 稳定/安全硬约束 | 地方更"怕事" |

## 四、盒式结论（线B · Q2）

$$
\boxed{
\begin{aligned}
& \text{1. 中央"要出清"是因为其目标函数} \ S_C \ \text{将出清收益（TFP/资源配置/消费）贴现为远期} \\
& \qquad \text{正值公共品；地方"要续命"是因为} \ U_L \ \text{把出清成本贴现为} \ \tau_L \ \text{内的即期私品。} \\
& \text{2. 二者错配的根本结构 = }\ \textcolor{red}{\text{时间尺度差（}\tau_L<\tau_C\text{）}} \ + \ \textcolor{red}{\text{收益公共化/成本私有化}} \ + \ \textcolor{red}{\text{锦标赛排名刚性}}。
\\
& \text{3. 保企=稳定（M4/M9）与保企=税基+净财政收益（M2/M5）是最强两个机制；} \\
& \qquad \text{银行续贷与城投接盘（M6/M7）为货币--财政--国有部门的联合续命通道。} \\
& \text{4. 决定性推论：}\ \text{除非"保人的社会安全网"+"重置资源配置的正激励"}\ (\text{线A Q13 通道1--4})\ \text{同时落地，} \\
