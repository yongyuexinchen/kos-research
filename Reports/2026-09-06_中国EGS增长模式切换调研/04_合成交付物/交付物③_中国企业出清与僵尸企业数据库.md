## 1. 核心发现（现状判定）

$$
\boxed{
(1)\ \text{低效企业不退出确实伤害整体经济：经"信贷挤占/要素滞留/通缩需求/就业抑制"四通道，}
\\
\qquad\ \ \text{Hsieh-Klenow 测算的错配损失可达中国制造业 TFP 的 30–50\% [R]。}
\\
(2)\ \text{出清现状 = } \textcolor{red}{\text{高进入 }(\approx10\%/\text{yr})\ \times\ \text{低退出 }(\approx3\text{–}6\%/\text{yr})\ \times\ \text{司法破产缺位}(<5\%\text{ 退出额占比})}。
\\
(3)\ \text{僵尸规模可信锚：规上工业约 7.51\%（聂辉华等 2016，2013 年末）[R]；产能利用率工业约 74–76\%。}
}
$$

## 3. 数据库字段设计（省/市/县三级）

| 字段 | 定义 | 粒度 | 单位 |
|---|---|---|---|
| `region_id` | 行政区划代码 | 县 | — |
| `N_t` | 存量企业数（法人，不含个体户） | 县 | 户 |
| `E_t` | 新设企业数 | 县 | 户 |
| `X_t` | 注吊销企业数 | 县 | 户 |
| `B_t` | 法院破产/强制清算受理数 | 县/市 | 件 |
| `λ` | 退出率 = X_t/N_t | 县 | % |
| `μ` | 进入率 = E_t/N_t | 县 | % |
| `θ` | 破产占比 = B_t/(B_t+X_t) | 县 | % |
| `cap_util` | 工业产能利用率 | 市/省 | % |
| `subsidy_t` | 政府补助总额 | 省 | 亿元 |
| `rollover_t` | 无还本续贷/借新还旧规模 | 省/市 | 亿元 |
| `npl_t` | 不良贷款率（分机构） | 省/市 | % |
| `industry_struc` | 行业产值/就业结构 | 县 | % |
| `zombie_share` | 僵尸企业占比（连续≥2年 EBIT<利息） | 市/省 | % |

## 4. 使用方法与待补数据

- 主通道建议自采：①市场监管部门"市场主体年报"（进入/退出）；②法院裁判文书库"企业破产"检索（司法出清）；③上市公司+发债企业财报（ICR<1 识别僵尸）。
- **待核优先级**：市县两级 $\lambda,\mu$（当前全国有的只是量级推断）、分省 `zombie_share`、`rollover_t` 的官方分项。

## 5. 盒式结论（交付物③）

$$
\boxed{
\begin{aligned}
& \text{中国存在"半出清均衡"（线A/C 判）：进入高、退出低、司法清算缺位}，\text{僵尸以补贴+续贷滞留。}\\
& \text{退出主通道是行政注吊销而非破产清算} \Rightarrow \text{债权/职工/税务的"有序分配"严重不足，僵尸的债与工被"带病失踪"。}\\
& \Rightarrow \ \text{政策含义：看得见的"出清指标"应是 } \theta=\dfrac{B_t}{B_t+X_t}\ \text{（司法破产占比）升破阈值，而非仅看注吊销总量。}
\end{aligned}
}
$$
