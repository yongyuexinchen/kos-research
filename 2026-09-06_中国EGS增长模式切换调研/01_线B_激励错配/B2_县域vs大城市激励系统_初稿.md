## 一、核心问题与定义（形式化）

**Q3：县域与大城市是不是完全不同的经济激励系统？**

### 1.1 企业"地方重要性"的形式化

设地区 $r$、企业 $i$，定义企业在地方的**综合重要性**为三维加总：

$$
\boxed{
w_{i,r} \;=\; a\,\log\big(1+\tfrac{\text{tax}_{i,r}}{\text{Fisc}_r}\big)
\;+\; b\,\log\big(1+\tfrac{L_{i,r}}{L_r}\big)
\;+\; c\,\log\big(1+\tfrac{V_{i,r}}{Y_r}\big)
,\qquad a+b+c=1
}
$$

其中 $\tfrac{\text{tax}_{i,r}}{\text{Fisc}_r}$ = 企业税收占地方财政收入比，$\tfrac{L_{i,r}}{L_r}$ = 企业就业占本地就业比，$\tfrac{V_{i,r}}{Y_r}$ = 企业增加值/GDP 比。

地区层面定义**经济结构集中度**（HHI 式）：

$$
H_r \;=\; \sum_{i} \Big( \tfrac{V_{i,r}}{Y_r} \Big)^2
$$

- 单一龙头县域：$H_r \to 1$；强制造地级市：$0.2\lesssim H_r \lesssim 0.6$；超大城市：$H_r \ll 0.1$。 [INF 结构定义]

### 1.2 保护强度的形式化与核心命题

定义地方政府对企业 $i$ 的保护投入强度：

$$
P_{i,r} \;=\; \mathbb{E}\Big[ \text{补贴}+\text{续贷}+\text{接盘输血}+\text{执法宽容} \mid \text{企业}i\ \text{进入困境} \Big]
$$

**核心假设（本次调研主线）：**

$$
\boxed{ P(\text{protect}_{i,r}) \;\propto\; w_{i,r} \;\cdot\; f(H_r) }
$$

即"**企业越重要，地方越不可能允许它出清**"；且集中度 $H_r$ 越高，单企业的重要性 $w_{i,r}$ 越大 → 保护强度越高。

### 1.3 三类地区结构定义

| 类型 | 代表 | 结构性特征 | $w_{i,r}$ 分布 | 预期保护强度 |
|---|---|---|---|---|
| A 超大城市 | 北上广深 | 企业存量极大、产业多元、人才流动高、替代供给充足 | $w_{i,r}$ 极小；无单点主导 | 低（对企业个体） |
| B 强制造业地市 | 苏州/东莞/宁波等 | 产业链集中但企业数量大，存在"链主"+大量配套 | $w_{i,r}$ 中；链主被隐性抬升 | 中（链主高、配套低） |
| C 产业单一县域 | 1–5 家龙头支撑的县 | 税、就业、稳定高度依赖少数龙头 | $w_{i,r}$ 极大，$H_r\to1$ | 极高（必要时接盘） |

## 二、机制分析：三类地区的"企业退出"激励差异

### 2.1 A 类（超大城市）：个体退出无足轻重，系统性分层保护

**机制 A1：替代供给的"可逆性"**。
- 因果链：企业密度高、人力资本池深、产业多元 → 单企业退出 → 员工可再就业、供应链可再配置、税基可由他企补位 → 平均重要性 $\bar{w}_{i,r}$ 低 → $P_{i,r}$ 低。
- 证据：[R] 城市产业多样性降低单一企业系统重要性的通识（Marshall 集聚外部性，通识）；[INF]。

**机制 A2：保护的对象"不是企业而是系统节点"**。
- 因果链：超大城市真正承担系统重要性的是**平台/生态位**（金融牌照、数据、网络效应）→ 保护函数从"保具体法人"切换为"保生态" → 个体企业退出被允许，但系统级风险被中央/金融监管直接接管。
- 证据：[INF]；[KB: 明斯基/金融演化] 大政府对"系统重要性"的隐性担保产生道德风险；[R] 中国"系统重要性金融机构"名单与处置机制（金监局，通识——具体企业名单 [E-需核实]）。

**机制 A3：晋升竞争的"锦标赛窗口"更宽松**。
- 因果链：大城市干部晋升的考核面更宽（科创、开放、治理），单家民企退出的边际影响力低于县级 → 缺少"救活某一企业 = 保住全县财政"的直接绑定。
- 证据：[KB: 聂辉华/06] 县委书记"三座大山"中稳定与招商绑定极紧；[INF] 级别越高的政府面对的企业主体更多，绑定位越弱。

**结论（A 类）**：激励系统是**分层 + 生态式**的；单企业出清可接受，系统性节点出清不可接受。企业退出的"社会传染"被城市韧性吸收。

### 2.2 B 类（强制造业地市）：链主保护、配套可出清

**机制 B1：链主 = 隐性的 $w$ 抬升**。
- 因果链：链主企业（如整车厂、电子代工龙头）的单体 $w^{tax}$ 未必极高，但其通过订单连接大量本地配套厂 → 链主退出 → 配套厂连锁倒闭 → 实际退出影响 = 链主自身 + ∑配套 → 地方以"隐性重要性"保护链主（续贷协调、订单托底、国资入股）。
- 证据：[INF]；[R] 通识：东莞电子产业链、苏州制造集群的"链主—配套"结构——具体链主名单与就业占比 [E-需核实]。

**机制 B2：配套企业是可出清层**。
- 因果链：配套企业数量多、单个 $w^{tax}, w^{emp}$ 低、产能可被同城替代 → 专项出清（关停低效配套）不会触碰地方财政与稳定底线 → 地方允许"尾部出清"。
- 证据：[INF]；线A 反内卷/产能治理（2025 起中央以监管推动行业出清）正是瞄准 B 类地区的产能层 [E]。

**机制 B3：土地—产业链的"复合质押"**。
- 因果链：地方过去以土地、基建、补贴投入产业链 → 链主绑定 = 前期投入的回收担保 → 出清链主 = 沉没全部基建 → 故保护强度随前期投入深度上升。
- 证据：[KB: 聂辉华/09] 土地财政驱动的基建—招商投入模式；[INF]。

**结论（B 类）**：激励系统是**链式分层**——保护强度沿"链主 > 关键配套 > 普通配套 > 尾部产能"分布。B 类保护强度介于 A、C 之间，但保护强度命题 $P \propto w$ 在此处应使用**直接间接税收加成**（含订单传导）而非单体 $w$。

### 2.3 C 类（产业单一县域）：龙头即财政、龙头即稳定、龙头即政绩

**机制 C1：财政的"三点一线"**。
- 因果链：县域 $H_r\to1$ → 龙头 $w^{tax}_{i,r}$ 常达数十个百分点（严重要核实）→ 龙头垮 → 县财政当年即入不敷出 → 干部面临"发不出工资/三保落空"的直接问责 → 保龙头 = 保财政生命线。
- 证据：[KB: 聂辉华/09] 土地财政枯竭后"地卖不动了，工资怎么发"的基层焦虑；[INF]；典型定性案例：魏桥创业（山东邹平）、宁德时代（福建宁德，地级市边缘区）、牧原股份（河南内乡）等"一企兴县/一企托县"格局 [R-通识/具体占比 E-需核实]。

**机制 C2：就业与稳定的"单点绑定"**。
- 因果链：县域就业高度依赖龙头及其供应链 → 龙头裁员/破产 → 数千—上万劳动力无替代岗位 → 返乡农民工无社保兜底（承 B1/M9 内卷化） → 群体性风险 → 一票否决 → 书记政治生命终结 → 保龙头 = 保平安。
- 证据：[KB: 温铁军/内卷化] 劳动力"无法退出"、城乡二元作为危机蓄水池；[KB: 聂辉华/05,06] 属地责任 + 三座大山；[INF]。

**机制 C3：招商引资的"橱窗效应"**。
- 因果链：县域吸引新资本的谈判筹码 = 现有龙头示范 → 龙头死 = "营商环境差"标签固化 = 招商素材归零 → 反而强化保龙头投入（陷入"越保越依赖"）。
- 证据：[INF]；承 B1/M3 招商竞价锁定逻辑。

**机制 C4：县级政府缺乏"接盘以外的处置选项"**。
- 因果链：A/B 类有产业基金、并购市场、人才承接；县域几乎无替代配置渠道 → 出清的"再配置通道"缺失 → 出清 = 纯损失 → 唯一理性选择是续命（城投接盘、国企并购、贷款展期）。
- 证据：[KB: 聂辉华/04 等级制资源配置] 资源与融资能力按行政级别梯度配置，县级获得的金融/人才/项目资源最少 → 县域处置能力最弱；[INF]。

**结论（C 类）**：激励系统是**单点刚耦合**——"龙头 = 财政 + 稳定 + 政绩 + 招商招牌"四位一体。县政府的效用对龙头存亡的一阶导远大于 A/B 类；当龙头陷入资不抵债，「续命」是县级唯一可执行策略。**这是全文命题最极端的实现域。**

## 三、验证 $P(\text{保护}) \propto w \cdot f(H)$：指标设计清单（T3）

### 3.1 重要性 $w_{i,r}$ 测度（自变量）

| 指标 | 定义 | 数据来源建议 |
|---|---|---|
| $w^{tax}_{i,r}$ | 龙头企业纳税/县级一般公共预算收入 | 县级财政决算公开、统计公报、企业信用年报 [E-需核实] |
| $w^{emp}_{i,r}$ | 龙头用工/县域规上工业用工（或城镇就业） | 四经普/五经普县域数据、龙头企业年报员工数 [E-需核实] |
| $w^{gdp}_{i,r}$ | 龙头增加值/县 GDP | 县级统计年鉴（注意虚拟企业口径）[E-需核实] |
| $H_r$ | 产业集中度 $\sum (V_{i,r}/Y_r)^2$ | 县级规上工业企业数据（统计局名录库）[E-需核实] |

### 3.2 保护强度 $P_{i,r}$ 的代理测度（因变量）

| 代理 | 操作化 | 说明 |
|---|---|---|
| 补贴强度 | 年获补贴额 / 纳税额 | 天眼查/企查查"税收优惠+政府补助"结构化字段 |
| 贷款久期与不良容忍 | 对困难企业持续展期时间、僵尸贷款余额 | 地方银行年报、贴现率替代；微观难获→用"长期零利息支出+持续经营"识别僵尸企业（ICR<1）[E-需核实] |
| 接盘事件 | 城投/国企对民企并购、增资、担保笔数 | 产权交易所挂牌公告、上市公司公告 |
| 执法宽容 | 环保/税务/消防处罚频次与金额（按同行业对比） | 中国裁判文书网 + 生态环境部处罚库 |
| 破产结案时长 | 从受理到终结的月数（按企业规模分组） | 裁判文书网破产裁定 |
| 存活悖论 | ICR<1 且成立年限 >10 年的存续企业数 | 上市/发债企业财务库 |

### 3.3 检验设计（T3 提议，本线未执行）

1. **截面回归**：$P_{i,r} = \alpha + \beta_1\, w^{tax}_{i,r} + \beta_2\, w^{emp}_{i,r} + \beta_3\, H_r + \gamma\, X_{i,r} + \varepsilon_{i,r}$，检验 $\beta_1,\beta_2,\beta_3>0$。
2. **自然实验/案例库**：收集 2019–2026 县域头部企业陷入困境（债务违约、现金流危机）后的处置模式，编码为 {出清, 展期, 补贴, 接盘, 混合}，对比企业与龙头集中度。

4. **面板差分**：HHI 变化的县（新增替代产业 vs 无替代），观察保企强度差异。

## 四、盒式结论（线B · Q3）

$$
\boxed{
\begin{aligned}
& \text{1. 县域与大城市确实构成}\ \textcolor{red}{\text{不同激励系统}}：\text{A 类为"生态分层式"，B 类为"链式分层式"，C 类为"单点刚耦合式"。}\\
& \text{2. 核心命题：}\ P(\text{protect}_{i,r}) \propto w_{i,r}\cdot f(H_r) \ \text{——企业越重要、结构越单一，出清越被禁止；}\\
& \qquad \text{其极端实现是 C 类县域"龙头=财政+稳定+政绩+招商"四位一体。}\\
& \text{3. 县域续命的} \ \textcolor{red}{\text{结构性根源}}\ \text{不在道德而在能力：再配置通道缺失（等级制资源配置）+ 劳动者无法退出（内卷化）}\\
& \qquad \text{使"出清"在县域几乎等于纯损失；因此同一中央政策，在 A 类可行、在 C 类必然变形。}\\
& \text{4. 对总判断的意义：B/C 类地区} \ \textcolor{red}{\text{保护强度更高}},\ \text{是全系统"企业不出清"的主要供给者；}\\
& \qquad \text{中央若要全局出清，必须优先解决 C 类再配置能力与劳动者保障, 否则地方续命是最优响应。}
\end{aligned}
}
$$
