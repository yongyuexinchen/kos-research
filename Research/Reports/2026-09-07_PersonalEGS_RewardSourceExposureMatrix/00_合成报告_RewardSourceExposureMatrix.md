# Personal EGS Reward Source Exposure Matrix · 合成报告（v1.0）

> 问题：个人全部资本究竟暴露于哪些**底层奖励源**，接受哪些**共同冲击**，资本间**隐性相关**为何，如何**转换**，各增多少**未来有效路径空间**？
> 北斗：不是投资推荐，不是"哪类资产最好"；是产出**可计算模型**，供下一轮 Dynamic Allocation 作底层输入。
> 证据纪律：E=实证｜L=文献｜S=机制推导｜J=专家判断｜A=情景假设；**无实证不造 0.75/0.80，用 高/中/低 + 需何数据量化**。L3/J 均显式标注。

---

## 〇、一句话总判

> **个人看似"多资本、多路径"，理想情况下其真实有效风险只取决于"少数几个底源"的聚集度（RSCI）与"可转换性"（Convertibility）；增加资本的边际价值，取决于它是否落到**新因子上**（增路径）还是**旧因子内**（伪分散）——收益可以协同，风险只有因子级才可分散。**

## 一、Reward Source 精确定义（Q1，Agent A）

**Reward Source ≠ 资产类别/收益流/风险因子**。定义：
> **Reward Source = 个人某项资本能持续产生价值/现金流/购买力/机会的"外部机制切口"，必须拆到底源：资产类别/行业是"皮肤"，底源是"肌肉"。**

| 资本 | 皮肤(传统) | 肌肉(Reward Source 底源) |
|---|---|---|
| 股票 | "股票" | 企业利润 × 权益风险溢价 × 经济增长 |
| 黄金 | "黄金" | 货币信用 × 实际利率 × 储备需求 × 购买力(时变，见 D 反例) |
| 债券 | "债券" | 国家信用 × 实际利率 × 通胀 |
| 人力资本 | "职业" | 劳动力需求 × (技能稀缺 − 替代速率) |
| 保险 | "保险" | 风险转移(精算池分摊) × 国家社保制度 |

> 关键：**同一"皮肤资产"在不同人手里依赖的底源可能完全不同**（例：A 的股票=全球科技增长，B 的股票=中国地产-银行制度）。所以矩阵必须建在"底源×个人映射"，不能建在"资产类别"上。

## 五、Pseudo-Diversification Test（Q5，Agent B+Ant）

**四组合判定**：
| 组合 | 主因子 | 判定 | 反例登记 |
|---|---|---|---|
| **A** AI工作+AI股+AI创业+AI内容 | AI capex×科技人才×自动化 | **强伪分散**（1因子4皮肤） | — |
| **B** 公务员+地产+银行+现金 | 中国地产-财政-本币制度 | **中-强伪分散** | 现金在失业/技术替代维度是分散的 |
| **C** 美元工资+美股+美元现金+美国科技 | 美国科技+美元 | **部分伪分散**（科技股 vs 美股同指；但美元现金通缩/避险真对冲） | — |
| **D** 中国职业+全球股票+黄金+美元 | 跨因子 | **真分散（最强）** | 全球流动性危机时相关飙向1（failure≠同源） |

**Pseudo-Diversification Rule（4 步可操作判据）**：
1. **识别底源**：两资本各映射到哪些 Reward Source（用 Matrix1）
2. **同源判定**：是否共享 ≥1 个高暴露主源
3. **高相关佐证**：若可估，ρ(同源) 高（>0.6 仅 L3 参考）；
4. **共击复核**（接 Q7）：是否同时被同一 Common Shock 打击
> 若(2)&(4)皆为是 → **伪分散成立**：n 条同因子路径，下行时组合波动 ≈ 单一路径，不降险。

## 六、相关性：不该只用 Pearson（Q6，Agent B）

- Pearson price correlation **只适用于金融资产**——Human/Business/IP 无价格序列，测不了。
- **适用序（对 Personal EGS）**：Factor correlation > Income correlation > Regime/Shock correlation > Price correlation。
- Policy/Geographic/Currency/Technology correlation **只能结构化判断（L3）**。
- 结论：Personal EGS Correlation Matrix 应建在 **因子簇层**（先按 Reward Source 聚合，再相关），而非资产类别层。

## 七、Common Shock Matrix（Q7，Agent B）保留 **27 源簇全部源**

17 类冲击 → 打击节点矩阵（详见 [02_伪分散共击与级联.md](file:///D:/Contents/Research/Reports/2026-09-07_PersonalEGS_RewardSourceExposureMatrix/02_伪分散共击与级联.md)）。选中揭示：

| 冲击 | 同时打击 |
|---|---|
| **失业/行业衰退** | 人力资本(工资↓)+商业(客户↓)+权益(行业股↓)——但常不及现金 |
| **高通胀** | 现金(购买力↓)+工资(实际购买力↓)+债券(名义利息被吃)——**"通胀税"** |
| **高利率** | 权益(贴现↑)+地产(按揭↑)+高久期资产——**全局贴现逆风** |
| **技术替代** | 技能(S24)+IP+内容——同源级联 |

**核心辨析（用户重点要求，必须分清）**：
- **Common Shock（共同冲击）**：同时**打击**多个资本的机制（下行风险协方差）
- **Common Reward Source（共同奖励源）**：同时**驱动**多个资本回报的机制（上行回报协方差）
> 两者**不是一回事**，方向可以反向。最危险的组合是"**密集双暴露**"：同受打击+同获回报（如"投自己就业行业的股票"——裁员和股价齐跌是 Common Shock，泡沫和薪资齐涨是 Common Reward）。
> 判定规则：区分三个阵——①共同冲击阵(降险关注) ②共同奖励阵(回报关注) ③密集双暴露阵(最危险，要避免)。

## 八、Capital Cascade（Q8，Agent B）

**Shock → Mechanism → Capital Loss** 级联传播规则（4 规则）：
1. **带次序串联**：冲击先伤人力现金流，再沿"消费-储蓄-再投资"传至金融资本
2. **三中继放大**：信心 → 估值 → 流动性，级联加速
3. **可自持循环**：若无外援，重仓失败自增强（如 AI 裁员→消费降→广告降→AI 公司再裁）
4. **流动性 = 断链止损位**：现金缓冲在级联中是"断链节点"，可终止循环

**D2"AI 伪分散"对应级联**：
```
AI行业衰退 → AI岗位↓ → 工资↓ → 人力现金流↓
         ↘ AI创业营收↓
         ↘ AI内容广告/课程预算↓
         ↘ AI股票(若重仓)估值↓  → 再融资冻结 → AI创业融资↓(自持)
[止损节点：若保有正交现金R5/泛行业R6 → 极断链]
```

## 九、Capital Conversion Matrix（Q9，Agent C）

Matrix 4（九类资本 × 六维转换属性）。代表链：
- 现金 → 教育 → **Human Capital**（开销低、时间数月–年、成功率中、见 CGM/Benzoni）
- Human Capital → 工资 → **Financial Capital**（最高效，见三专长制）
- Knowledge → IP → **Business Capital**（T 时间，变现窗口）
- Reputation → Customers → **Business Capital**（信任，高协同）
- 现金 → 创业 → **Business Capital**（成功率高波动、杠杆双刃、不可逆部分）
- Cash → Global FD → **跨币区（C10）**（流动性最高）

**Capital Convertibility 指标（Agent C 定义，半结构，L3）**：
```
Convertibility_i = Σ_{通道} (1−损耗)(1−成本) × 成功率 × 时间衰减
排序：Safety≈Financial > Human > Network≈Reputation > IP≈Business > Physical(最低)
```
> 物理资产可转换性最低（呼应 D2"房产 8–12% 往返/30-90d）——高流动壁垒资产在转换窗口窄的人手里是"陷阱"。

## 十、Future Effective Path Space（Q10，Agent C）

**ΔPathSpace**：增加 1 单位资本新增的"有效未来路径"的量 + 去相关度（非收益率）。

| 新增资本 | 增路径效果 | 依据 |
|---|---|---|
| 现金 +10万 | **最高**（正交、即时、零转换损耗） | 增长期权 |
| 跨行业客户网络 | **很高**（复用技能、去相关） | — |
| 同因子新技能 | **低**（同源新皮肤，伪分散） | S24 |
| 可商业化 IP | 中（利用率依赖平台/注意力） | — |
| 海外正交金融资产 | **高**（增 C10 跨币/跨因子） | — |

> 核心：**路径价值来自"新增因子 + 转换低成本"，不是"名义资本增加"**。这与 D2"分散的是因子不是流"严格对齐。

## 十一、Reward Source Concentration（Q11，Agent C）

**RSCI 方法评估（未直接接受 HHI）**：
- **HHI(Σsᵢ²)** 局限：①少量路径即畸高 ②沿用资产层而非因子层 ③非交易资产/0暴露源无法定价 ④混淆"路径数少"与"因子集中"。
- **改良 RSCI_f（推荐）**：**按因子簇聚合**后再算 HHI（互补），并叠加 **NSRC（等效独立因子数）**。
- 因子层聚合 → 显性判 "AI 4 条流 = 1 因子"（与 D2/A 的源级判断一致）。
- Shannon entropy / Effective # 亦评估，作为 NSRC 的补充。

> 结论：Personal EGS 用**因子层 RSCI_f + NSRC**，比粗 HHI 更能暴露"伪分散"；但仍是 L3/J 构造，需 H(总人力现值)、W、各源暴露权重实证才能转 E。

## 十二、三维健康（Q12，Agent C）

三个维度：**Wealth / Reward Sources / Switchability**。
- 判据：**健康 = 财富足以覆盖转换窗口 + 跨 ≥2 独立因子 + 高可切换**。
- 公平讨论（非唯一解）：低财富但广分散可迁移（Payer 期权）通常健康，因为 Switchability 补 Wealth；但**当财富大到可自筑正交子组合时，排序可能反转**（高财富+集中但自我生成多元，也健康）。
- 结论（L3/结构）：**Switchability 是个人 EGS 区别于机构组合的关键维度——它把"迁移能力"资本化**。

## 十三、生命周期（Q13，Agent C）

用生命周期金融：人力资本现值随年龄**先升后降**（青壮年最高）。阶段结构变化：

| 阶段 | 人力资本(H) | 需增强 | 金融组合取向 | 注 |
|---|---|---|---|---|
| 20s/学习期 | 现值最大、人力≈债券 | 教育/技能(最高边际) | 因 H 大可高权益**但须低相关** | 反例警示 |
| 30s/转型期 | 现值大、但相关性待估 | 正交现金+泛行业(C10) | 进取放低相关/现金侧 | **对象当前阶段(D2)** |
| 40s/高收入 | 现值下降、收入稳定 | 转储蓄/资产积累 | 可增权益、降人力保险需求 | — |
| 50s/退休 | 人力≈0 | 年金/降杠杆/保险 | 增债券/降权益、耗 H | 人力资本耗竭 |

**关键反例（Agent C+D 双重警示）**："年轻应高权益"的**前提是人力资本与权益低相关**（债券化）；若人力资本与权益高相关（股票化，Benzoni-CDG），结论**反转为"年轻应近零权益、驼峰状"**——两者方向相反，该前提是**待估的个人 β，不是可假定**。

## 十六、反例 / 需改述的假设（Agent D，5 处）

1. **"分散的是因子不是流"一刀切过度**：个体只有 1-4 次实现，特异项无法大数平均化；同因子多流仍降低"个人特异尾部风险"，但几乎不降"系统因子方差"。改述：**判伪分散需区分"系统因子方差"(因子层，不降) 与"个人特异变异"(可降)**。
2. **"年轻可高权益"确认性偏差**：引"债券化→高权益"未引同源反例"高相关→近零权益"；两方向相反，前提是待估 β。
3. **黄金=尾部货币对冲（强 L1 反证）**：黄金×10Y 实际利率 −0.7~−0.85 关系 2022-24 崩解（JPM R²85%→16%）；2021-22 通胀>9%但金价跌>20%。**"利率主导的尾部"恰是与黄金对冲机制同向冲突的情景**→ 改述为"时变实际利率/美元对冲"。
4. **现金缓冲=唯一真增路径/5分**：需加"缓冲窗口内的期权价值 vs 超出部分的机会成本+通胀税"。
5. **人力资本现值 200-300万**：A/S 粗参考，不可用于权益权重推导。

> 纪律审计结论：模型**未预设资产级优序（合规）**；但既有 D2 存在 2 处确认性偏差 + 多处伪精确数字 + 缺"假设放弃清单"。已给出 5 处需改述件 + 移交配置层的 5 项升级数据。

## 十九、汇报式总结（回答母问题五个子问）

- **我到底拥有多少资产？** → 11 独立资本（去重后）+3 复合用途，需按"资产还能变现成什么"而非科目数。
- **依赖多少种独立奖励源？** → 用 NSRC/RSCI_f 测，对象当前倾向"因子级集中（AI）"，有效独立源少于资产数。
- **会不会同时失效？** → 用 Common Shock 阵（密集双暴露要警惕）；失业&技术替代攻击同一侧。
- **失效能否切换？** → 用 Convertibility + Switchability：现金/泛行业/海外正交最切得动，物理资产最锁死。
- **哪些新增增路径？** → 只有落在"新因子 + 低转换损耗"的新资本才增 ΔPathSpace；旧因子内第 N 条流是负边际。
