# 考研去留 · 逻辑链终版（2026-08-15 补全）

> 证据纪律：全部关键事实带来源与日期；概率标注[估算]；结论可被新证据修订（先记录再修订）

## 一、决策问题

- 选项A：2026.12 初试，中大非全大数据（085411，7.5万学费，备考约6个月）
- 选项B：AI 开发培训（2.5万学费，4个月，2027.01 入行）
- 时间冲突：2026下半年全力备考 vs 全力学技术，互斥；考上后非全=在职读（周末上课），可与工作并存

## 二、关键事实链（逐环证据）

**环1：非全报考硬前提 = 在职定向（劳动合同+社保）**
- 证据：中大研招办电话（2026-08-12，S级）"非全只招收在职定向就业人员；需单位保管人事档案+交社保"
- 推论：当前失业状态报考有障碍（除非操作妈妈个体户）；**工作后在职读天然满足**（工作单位=定向单位）

**环2：毕业证写明"非全日制"**
- 证据：研招办明确回答（S级）；08-12 调研：央国企校招封死非全、民企"锦上添花"、公务员基本放开
- 推论：学历的市场感知再降一档——"法律同等效力，证书有可见标注"

**环3：士兵专项——政策面未关闭，执行面两年零交叉**
- 证据：研招办"先报名获得资格，名额按专业分"（政策面S级）；中大复试公示 2025/2026 非全×专项零交叉（执行面S级）
- 推论：2027 级获专项概率 5-10% [估算]；章程 9 月下旬发布是确认点——**但确认了也来不及 2026.12 初试（只剩3个月+无定向单位），只能作为 2029 在职读的决策输入**

**环4：280分是误认**
- 证据：那是工学学硕线；非全大数据（085411）实际复试线 309/301（官网公示）
- 推论：用"低分好考"支持考研的论据不成立——真实门槛不低

**环5：学历在AI行业的真实权重**
- 证据：08-12 调研（真实JD）——AI应用开发本科即可（95%岗位不限制非全）；学历决定能否进面试（~20%权重），作品/项目经验决定录用（80%权重）
- 推论：非全硕士只解决20%的筛选关，不解决80%的录用关

**环6：学历不是35岁年龄保险**
- 证据：08-15 调研——清华硕士被裁；学历=赛道门票（央国企/研究院/算法硬门槛）非免死金牌；资深岗"1-3年硕士/3-5年本科"=市场自己定价：越资深越看经验
- 推论：为"防35岁危机"读研的动机不成立——防不住

**环7：时间线账（08-15 给父母版修正后）**
- AI 开发培训：2027.01 入行 → 三年累计约61万（基准）；回本2-3个月
- 考研：2027.07 入行（等复试录取）→ 三年累计约44万（基准）；回本5-6个月且晚2年
- 差距：工资差约17.4万 + 学费差5万 ≈ **22万（基准，区间17-35万）** + 少1.5年经验 + 多100天周末上课

## 三、不对称性分析（决策核心）

```
考上（概率30-50%[估算，官方数据修正自用户自估70%]）：
  收益 = 非全标注硕士 + 985牌子 + 系统训练
  成本 = 7.5万 + 6个月备考 + 100天周末 + 延迟入行半年到一年 + 在职定向绑定

考不上（概率50-70%）：
  损失 = 6个月备考时间全沉没 + AI 开发培训效果打折（分心） + 心理打击
  时间窗口 = 2027 入行推迟（不可逆损失）

不考（AI 开发培训）：
  收益 = 2027.01 入行，早1.5年经验，早22万+（基准），技术直接变现
  成本 = 没有硕士学历——但可 2029 在职读（可逆，见四）
```

**不对称结论**：考研的赌注（6个月+7.5万+100天周末）换"锦上添花"学历；AI 开发培训的赌注（2.5万+4个月）换"早入行+真技术+现金流"。**大额慢周转 vs 小额快周转。**

## 四、可逆性分析（不确定性的关键解药）

| 决策 | 可逆性 | 说明 |
|------|--------|------|
| **不考** | ✅ **可逆** | 2029 在职读非全=工作后读，天然满足所有约束（单位=定向单位、有社保、有钱、毕业证标注无所谓）——**"不考"不关闭任何门，只推迟** |
| 考了没考上 | ❌ 不可逆 | 6个月+时间沉没，2027 入行推迟 |
| 考上了 | 部分可逆 | 可放弃入学，但浪费报名+备考 |

**核心**：决策的不对称性 = 不考的下行风险（少个学历，可后补）远小于考的下行风险（时间+金钱+心理沉没）。**理性人选择不可逆性小的一侧。**

## 五、不确定性来源逐个拆解

1. **"万一以后要硕士才能进某些公司/考公/央国企？"** → 2029在职读可补（可逆）；央国企校招封死的是应届非全，社招看单位；公务员基本放开
2. **"士兵专项没准2027给了呢？"** → 概率5-10%[估算]（两年零交叉）；且给了也不改变"非全标注+在职定向"减分项；章程9月下旬确认，但确认了也来不及2026.12考——只是2029的输入
3. **"本科是不是低人一等？"** → AI应用开发本科可投（S级JD证据）；学历=赛道门票非年龄保险；作品集=自己的"学历"
4. **"考不上怎么办？"** → 50-70%概率，6个月沉没；AI 开发培训路线没有此风险
5. **"别人都读研我是不是落后？"** → 参照点管理失败（自身教训：参照点推太高会失望）；比较对象=35岁的自己，不是别人
6. **"这个决策是不是冲动了？"** → 不是：七轮调研+官方电话+全部落盘可查；28个工作日+决策记录，非情绪决策

## 六、结论

- **拍板：不考（2026.12初试），AI 开发培训 2026-08-16 入学**
- **保留期权：2029 在职读非全**（工作稳定后，若需要赛道切换/学历门槛/系统训练）
- **保留监测点：2027级章程（2026-09下旬）**——专项是否给非全名额，作为 2029 决策输入（非当前翻盘点）
- **决策可被新证据修订**：若 2029 前后出现"必须硕士"的硬门槛（如央国企社招全线要求硕士），重新评估在职读
