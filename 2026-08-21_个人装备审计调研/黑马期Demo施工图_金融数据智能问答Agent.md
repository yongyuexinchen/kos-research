# AI 开发培训期 Demo 施工图：金融数据智能问答 Agent（RAG+记忆+评测）

> 提案日期：2026-08-21 ｜ 来源：《2026-08-21 个人装备审计调研》合成判断 + 用户拍板
> 垂直领域：金融/数据服务（用户拍板 2026-08-21，否决政务方向）
> 定位：AI 开发培训期（2026-08-16 起 16 周）唯一主任务——造出第一件"时代买得起"的成品
> 一句话：做一个"金融数据/指标口径智能问答 Agent"，用数仓经验 + RAG + 记忆 + 评测四件套敲门

---

## 一、为什么做它（选型逻辑）

1. **资产匹配度最高**：上海钢联 JD 原文"有数据治理+大模型落地经验优先"（硬证据）；神州信息 Text2SQL 智能数据服务岗；金融数据口径/血缘/质量=数据治理看家活
2. **投资经验=隐藏资产**：用户炒股（牧原/创新药/长电），懂财报/指标/口径——评测集可以用自己的真实问题，面试扛得住深挖
3. **薪资更高**：金融数据服务薪资普遍高于泛B端知识库
4. **本地优先天然成立**：金融数据合规要求极高（数据不出域），本地部署叙事价值最大化

## 二、技术栈（全用已有资产）

| 层 | 选型 | 说明 |
|---|---|---|
| 模型 | DeepSeek API（.env key）主用 + Ollama 本地小模型备用 | 演示"本地优先"叙事 |
| Embedding | bge-m3（已用过） | 已有经验 |
| 向量库 | ChromaDB 或 SQLite-vec | 本地优先，不上 Milvus |
| 后端 | FastAPI（AI 开发培训在学） | 手敲纪律 |
| 记忆存储 | SQLite | 手敲，可导出=差异化 |
| 界面 | Streamlit | 半小时出聊天界面 |
| 评测 | 手工评测集（30题）+ 跑分脚本 | 市场 P0 要求 |

**手敲范围**：RAG 主流程（分块→检索→组装）、记忆模块（存→提取→注入）手敲；重复部分 AI 生成。

## 三、场景设计（demo 做什么）

| 场景 | 面向 | 问什么 | 记忆的价值 |
|---|---|---|---|
| ① 指标口径问答 | 数据使用方 | "ROE统计口径是什么""营收含不含并表子公司" | 记住用户关注的股票/常用口径偏好 |
| ② 财报/研报问答 | 投资者/分析师 | "牧原2025毛利率多少""创新药集采影响哪些指标" | 多轮追问"上次那个指标" |
| ③ 金融知识问答 | 新手/内部培训 | "PE和PB区别""市占率数据来源哪" | 记住用户知识水平 |

**核心痛点**：金融数据治理的"口径管理"——同一指标不同部门口径不同，这是数仓经验里的看家活。

## 四、数据源（全部公开可得）

1. 上市公司财报：巨潮资讯网/上交所/深交所公开年报季报（PDF→文本）
2. 券商研报公开摘要（慧博/东方财富公开部分）
3. 财务指标口径说明（证监会/交易所披露规则文档）
4. 金融术语词典（公开）
5. **用户自己的投资问题**（牧原/创新药/长电的真实问题）→ 评测集

**红线**：不碰任何涉密/付费数据，只用公开披露——面试里强调"我懂什么能公开什么不能"本身是加分。

## 五、六模块拆解

```
① 数据层：财报/研报/口径文档 → 清洗 → 分块 → bge-m3 向量化 → 存 SQLite-vec
② RAG层：混合检索（BM25+向量）→ 组装上下文 → DeepSeek 生成
③ 记忆层（差异化核心）：对话历史存 SQLite → 提取用户关注标的/口径偏好 → 检索注入 → 支持"上次那个指标"
④ 评测层：30题评测集（含用户真实投资问题）→ 跑分脚本 → 准确率/漏检率报告 → Bad Case 分析
⑤ 演示层：Streamlit 聊天界面 + 架构图（mermaid）
⑥ 工程层：重试/降级/Token成本统计/配置化
```

**记忆层是灵魂**：别人做金融问答只做②，你加③④ = "Agent记忆"+"评测闭环"两个市场高频词的落地。
