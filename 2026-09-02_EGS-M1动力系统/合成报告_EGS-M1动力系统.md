## 〇、摘要

EGS-M1 把 M0 的"系统会不会崩"升级为"崩了以后人往哪走"，并让人的选择反作用于系统。模型包含用户 2026-09-02 分析指定的三件核心装备：

1. **P/S 不对称衰减**：承诺期望 P 以 γ_P 速率向担保现实回归、制裁期望 S 以 γ_S 速率回归，γ_P > γ_S——"恐惧比承诺活得久"的显式动力学；
2. **策略选择**：个体在每个时刻以 softmax 从 {参与, 退出, 替代担保, 降欲, 重建} 中重分配概率（EGS-Choice 层）；
3. **担保闭环**：担保容量 G 的再生依赖参与率（π_participate），消耗来自制度优化压力 c(t)——个体选择反作用于系统。

数值实验得到三个结果：
- **Q1（不对称衰减）**：制度压力缓慢爬升时，G 跟随式下滑（看似平稳），P 崩塌快于 S（GAI 从 0 扩大到 +0.5），跨过信任临界后突变崩塌——"渐变中的突变"；
- **Q2（替代担保决定逃逸方向）**：同一担保状态 (G=0.45, P=0.30, S=0.68) 下，替代担保 A 从 0.1 升到 0.9，个体策略从"参与 87%+降欲 8%"转为"参与 39%+替代 54%"——**相同社会失信 → 不同文化形态，调节变量是替代担保结构**；
- **Q3（替代担保悖论）**：高 A 社会主担保反而更早跨临界（A=0.9 于 t=96 vs A=0.1 于 t=112）——替代担保在**个体层缓冲绝望**（崩溃后 A=0.1 社会：退出 77%+降欲 22%；A=0.9 社会：替代 31%+重建 29%），但在**系统层分流参与、削弱主担保再生产**——这定义了 **Regime Transition**（一种"正常"向另一种"正常"的让位）的动力学机制。

## 一、模型定义

### 1.1 状态变量

| 变量 | 含义 | 域 |
|------|------|-----|
| G(t) | 主担保容量（传统社会承诺的兑现能力） | [0,1] |
| P(t) | 承诺期望（个体预期"做了X会得Y"） | [0,1] |
| S(t) | 制裁期望（个体预期"不做X会遭Z"） | [0,1] |
| A | 替代担保可得性（宗教/社区/AI 伴侣/亚文化；外生参数） | [0,1] |

### 1.2 动力学方程

**P/S 不对称更新**（公理实现：承诺期望快崩、制裁期望黏滞）：
```
失效压力   f(G) = 1 − G
承诺期望   dP/dt = γ_P · f(G) · (G − P)         γ_P 大 → 快速跌向担保现实
制裁期望   dS/dt = γ_S · f(G) · ((1+G)/2 − S)    γ_S 小 → 缓慢跌向"黏性水平"
```
（γ_P=2.5 > γ_S=0.45；G→0 时 P→0 快、S→0.5 慢 ⇒ GAI = S−P 扩大）

**策略选择**（softmax / random utility，τ 温度）：
```
V_participate = α_G·G + α_P·P
V_exit        = β_E·(1−G) − C_E
V_substitute  = β_A·A − C_A
V_desire_off  = β_D·(1−P) − C_D          （欲望关闭：P 崩时"不敢想要"）
V_rebuild     = β_R·A·(1−G) − C_R
P(Y_i) = exp(V_i/τ) / Σ_j exp(V_j/τ)
```

**担保闭环**（再生依赖参与率 + 制度压力随时间爬升）：
```
dG/dt = ρ·T(G)·(1−G)·(θ₀ + θ₁·π_participate) − c(t)·x*(G)
T(G)  = sigmoid(k(G − Gc))                 （信任：低于临界即崩）
x*(G) = a / (b + λ(1−G))                   （M0 优化强度：担保越足越敢优化）
c(t)  = c₀ + c_rate·t                      （制度优化压力缓慢爬升）
```

**模型逻辑链**：
```
制度压力↑ → G 下滑（渐变） → P 快崩 S 慢崩（GAI↑）
  → 策略概率重分配（参与↓ 替代/降欲/退出↑）
  → π_participate ↓ → 再生流失 → G 加速下滑（正反馈）
  → 跨过信任临界 → 突变崩塌 → 替代担保接住个体（或绝望）
```

## 二、与三层理论架构的对应

| EGS 架构层 | 本模型中的位置 | 状态 |
|-----------|--------------|------|
| **EGS-Core**（为什么产生 P+S；不对称假说） | P/S 更新方程 + γ_P>γ_S（公理层，参数化不推导） | 预设（引用 v1.x 实证） |
| **EGS-Dynamics**（担保如何演化） | G 动力学 + c(t) 爬升 + 信任临界 | M0 升级版 |
| **EGS-Choice**（崩了以后人怎么逃） | softmax 策略选择 + 替代担保 A | **M1 新增核心** |
| **Regime Transition**（一种正常→另一种正常） | Q3 的替代担保悖论（自发涌现，非预设） | M1 涌现结果 |

**关键：Choice 层反馈进 Dynamics 层**（π_participate 进入 G 的再生）——这是 M1 相对 M0 的本质升级，也是"众生百态"第一次拥有力学位置。

## 三、数值结果

### 3.1 Q1：不对称衰减与"渐变中的突变"（fig1）

制度压力 c(t)=0.60+0.011t 缓慢爬升（A=0.2 场景）：

| t | G | P（承诺期望） | S（制裁期望） | GAI=S−P | 参与率 |
|---|-----|------|------|--------|-------|
| 0 | 0.94 | 1.00 | 1.00 | 0.00 | 100% |
| 30 | 0.77 | 0.78 | 0.90 | +0.13 | 100% |
| 60 | 0.70 | 0.71 | 0.86 | +0.16 | 100% |
| 90 | 0.62 | 0.63 | 0.82 | +0.19 | 100% |
| 105 | 0.56 | 0.57 | 0.79 | +0.23 | 100% |
| 120 | **0.00** | **0.00** | **0.51** | **+0.51** | **0%** |

**读数**：
- t∈[0,105]：G 跟随式下滑（0.94→0.56），系统"看似平稳"——P 快跟（1.0→0.57）、S 慢跟（1.0→0.79），GAI 温和扩大（0→0.23）；
- t≈112 跨过信任临界（Gc=0.45）后**突变**：G→0、P→0（承诺期望全崩）、S→0.51（制裁期望仍半高位）、GAI 跳到 +0.51——**"恐惧比承诺活得久"在最坏处精确成立**；
- 参与率从 100% 断崖到 0%，退出 77% + 降欲 22% 承接（低替代社会的绝望形态）。

### 3.2 Q2：策略概率重分配（fig2）+ 替代担保比较静态（fig3）

**（a）时间演化**（fig2）：参与率在临界前保持高位（制度仍可信），跨临界后概率质量从"参与"转向"退出/降欲"——**不是所有人躺平，是概率分布整体迁移**。

**（b）比较静态**（fig3，固定状态 G=0.45, P=0.30, S=0.68）：

| 替代担保 A | 参与 | 退出 | 替代担保 | 降欲 | 重建 |
|-----------|------|------|---------|------|------|
| 0.1 | 87% | 5% | 0% | 8% | 0% |
| 0.3 | 86% | 5% | 1% | 8% | 0% |
| 0.5 | 83% | 5% | 4% | 7% | 0% |
| 0.7 | 70% | 4% | 19% | 6% | 1% |
| 0.9 | 39% | 2% | **54%** | 3% | 1% |

**读数**：同一担保状态（同一"社会失信"），仅替代担保供给不同 → 策略分布系统性分化——**EGS 水平不是充分条件，替代担保结构决定逃逸方向**。这正是"韩国式绝望 vs 北欧式重组"或"宗教复兴 vs 躺平"分野的模型位置。

### 3.3 Q3：替代担保悖论与 Regime Transition（fig4 + 崩溃后截面）

**跨临界时刻随 A 的变化（反直觉结果）**：

| A | 跨临界时刻 |
|---|-----------|
| 0.1 | t=112 |
| 0.35 | t=112 |
| 0.6 | t=110 |
| 0.9 | **t=96（更早！）** |

**崩溃后截面（主担保 G 均崩到 0）**：

| A | 退出 | 替代担保 | 降欲 | 重建 | 文化形态 |
|---|------|---------|------|------|---------|
| 0.1（低替代） | 77% | 0% | 22% | 0% | **绝望文化**（退出+降欲主导） |
| 0.9（高替代） | 31% | 31% | 9% | 29% | **迁移文化**（替代+重建承接） |

**替代担保悖论（本模型最重要的涌现发现）**：
- **个体层**：A 高 → 崩溃后个体被替代担保/重建接住（不绝望）——**缓冲成立**；
- **系统层**：A 高 → 更多个体转向替代担保 → π_participate 下降 → 主担保再生的参与基础流失 → **主担保 G 更早跨临界**——**缓冲失效甚至加速**。

这不是模型缺陷，而是定义了 **Regime Transition 的机制**：替代担保不是"修补旧系统"，而是"为新系统募集移民"。当替代担保足够有吸引力时，旧担保系统的崩溃不是灾难而是**让位**——一种"正常"被另一种"正常"替换（H6 的动力学意义）。高 A 社会的主担保崩溃时刻更早，但崩溃后的个体状态远好于低 A 社会——**同一个"崩"字，两种命运**。

**对 H4（AI 伴侣）的理论升级**：AI 作为替代担保节点 A_AI 上升时——个体层缓冲孤独与绝望（P4.1 支持），系统层则意味着传统担保（工作/家庭/制度承诺）的参与基础被分流（"个体转向私人担保"）——**Guarantee substitution 不是产品问题，是担保系统的迁移动力学**。

## 四、与机器学习同构的定位（回应架构建议）

按"不要把同构放 EGS-Core"的建议，EGS-M1 的同构对应放在 **Dynamics + Choice 层**：

| EGS-M1 元素 | 机器学习/控制对应 |
|------------|------------------|
| P/S 不对称衰减（γ_P>γ_S） | 不对称正则（负样本权重更高）；损失函数的不对称惩罚 |
| G 再生依赖参与率 | 数据飞轮（用户参与→数据→模型→更多用户）；DAU 依赖 |
| c(t) 制度压力爬升 | 训练步数增加→过拟合压力累积 |
| 信任临界 Gc | 分布失配阈值（性能悬崖） |
| softmax 策略重分配 | 策略梯度/策略搜索（policy reallocation） |
| 替代担保 A | 替代假设空间/多任务分支/迁移目标域 |
| 替代担保悖论 | 多任务学习的负迁移（auxiliary task 分流主任务资源） |

**定位声明**：EGS-M1 不是"社会版机器学习"，而是"受约束自适应系统的策略-资源闭环"的一个实例化；机器学习同构是事后发现的桥梁（理论升级接口），不是理论前提。

## 六、局限与下一步

### 局限
1. A 为**外生参数**——替代担保供给本身不演化（现实中宗教复兴/AI 伴侣渗透是内生的）；
2. 单一主担保 G——未实现多维 GFR 向量（G_work, G_housing, G_family...），韩国案例的"住房通道 vs 就业通道"分化无法表达；
3. 策略集固定 5 项——真实策略空间连续且含隐性抵抗等；
4. 确定性 ODE——无个体异质性（δ 分布）与随机冲击；
5. 参数为理论设定，未校准真实数据（时间尺度无实证锚点）。

### 下一步（M2 方向）
| 优先级 | 扩展 | 目的 |
|--------|------|------|
| P0 | **A 内生**（dA/dt = σ·(1−G)·(A_max−A) − δA：担保失败催生替代供给） | 宗教复兴/AI 伴侣渗透的内生动力学 |
| P0 | **多维 G 向量**（G_work/G_housing/G_family...各自 P_i/S_i） | 韩国案例：就业通道崩但住房通道崩得更狠 |
| P1 | 个体异质性（参数分布 + 随机冲击，蒙特卡洛） | 从"概率分布"到"人群异质性" |
| P1 | 校准：用 v1.3/v1.4 数据（青年失业→TFR；排斥→婚姻）锚定参数 | 从机制演示到实证模型 |
| P2 | 双稳态验证：A 内生后系统是否出现"旧担保 vs 新担保"的双稳态并存与滞后 | Regime Transition 的完整相图 |

## 七、结论

**EGS-M1 回答了 M0 回答不了的问题**：M0 说"系统会崩"（临界转变），M1 说"崩了以后变成什么取决于替代担保结构"（Regime Transition）。三个核心读数：

1. **不对称公理有了动力学形态**：G 渐变下滑期 GAI 温和扩大（0→0.23），跨临界后跳到 +0.51——承诺期望全崩、制裁期望仍半高位，"恐惧比承诺活得久"在系统最坏处精确成立；
2. **"相同失信→不同文化形态"有了模型答案**：调节变量是替代担保结构 A（比较静态：参与 87%→39%、替代 0%→54%）；
3. **替代担保悖论是最大涌现发现**：个体层缓冲、系统层让位——它把 H4（AI 伴侣）、H6（两种正常）、Regime Transition 焊成一条动力学链：**担保失败 → 策略搜索 → 替代担保分流参与 → 主担保让位 → 新"正常"成形**。

这也正是用户 2026-09-02 分析所预见的："EGS 未来可能不是社会理论，而是一类动力系统"——M1 是这条路上的第一个完整闭环。
