# 任务定义：EGS 同构理论勘测——防重复造轮子的理论生态位地图（Phase 0）

日期：2026-09-02
类型：理论勘测（学科生态位扫描，非单一假设检验）
触发：用户——"接下来我要你做EGS同构理论调研，这个调研是为了避免我们之后重复做轮子……就像我们没有预见到机器学习的模型正则化和EGS理论同构一样，这样我们为理论拓展和落地做基础建设"
预印本：`github.com/yongyuexinchen/egs-theory`（v1.4 命题集，作者 Yong Yue）

## 一、任务本质

**事前勘测**：EGS 理论的核心构念，在多大程度上已被其他学科的既有理论独立发现过？哪些"发现"实际上是撞车（重复造轮子风险）？哪些是 EGS 真空白（文献空白，值得继续投入）？每个同构方向能借用什么现成工具（方法/量表/数据集/模型）？

上一轮已确认一个事后才发现的高撞车点：**机器学习正则化/控制理论（EGS-M0 模型）**——本勘测要把这类撞车点系统化地事先找出来。

## 二、EGS 核心构念清单（勘测对象，来自 v1.4 命题集）

| # | 构念 | 定义 |
|---|------|------|
| C1 | 存在担保系统（EGS） | 正面承诺（"做X得Y"）+ 负面制裁（"不做X遭Z"）双轨结构 |
| C2 | 担保不对称公理 | **"恐惧比承诺活得久"**：正面承诺期望比负面制裁期望崩塌更快 |
| C3 | 期望担保兑现率（GFR） | 个体预期社会未来兑现承诺的程度（前瞻性） |
| C4 | 担保不对称指数（GAI） | Z(制裁期望) − Z(承诺期望) |
| C5 | 担保人（Guarantor） | 保证"做了X就能如何"的存在体；兑现率升/降 |
| C6 | 逃逸线（H5） | 担保失败后分叉：逃离（退出）vs 重建（替代担保） |
| C7 | 收编三轨 | 逃逸归宿：价值（资本商品化）/权力（政治化）/话语（道德化） |
| C8 | 两种"正常"+排斥力（H6） | 规范正常通过排斥/不容忍强度操作化；排斥力降→行为扩散 |
| C9 | 惩罚设计三杠杆 | 国家权力/企业权力/话语权力 |
| C10 | 临界转变/崩塌动力学（M0） | 担保容量临界消耗→突然崩塌（上轮同构报告） |
| C11 | 个体层：欲望关闭（P1.4） | 高惩罚压力→抱负下降（"不敢想要"） |
| C12 | AI 伴侣作为新担保人（H4/P4） | 技术物替代人类担保 |

## 三、勘测学科域（并行子代理分组）

| 组 | 学科域 | 重点寻找的同构理论 |
|----|--------|-------------------|
| A | 心理学/行为科学 | 损失厌恶与负性偏差（"恐惧>承诺"的撞车?）、心理契约违背（psychological contract breach）、习得性无助、系统正当化（Jost）、希望/绝望理论、目标脱离（goal disengagement）、世界假设理论（Janoff-Bulman） |
| B | 经济/组织/博弈 | 契约理论与委托代理、Hirschman Exit-Voice-Loyalty、信任博弈、利他惩罚（Fehr & Gächter）、心理契约文献（组织侧）、激励理论、prospect theory |
| C | 社会/政治/演化/跨学科 | 社会契约论与制度信任、合法性（Weber/现代）、社会资本（Putnam）、社会规范（Bicchieri）、相对剥夺、福利国家制度（Esping-Andersen）、成本信号理论（costly signaling）、互惠演化、TMT 恐怖管理理论（EGS 自称扩展——核对关系） |

## 四、输出判据（每个同构点都要给出）

1. **同构点**：EGS 哪个构念 ↔ 哪个既有理论/概念
2. **代表文献**：作者/年份/关键结论（禁编造，L2 优先）
3. **差异点**：EGS 与既有理论不同的地方（哪怕同构，EGS 的增量是什么）
4. **撞车风险等级**：🔴 高（EGS 可能重新发明，需引用并差异化）/ 🟡 中（部分重叠）/ 🟢 低（EGS 空白，值得投入）
5. **可借用工具**：方法/量表/数据集/模型/实证先例
