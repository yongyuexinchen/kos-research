# 决定性实验 v2 · 预注册协议（2026-08-30）

> **性质**：预注册文档——**§三冻结项在正式实验开始前落盘生效，开跑后不可修改**；任何修改必须另开 v3 协议并在报告"协议偏差"节声明。
> **目的**：回答方法发现引擎的生死问题——**结构脚手架（比喻模型 M + fit + 投影契约）比裸 LLM 跨域判断和语义 embedding，多捞到什么？**
> **上游**：《研究进程与文档索引》《GPT对齐过程记录》《方法发现引擎_定位与主线》（双分数/清单核对/防条件偷搬）《投影契约》《类比检索系统_工程架构_v0.1》
> **对 v1 的关系**：v1（fit_vs_baseline 报告）降级为 **pilot**——其基线过弱（词袋 Jaccard）、M 关系事后可选、n=1 查询，均不构成判据；v1 的 12 卡与结果只作管道调试与假设来源。

## 一、术语定义（先手拆弹，Hermes 补丁采纳）

- **方法（method）**：已验证的**推理/策略模式**（proof-plan 层：构造辅助对象→建不变量→推矛盾这类步骤链），即 KOS 卡的"机制段/因果链详述"——**不是算法本身**。论文与报告首次出现时按此定义。
- **发现（discovery）**：**rediscovery, not invention**——让库内已验证方法被另一个领域的问题重新找到。不声称发明新方法。
- **真远亲（true far neighbor）**：与查询问题在机制层同构、且表面词汇零/低重叠的卡。**标签独立性是本实验的命门**（v0.2 G↔B、v1 语音克隆的教训：标签不得由实验参与者的结构直觉产生）。

## 二、要回答的三个问题（拆开"净贡献"，防归因困难）

- **Q1（机器的存在意义）**：结构脚手架（A2）vs 裸 LLM 判断（A1）——同信息不同脚手架，脚手架的净贡献 = A2 − A1
- **Q2（结构通道的存在意义）**：脚手架（A2/B）vs 纯语义 embedding（C）——表面零重叠场景下 embedding 是否必然失效（公平性声明见 §四.6）
- **Q3（归因）**：B（纯机器 fit）vs A1——fit 的贡献是否独立于 LLM 脚手架

## 三、冻结项清单（开跑前逐项落盘确认，打勾后不许动）

- [ ] **F1 M 冻结**：每个查询的比喻模型 M 由 Agent1 生成→Agent2 审计→PASS 后冻结（含核心关系集合、inference_permission），**哈希落盘并记时间戳；冻结发生在任何候选卡被评分之前**。v1 的 R6/R7 手选模式禁止重现——M 生成者不得知晓候选卡内容（生成/排序解耦）。
- [ ] **F2 评分函数冻结**：fit(card,M) 的关系权重、通过阈值、精确算式落盘（代码+参数 commit），之后不调。
- [ ] **F3 查询集冻结**：6-10 个查询（3 个已成型：DHCP 公共浴场/防冒充/堵塞-衰竭 + 3-7 个新增）。新增查询由"只见过问题域、没见过候选排序"的流程产生；查询文本用**用户自然领域语言**，禁止掺入目标域词汇（现实性原则）。冻结后不许换、不许加（跑不完就截断，不许挑）。
- [ ] **F4 标签冻结**：每个查询的 真远亲×3 / 表面负×5 / 结构不完整负×5，标签来源两选一：①外部文献/历史记载锚定（列出来源）②**双盲双标**——用户与 Hermes 各自独立标注后比对，一致才收，不一致对剔除或仲裁（仲裁记录落盘）。标注者不得先看任何方法的排序结果。
- [ ] **F5 prompt 模板冻结**：A1/A2 的 LLM 判断 prompt 模板、模型（DeepSeek）、temperature=0、候选呈现顺序**随机化**（Lewis & Mitchell 教训：LLM 对顺序敏感）——模板文本落盘。
- [ ] **F6 判定规则冻结**：见 §五生死线，数值写死。
- [ ] **F7 臂间隔离**：各臂实验独立执行，任一臂的结果在全部臂跑完前不得反馈修改其他臂的任何参数。

## 四、实验设计

1. **候选池**：每查询 ~13 卡（3 正 + 10 负），从库内正式卡复用，负样本挑选者不看 fit/LLM 任何输出。
2. **五臂**：
   - **A1 裸 LLM 判断**：输入=问题原文+候选卡原文（无 M、无审计单、无比喻故事），问"该卡的方法/机制与此问题结构是否相容"，输出分数排序
   - **A2 脚手架 LLM 判断**：同 A1，附加冻结版 M + 投影审计单（faithful/emergent/inference_permission 全给）
   - **B fit(card,M)**：纯机器结构评分（冻结版 F2），无 LLM
   - **C bge-m3 embedding**：问题文本 vs 卡全文，余弦排序（语义基线）
   - **E 关键词/Jaccard**：下界哨兵，仅验证管道未坏，不进判定
3. **采集纪律**：LLM 判断每查询×每卡跑 3 遍取中位（防温度漂移），原始输出全落盘（不滤"难看"的回复）；A1/A2 判断者不知道彼此存在。
4. **全量报告纪律**：所有查询×所有臂×所有候选的原始分数表落盘，不挑极值、不删查询（继承 v0.2 "全矩阵全报"纪律）。
5. **统计边界声明**：6-10 查询的功效有限——结果分三级解释（方向性/强信号/决定性），"决定性"仅当 Q1 差距超过 §五阈值且方向在多数查询一致。
6. **公平性声明（预写进报告）**：C（embedding）在跨域零词汇重叠场景天然劣势——这是**现实场景的忠实设定**（用户用自己的领域语言提问），不是基线歧视；但报告必须同时给"查询含目标域词汇"的对照版 C'，排除"查询措辞人为压制 embedding"的质疑。

## 五、生死线（F6 预注册数值，写死）

主指标：**Cross-domain Recall@10**（真远亲进前 10 的比例）+ **Hard-negative rejection**（前 10 中表面负样本数，越少越好）。辅指标：MRR、nDCG。

| 情形 | 判定 | 后果 |
|---|---|---|
| A2 ≥ A1 + **0.15**（Recall@10）且 A2 的 hard-negative rejection 优于 A1 | **脚手架有净贡献** | 线活，继续 M0/黄金集扩建 |
| A2 − A1 < **0.05**，且 B 亦不优于 A1 + 0.05 | **裸 LLM 已够** | **停线**（比喻/脚手架层撤销），转回纯签名检索工程线或放弃 |
| B > A1 + 0.05 但 A2 ≈ A1 | fit 有效但 LLM 脚手架无增益 | 降级：机器结构检索线保留，比喻包装层降为可选 |
| A1 完全失败（自身 Recall@10 < 0.3）而 A2 正常 | 裸 LLM 不够、脚手架是必需品 | 最强活信号（等价于 Q1 大差值） |

## 六、与并行工作的协调（给 Hermes 的执行边界）

- **现在就可以跑的**：A1 裸基线按 v1 的 12 卡/浴场查询跑——**数据只能标 pilot（探索性）**，用于校准 prompt 和观察 LLM 判断的分布形态；**不进 v2 判定**（v1 查询集/候选池未按 F3/F4 冻结）。
- **正式 v2 跑的条件**：F1-F7 全部打勾落盘之后。建议顺序：F3 查询集+候选池 → F4 双盲标注 → F1 M 生成与冻结 → F2/F5/F6 参数冻结 → 五臂开跑。
- **S0 依赖**：27B/DeepSeek 抽取质量影响 A2 的审计单与 M 生成——记录所用模型与版本，作为协变量报告。
