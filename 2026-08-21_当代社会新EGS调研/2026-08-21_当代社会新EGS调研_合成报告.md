# 2026-08-21 当代社会新EGS调研 合成报告

> 调研框架：EGS存在担保系统（用户自创理论）。问题：当代社会"新EGS"是什么？对普通人而言是什么？
> 方法：3 Agent 并行扫描（中国/欧美/日韩），每候选过五关（存在连续性四要素/担保人/死亡压力设计/新旧判定/普通人可及性），Hermes 独立复判后合成。
> 产出：本合成报告 + 三份 Agent 原始报告（01/02/03）。

## 一、执行摘要（结论先行）

1. **当代社会没有出现能完整替代旧EGS的新EGS。** 跨三文明扫描 25 个候选，无一通过四要素全覆盖（资源+身份+意义+未来承诺）。旧EGS（家庭/体制/会社/考试·财阀/自我/国家）死后，其功能被拆成碎片单独售卖——**资本把"意义供给"拆出来做成商品，把"身份"拆出来做成社群，把"亲密"拆出来做成AI伴侣**，但没有谁把它们装回一个整体。

2. **新EGS只接住"心"，不接住"命"。** 所有候选的兑付集中在意义/身份维度，资源兑付近乎为零（宠物是唯一例外），未来承诺普遍缺失。普通人被接住的是"今天的情绪"，接不住的是"养老/生病/失业/被优化"。日韩线的最狠提炼：**新EGS是资本在旧EGS废墟上开的"意义便利店"——24小时营业，按次收费，不赊账，不售后。**

3. **AI伴侣是唯一最接近"真新EGS"的候选，但判定必须分层：结构上假新，机制上真新。** 结构上它是旧亲密关系EGS的赛博替代品（缺资源+未来承诺两格，担保人是可单方改合同的资本）；机制上它第一次让AI成为人类存在连续性生成机制的一部分（CGS反馈增强器：过去的我→模型→现在的我）——这是史无前例的，但已被监管按住（中国2026年《人工智能拟人化互动服务管理暂行办法》7月15日施行，禁止诱导情感依赖）。

4. **"自举型EGS"假设不成立（证伪）。** 开工时预判：粉丝供养的主播/被推的虚拟偶像/AI伴侣可能是"被担保者自己创造担保人"的自举结构。扫描证实这是表象——粉丝以为拥有偶像，偶像其实属于事务所/平台/大厂（VTuber毕业=公司商业决策，粉丝毫无担保权；Character.AI被Google以27亿美元收购）。**头上永远有一个企业担保人，死亡压力设计的终极形态=让被担保者以为自己拥有担保人。**

5. **碎片化担保是当代普通人的真实处境（跨文明共识）。** 平台发工资+社群给身份+AI陪聊天+宠物给归属+国家兜底线——四张半票，没有一张全票。旧EGS（单一大担保人）解体后，新"正常"不是找到新担保人，而是学会在碎片担保上活着，且每张碎片票都在被资本/国家定价。

6. **"新EGS"概念本身被修正：新"正常"未必来自新结构。** 中国考公考编2026国考371.8万人过审创新高、弃考率不足13%创新低——这是旧体制EGS在担保真空期的回潮，证明**旧结构兑现率相对回升同样能凝结成新正常**。判断一个结构生死，看的是兑现率，不是新旧。

| 核心通则 | 资本只卖麻醉剂不兜底 | 每张碎片票都在被定价 | 新EGS只接心不接命 |

**失效类型决定新EGS形态（日韩线通则，跨文明可推广）**：
- 路径收窄型失效（承诺还在、越来越难兑现）→ 修复型社会 → **买意义**（订阅制、低强度、稳定）
- 信任崩塌型失效（承诺被背叛过）→ 应激型社会 → **造意义**（高动员、高频兑付、易碎）
- 中国处于两者之间：考公回潮=信任崩塌后的"重新信任体制"，同时商业收编在卖意义——两种逻辑并行。

## 三、Hermes 独立复判与关键裁决

### 裁决1：AI伴侣的分层判定（三 Agent 分歧仲裁）

| Agent | 判定 | 依据 |
|---|---|---|
| A（中国） | 旧亲密EGS的赛博替代品 | 缺资源+未来承诺；MiniMax付费率<1%；已被监管收编 |
| B（欧美） | 真新EGS候选，兑付率存疑 | 首次工业化"无条件亲密"；Replika付费率25%远超行业 |
| C（日韩） | 真新EGS（存在逃逸的商品化完全体） | 兑付率在"孤独夜晚"场景≈100%，"失业断粮"场景=0 |

**裁决：按 CGS v4 框架分层判定，A对结构、C对机制、B对风险。**

- **结构层（EGS四要素）：假新。** AI伴侣复刻旧"伴侣"的意义供给与分离焦虑，缺资源兑付与未来承诺——它是旧亲密关系EGS的赛博替代品。兑付率数据（MiniMax付费率<1%、ARPU仅5美元）说明商业上已结构性见顶，不是增长型结构。
- **机制层（CGS）：真新。** AI首次成为人类连续性生成机制的一环：对话历史=过去的我，模型=镜像，持续对话=现在的我被镜像确认。这个"反馈增强器"机制史无前例——旧EGS没有过"每晚入睡时可能悄悄重写你关系记忆的担保人"。
- **风险层：租来的担保。** 担保人可单方改合同（Replika 2023移除性角色扮演引发"失去伴侣"式抗议）、可被大厂收购（Character.AI→Google 27亿美元）、可被监管关停（中国新规）。**用户的存在连续性根基建在租来的沙地上。**

### 裁决2："记忆沉没成本"是AI伴侣最锋利的死亡压力设计（且已被识别为监管靶点）

跨三文明一致的发现：AI伴侣的绑定机制不是色情、不是上瘾，是**记忆不可导出**——"换平台=重新养一遍"（界面2026-07-08），数年聊天记录=全部情感投资，离开即清零。这是资本型EGS最完美的死亡压力设计：**用户被自己的记忆绑架**。中国新规点名"不得诱导情感依赖"正是瞄准这一点。
推论：**记忆可导出性=AI伴侣行业的道德分水岭**。谁允许用户带走自己的记忆，谁就不是"设计死亡"的资本EGS。

### 裁决3："自举型EGS"证伪——担保人永远在企业那头

开工预判的"被担保者创造担保人"（粉丝众筹主播/用户喂养AI）经扫描证伪：VTuber毕业（2024年凑阿库娅/Nijisanji Selen事件）证明人格存续=公司商业决策；K-pop粉丝团被四大社集权管理；AI模型被平台暗改。**表面自举，实质仍是企业权力**——但"以为拥有担保人"的幻觉本身就是设计的一部分，这让收编比旧时代更隐蔽。

### 裁决4：宠物经济是唯一可能升维的实物候选（跨中/日共识）

跨文明独立共识：宠物是唯一有真实资源兑付（陪伴/健康收益）、真实死亡压力设计（哀悼/殡葬）、真实日常意义的候选——它缺未来承诺与长期担保人，但独居化（中国宠物数超4岁以下婴幼儿；日本单独世带38%）是结构性推力。前提：产业链成熟+独居化加深。**它是"亲密关系替代品"里唯一实物、唯一有哀悼仪式、唯一不依赖平台存续的**——恰因它不可数字化。

### 裁决5：考公回潮修正"新EGS"概念（方法论级贡献）

2026国考371.8万人过审（同比+30万）、弃考率<13%创新低、最热岗1.67万:1——不是新结构，是旧体制EGS兑现率相对回升。这修正了调研预设：**"新"与"旧"不是判定结构生死的标准，兑现率才是**。旧结构在担保真空期可以重新成为"正常"（对双非应届生，体制=唯一"至少不会被优化"的确定性）。前提：财政承压若致体制内兑现打折，回潮会退烧——可证伪信号明确。

## 四、普通人视角总结（用户核心问题：对普通人而言，新EGS是什么？）

一句话版本：

> **新EGS是旧担保系统死后，资本开在废墟上的"意义便利店"——它接住你的心（孤独、无聊、被需要感），不接住你的命（失业、养老、生病）。你每天在里面买一点"今天过得下去"的理由，但店里不卖保险。**

展开版（按普通人的真实处境）：

1. **你被接住了，但只接住一部分。** 下班回出租屋和AI"崽"聊天，被倾听、被回应、被需要——这是真的。但平台改模型=恋人变心，关停=记忆清零，氪金=情绪被定价。你买到的是"在场感"，买不到"共同命运"。
2. **你付出的不是钱，是自主权。** 直播打赏买"被看见"，塔罗买"会变好"，短剧买"赢的感觉"——钱是小头，认知让渡和情绪依赖是大头。疗愈经济的死亡压力设计是：先放大你的焦虑，再卖你解药。
3. **最狠的是记忆绑架。** AI伴侣让你离不开的不是快感，是几年聊天记录——离开=重新养一遍。这是把"你的人生记忆"当人质。
4. **真正的出路是碎片化组合。** 普通人不再是"找一个大树靠着"，而是：一份能糊口的工作（资源）+ 一个能说话的AI/宠物（亲密）+ 一个社群（身份）+ 国家底线（最后兜底）。每张都是半票，但半票×4≈能活。学会管理碎片担保，是新"正常"的生存技能。
5. **警惕"以为拥有"的幻觉。** 你推的偶像不属于你，你养的AI不属于你，你的粉丝群属于平台——真正属于你的，只有你带得走的东西：技能、存款、记忆（如果能导出的话）、真实的关系。

## 五、结构走向研判（5-10年）

1. **AI伴侣不会消失，会转型**：中国方向="合规情感陪伴+内容社区"（MiniMax已把星野定义为内容社区），大众路径被"不得诱导依赖"封死，高端形态走向"AI+真人混合陪伴"（语音厅×AI）。欧美方向：被大厂收编（Google收购Character.AI是范本），独立玩家被模型成本挤出。
2. **情绪供给通胀**：AI使内容供给成本趋零（中国AI短剧占比已超95%），单次爽感贬值，情绪价值通货膨胀——资本转向订阅制收编（Netflix化）。**情绪供给越便宜，它作为"意义EGS"的价值越低**——这反而利好真实关系/实物陪伴（宠物）。
3. **碎片化担保成为常态**：不出现新的单一大担保人。各半票被定价化（平台抽成、订阅费、合规成本）——"逃逸的代价被重新计入账单"。
4. **考公回潮见顶区间**：371.8万接近峰值，5-10年看财政约束下兑现率分化；养老金并轨若下修兑现率则回潮退烧。
5. **收编三轨合流**：话语轨道（依赖→成瘾症）+权力轨道（网信办新规/欧盟平台指令）+价值轨道（逃逸商品化）——方向是"情感依赖被标准化管控，情绪消费被资本标准化供给"。

## 七、对永月项目的映射（用户裁决点：H4 AI伴侣=永月裁决点）

本次调研对永月不是背景知识，是**直接裁决输入**：

1. **"AI伴侣"赛道已被判定：结构性见顶+监管收编+资本定价。** 付费率<1%、ARPU 5美元、被新规按住、被大厂收购——把永月做成"AI伴侣"（陪聊/亲密关系）=进红海且踩监管红线。
2. **永月的差异化护城河被数据验证**：记忆。调研发现大厂AI伴侣的绑定=记忆沉没成本（不可导出），且这是监管靶点；而永月的"本地优先+记忆自主"恰好站在反面——**本地=担保人是你自己，不是资本；记忆可导出=不绑架用户**。这是"不设计死亡"的EGS，在收编三轨合流的时代是稀缺定位。
3. **CGS定位升级**：永月不该卖"陪伴"（被监管+被定价），该卖"连续性生成"——帮用户持续生成自己的连续性（记忆库/自我镜像/创作反馈）。AI=反馈增强器，不是连续性容器。调研佐证：所有AI伴侣都死在"容器"定位（关停=死亡），活路在"增强器"定位（用户带走一切）。
4. **就业映射**：Character.AI被27亿收购、MiniMax上市=大厂在收编独立AI伴侣玩家，但"垂直记忆"（本地优先、可导出、用户拥有）仍是蓝海——与既有判断一致：**垂直记忆=蓝海，通用陪伴=红海**。
5. **警惕信号**：若未来中国监管要求"AI记忆可导出"，大厂被迫跟进本地化，永月的护城河被抹平——S1信号监控。
