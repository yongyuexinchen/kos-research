## §1 一句话定位

> **M1 应当被理解为"早期动力学原型"：它贡献了"宏观状态→感知→策略→宏观反馈"的闭环直觉和三层动力学骨架，但它的具体结构（S 隔离、G=trust、γP>γS 硬编码、A 常量、Π 瞬时 softmax、GFR/Y 缺席）已被 B 线审计逐项否决或降级。它不是最终 EGS，是 EGS 走向 Macro–Micro Game 之前的过渡模型。**

## §2 已保留（继承到 B12/B13）

| 遗产 | 保留下来的形态 | 依据 |
|---|---|---|
| **反馈闭环直觉** | G → … → Π → regen → G 的宏观反馈思想，在 B12 DAG / B13 SA-8 中继承为"聚合→制度响应→G"闭环 | B12 §7 |

| **快/慢分类直觉** | G 慢、P/S 中、Π/行为快的分层 → 保留为 B13 时间尺度结构（但去硬编码） | B13 §2 |
| **e/intervention 概念雏形** | "最小有效干预强度 ρ*""制度化 vs 私人替代"等概念 → 保留为 L6 干预层的本体候选 | LHS v0.3 L6 |

## §3 必须删除（B 线裁决后结构性失效）

| M1 项 | 失效原因（裁决来源） |
|---|---|
| **S 无行为通道（choice 不吃 S）** | B1：S 是孤立输出；"制裁陷阱"是拓扑必然非机制发现 → B12 要求 S^d 独立进入策略（SA-2 修正） |
| **G = 资源+制度+信任 混合体** | B11：trust 必须从 G 中删除（G=G_A 纯客观） |
| **硬编码 γP>γS** | B1：这是 imposed condition 非 emergent finding；不得写入新模型为"发现" |
| **A 常量外生** | B12/B13：A 必须具有自身结构/动态，否则担保迁移（B12 §10）不可表达 |
| **Π = 瞬时 softmax** | B12 §5：策略激活谱非互斥、非瞬时；softmax 只是候选之一 |
| **双稳态/滞后未经证实的表述** | B 线纪律：模型 conjecture 不进入结论区 |
| **GFR 缺席 / Y 缺席** | B12/B13 核心变量必须补位 |

## §4 需要重新定义（名称保留、语义升级）

| 旧 M1 | 新定义 | 依据 |
|---|---|---|
| P（承诺期望，单域） | **P^d**（领域条件期望，多域向量） | B10 multi-domain |
| S（制裁期望，无通道） | **S^d**（领域负向期望，独立进策略） | B1 修正 |
| GFR（缺席） | **GFR_global**（非构造式总体信念） | B11 |
| G（混合） | **G**（纯客观，去信任化） | B11 |
| A（外生常量） | **A**（替代担保供给结构，动态） | B12 §4 |
| Π（瞬时互斥 softmax） | **Π**（策略激活谱/资源配置） | B12 §5 |

## §5 只是早期原型、不可继承的内容

| 内容 | 为何定位为原型 |
|---|---|
| M1 具体参数（a/b/λ/ρ/k/Gc/τ 等） | 无实证锚定，作演示参数 |
| M1 的"禁选择"函数族（sigmoinds, softmax with fixed τ） | 结构假设待 B5–B8 识别 |
| M1 的干预矩阵读数 | 只标 MODEL RESULT（T2），不进现实结论 |
| M1.1-M1.3 版本链的数值结论 | 在 B13 结构框架确立后才能重设数值实验 |
