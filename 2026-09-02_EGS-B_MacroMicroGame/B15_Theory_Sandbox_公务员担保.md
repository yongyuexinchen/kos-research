## §2 情境设定（从 FT01 继承的客观结构事实）

按 B12 领域担保结构，把"公务员工资/就业市场"编码为两个领域的担保结构：

```
Macro G = moderate（FT01 客观层事实：财政紧平衡、编制总量只减不增、保工资制度化兜底、青年失业高企）
GS^public :
   X_public  = 进入并持续担任公务员（考试→录用→履职）
   Y_public  = 稳定职业 + 稳定收入/福利 + 低非自愿失业风险
   I_public  = 财政供养、编制制度、退出门槛法定（公务员法）
   R_public  = 退出/不进入 → 失去低失业暴露 + 稳定福利（相对市场）
   M_public  = 财政保底型承诺-制裁
GS^market :
   X_market  = 市场化就业投入
   Y_market  = 市场收入 + 有波动（青年失业、灵活就业替换）
   I_market  = 市场契约/雇主
   R_market  = 不进入 → 中青年失业/收入波动暴露较高
   M_market  = 市场配给型
```

替代担保供给（B12 A，本沙盒给定，不作实证推断）：
```
A_public  = 有限（财政铁饭碗机制独特，替代质量次一档）
A_market  = 较高（民企、国企、灵活就业路径多但保底弱）
```

## §4 机制演算（B13 结构，T2 推演）

### 4.1 信念层（方向性推演，结构假设 SA-1/2/3）

- GFR_global：宏观 G 中等 → 总体信念中位（不直接决定领域分化）。
- P^public：I_public 强（财政保底）→ 领域期望高
- P^market：低失业暴露 + 灵活就业替换 → 领域期望低
- S^public：退出的机会成本高（失去稳定暴露）→ 中高
- S^market：退出的机会成本相对低（有市场变体）→ 中

### 4.2 策略层（B12 基础操作推演）

| 主体 | 主导策略（T2 推演） | 逻辑 |
|---|---|---|
| S_a | substitute（保留路径 Y_public 但部分资源投入市场）/ retain 高涉入 | 有资源兼顾 |
| S_b | defer（延迟消费/婚姻 / 暂缓市场冒险）+ substitute 弱 | 双域暴露，成本约束 |
| S_c | retain_public 高 + desire_reduction（下调 Y 预期）| 无替代，投入铁饭碗 + 降欲 |

### 4.3 聚合与反馈（T2 推演）

聚合策略分布（演示）：retain_public 上升、defer 上升、desire_reduction 上升、switch_market 受限。

宏观反馈链（B13 SA-8）：
```
Y_t（大量主体偏向 retain_public + defer + desire_reduction）
   → aggregate variable：公务员报考热度维持/上升；市场化劳动供给相对收缩；消费/生育延迟
   → institutional response：财政压力在编制侧缓解（报考热度高→供给充足）但需求侧结构性承压
       市场侧：劳动供给收缩→雇佣谈判力部分改善（中长期）
   → G_{t+1}：系统结构性调整（财政/编制相对稳定，市场化配置相对收缩）
```

**沙盒结论性陈述**：在同一宏观状态下，B12/B13 结构可推演出"主体按 R_i/Exposure/History 分化+聚合反馈"的完整闭环，且领域分化必须由 P^d 承载（无 P^d 则 S_a/S_b/S_c 的策略分化退化为 GFR 单值驱动）——与 B10/B13 CF-1 一致。
