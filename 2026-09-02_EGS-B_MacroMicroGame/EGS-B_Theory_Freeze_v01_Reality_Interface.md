## §4 Reality Interface（A 线未来需提供的四类现实输入）

| 接口 | A 线提供什么 | 关键要求 |
|---|---|---|
| **RI-1 Guarantee State** | 现实某领域中 G / GS^d / P^d / S^d / A / opportunity 的变化 | 客观可观测；禁止用"感觉"替代 |
| **RI-2 Micro Response** | 多个主体 Π_i / Y_i 的变化 | 重点不是"多少人退出"，而是**不同策略是否出现系统性重新配置**（策略分布的结构变化） |
| **RI-3 Aggregate Behavior** | 个体变化聚合后的 Π_t / Y_t 变化 | 保留分布；聚合结构可观察 |
| **RI-4 Institutional Feedback** | Aggregate → Institutional Response → G_(t+1) 是否可观察的完整反馈 | **最重要的接口**；无此则反馈链无实证 |

> A 线不需要大量问卷，需要这四类现实材料。

## §10 P^d 的真正生死门（Macro–Micro 层裁判标准）

不再争论"P 是否心理测量学独立"。新的裁判是：

> **在相同或相近 GFR 下，P^d 能否解释可重复的跨领域策略分化。**

现实必须至少出现：

```
GFR_i ≈ GFR_j
且 P^d_i / P^d_j 明显不同
且 Π_i / Π_j 出现稳定差异
```

若最终显示 `GFR → Π` 已足够 → **P^d 降级或删除（禁止因 ontology 已喜欢 P 而保留）。**

## §11 A 的真正生死门

观察模式：

```
P^d ↓  +  A ↑  →  substitute / switch ↑
```

- 若现实长期显示"担保下降后主体只退出、降欲、从不发生担保迁移" → **A 的核心地位重新评估**；
- 若替代路径迁移反复出现 → **A 获得现实支持**。
