> 性质：**模型结构文档（T1/T2）**。所有函数形式标 structural assumption；禁止为"跑起来"任意指定参数。模型结果 ≠ 现实证据。

---

## §1 设计原则（继承 B 线全部铁律）

1. **最小充分结构**：只含 B12 ontology 的核心变量；条件变量（R_i/C_i/Exposure/History）只作异质性调节，不抬入核心状态。
2. **不设硬编码发现**：γP>γS、双稳态、罚陷阱等一律不得直接写进结构；必须先证明内生。
3. **快慢分层**：时间尺度是结构的一部分，不是调参。
4. **可删性检验**：每个变量都要过 deletion counterfactual。
5. **标出不可识别性**：能写清楚的识别条件写清楚；写不清的标"未定义"。

## §4 核心方程（候选形式 —— 全部标注 structural assumption）

### 4.1 信念层（P^d / S^d / GFR）

候选一般形式（**不冻结具体参数**，只给结构空间；实现时必须先做 identifiability 审计，B5–B8 协议执行）：

```
P^d_{i,t+1} = F_P( P^d_{i,t}, 兑现信号^d_{i,t}, GS^d_t, GFR_{i,t}; ψ_P )   [SA-1]
S^d_{i,t+1} = F_S( S^d_{i,t}, 退出代价信号^d_{i,t}, GS^d_t; ψ_S )           [SA-2]
GFR_{i,t+1} = F_G( GFR_{i,t}, Z_shared, Z_global; ψ_G )                    [SA-3]
```

- **SA-1 声明**：P^d 由领域特异兑现信号更新；GFR 不作为 P 的构造成分（B11）。
- **SA-2 声明**：S^d 独立更新，不进 P 的传播通道。
- **SA-3 声明**：GFR 由共同原因（Z_shared：客观兑现史）+ 总体信号（Z_global）驱动；**无 P→GFR 构造边**（B11 共同原因式）。

### 4.2 策略层（Π）

```
Π_i,t = σ( V_i,t )                                    [SA-4]
V_i,t = h( GFR_{i,t}, {P^d,S^d}_{i,t}, A_{i,t}; R_i, C_i, Exposure_i, History_i )   [SA-5]
```

- **SA-4 声明**：σ 是策略激活映射（softmax 只是候选之一；互斥性不被默认）。
- **SA-5 声明**：h 的结构与参数将按 B5–B8 识别协议判定，先标结构假设，不预设线性/单调。

### 4.3 行为与聚合

```
Y_i,t     = g( Π_i,t )                                 [SA-6]
Y_t       = Aggregate_i( Y_i,t ; 分布 )                 [SA-7]
```

- **SA-6**：行为是策略激活的函数（映射形式待识别）。
- **SA-7**：聚合保留分布信息；禁止用总量取代结构。

### 4.4 宏观反馈（闭环关键）

```
G_{t+1} = F( G_t, Aggregate(Y_t; 制度响应), external_t )   [SA-8]
```

- **SA-8 声明**：制度响应是反馈链的必要环节（B12 §7）；"任一个人口变化=反馈"被禁止。
- 制度响应形式暂标 T1：候选机制包括财政压力、编制/制度调整、市场供给变化（劳动/消费/资本配置）。

## §7 Degenerate Cases（模型退化判定）

| 情形 | 退化含义 | 处理 |
|---|---|---|
| 无反馈（制度响应=0） | 单向响应模型，无 Macro–Micro 机制 | B13 不承认其为机制模型 |
| 无异质性（条件变量全同） | Π 分布塌缩为单点 | 只允许作为理论检验特例 |
| 信念=客观（感知即时投影） | 退回 M1 D2 滤波；信念层消失 | 违反 B11，禁止 |
| A 为常量 / 无替代 | 担保迁移（B12 §10）不可表达 | 违反 B12，禁止 |
| S 无行为通道 | 制裁维度退化为装饰 | 违反 B1 修正确认，禁止 |
| Π 退化为 one-hot | 回到互斥分类，失去激活谱 | 违反 B12 §5 |

## §8 Deletion Counterfactuals（B12 核心对象的删/留裁定，理论级，非实证）

### CF-1：删除 P^d

**反事实**：若模型 = {GFR_global + S^d + A}（无 P^d），能否产生领域差异策略？

- **理论层**：B12 DAG 中，领域差异来源有两个候选：GS^d 结构差异（客观）与 P^d 信念差异（主观）。删除 P^d 后，策略只能由 GFR/S/A 驱动——**同一宏观结构下所有主体领域内差异化反应消失**。
- **B10 多领域裁决**：R15 韩国案例的解释依赖"就业/住房领域分化"——这必然经 P^d（或等领域价物）表现。
- **裁定**：**P^d 不能删**（与 B4–B10 一致）。若未来 A 线显示 P^d 无增量（Failure A），则 B12 本体需回炉——但那是实证裁决，非模型内可从由删除。

### CF-2：删除 A

**反事实**：无替代担保结构，主体还能"转向替代路径"吗？

- 担保迁移（B12 §10）要求 A 存在。删除 A ⇒ 策略空间只剩 {retain, withdraw, defer, desire-reduction}——switch/reconstruct 消失。
- **裁定**：**A 是必需的最小结构**（M1 中 A 常量已修）。

### CF-3：删除反馈（无制度响应）

**反事实**：G 外生 + 微观单向响应。

- 无 → G 反馈，系统只是"宏观状态 + 个体预测"的拼接（任务书明确点名拒绝的形态）。
- **裁定**：**反馈必须存在**，否则不构成 Macro–Micro mechanism。

### CF-4：删除 GFR_global（只有 P^d）

**反事实**：领域信念总汇能否替代总体信念？

- E5 反证（B4）：同 P^d、异 GFR 必须是合法状态；删除 GFR 后总体层无安放处。
- **裁定**：GFR_global 不可删（B4/B11）。
